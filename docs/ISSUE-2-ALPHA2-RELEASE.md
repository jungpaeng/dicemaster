# DiceMaster v1.0.4-alpha.2 — 선택지 미리보기 가독성

alpha.1의 선택지 결과 표시를 읽기 쉽게 다듬은 prerelease입니다. 사용자 피드백과 게시 지시에 따라 배포하며, 정식 Latest는 [v1.0.3](https://github.com/jungpaeng/dicemaster/releases/tag/v1.0.3)으로 유지합니다.

## 바뀐 표시

- 일부 결과를 해석하지 못하면 **추가 영향 가능**, 확인된 효과 없이 미해석 부분만 있으면 **결과는 진행 후 확인**으로 안내합니다. 추가 영향은 보상·손해 어느 쪽일 수도 있습니다. 실제 읽기 실패와 게임 데이터 대기는 기존 오류 상태로 구분합니다.
- 같은 조건문의 효과를 분기별 한 줄로 묶습니다. 같은 번호의 A/B/C는 한 조건문의 갈래이며, 서로 독립적인 조건문과 중첩 조건문은 별도 번호·경로로 구분합니다.
- 갈래 제목은 청록·연보라·금색으로 구분합니다. 색상은 **갈래 구분용**이며 현재 조건의 충족 여부가 아닙니다. 효과 자체의 기존 증감 색상은 유지합니다.
- 후속 효과는 **이어서 진행 시** 아래에 배치하고 내부 스크립트 등록 문구를 숨깁니다. 다음 사용자 선택 전까지의 기존 추적 경계를 유지합니다. 후속 연결 자체가 능력치 판정을 뜻하지 않으며, 조건은 플래그·미션·이야기 흐름 등에 따라서도 달라질 수 있습니다.
- Tab 로그에는 전체 설명을 줄바꿈하여 표시하고, 게임 선택지 옆에는 줄바꿈을 구분자로 줄인 기존 50자 요약을 표시합니다. 추가 영향 안내는 요약이 잘려도 앞에 남깁니다.

표시 형태의 예시입니다. 실제 조건이 아래 수치와 같다는 뜻은 아닙니다.

```text
추가 영향 가능
이어서 진행 시 · 구간 1
  [분기 1-A] 호감도 +5 | 체력 +3
  [분기 1-B · 그 외] 호감도 -3 | 체력 +10
```

실제 같은 `if/elseif/else`의 효과만 묶습니다. 서로 독립적인 조건문을 양자택일로 합치지 않으며, 현재 능력치로 어떤 갈래가 실행될지 임의로 판정하지 않습니다. 표시를 위해 게임 Lua·상태 변경 API·게임 RNG·원래 조건 실행 사슬을 실행하지 않습니다. 전체 Lua 원문과 세이브 내용은 진단 로그에 남기지 않습니다. 설정·세이브 형식과 기존 로그·난수·수명주기·주사위·패드 계약을 유지합니다.

## 실행한 검사와 남은 확인

관리 코드와 읽기 경계 대역으로 다음 검사를 통과했습니다.

- 실제 후보 DLL의 미리보기 467단언, 실제 요약·파서·로그 통합 138단언.
- 갱신 보호 19단언, 갱신 엔진 16개 시나리오·70단언, 수명주기 4,023단언.
- 실제 게임 관리 IL 동작 3,914단언과 메타데이터 계약 1,021단언.
- 패드 262,715단언, 번역·주사위 2,170단언.
- 기존 injector 신규·반복 적용에서도 미리보기·통합·관리 동작·메타데이터 검사 통과. 내장 리소스 8개 보존.
- 설치 ZIP의 CRC·정확히 두 파일·새 소스 빌드 DLL과 설정의 바이트·해시 일치.

**실제 Lua 리소스 대조, 이번 DLL의 Windows·Unity/native·실제 Harmony·게임 화면·진행·실게임 성능 확인은 미완료입니다.** 사용자의 기존 alpha.4 Windows 확인을 이번 DLL에 승계하지 않습니다. 개발 추적 한도는 alpha.1과 같으며 실제 Lua와 비용 측정에 따른 최종값은 아직 확정하지 않았습니다. 이번 게시로 PRD #2 전체나 기능 완료를 선언하지 않고 이슈 #2는 open으로 유지합니다. 상세 조건과 검사 기록은 [구현·검증 기록](https://github.com/jungpaeng/dicemaster/blob/main/docs/ISSUE-2-IMPLEMENTATION.md)에 있습니다.

## 설치 파일

자산 **DiceMaster-v1.0.4-alpha.2.zip**을 사용합니다. GitHub 자동 Source code 압축 파일과 구분합니다. ZIP에는 다음 두 파일만 포함합니다.

```text
config/DiceMaster.cfg
plugins/DiceMaster/DiceMaster.dll
```

| 항목 | 크기 | SHA-256 |
| --- | ---: | --- |
| `DiceMaster.dll` | 504,320바이트 | `121f09973f8c37353e78afd341c735c84ca3f49f8ca20319c54b62bfc091b5b2` |
| 설치 ZIP | 210,060바이트 | `0721cd36a6c951af31853679d131f0f07a9b59f8f1d85f66ee7ec541cfe39e57` |
| `DiceMaster.cfg` | 9,759바이트 | `8fada1d878689e70f1ec510c6438116f7ab6e69e1e7a728bbb0986164e77bc7e` |

게임 DLL·게임 소스·실제 Lua·세이브·개발 로그는 설치 ZIP에 포함하지 않습니다. 어셈블리 내부 버전은 기존 `1.0.0.0`을 유지하며 배포 태그와 SHA-256으로 파일을 구분합니다. 이전 Release·태그·자산은 보존합니다.
