## 재현과 이전 검사의 한계

사용자는 alpha.20에서도 남제자방의 사사형 툴팁이 10~20초 이상 남는다고 확인했다. 같은 문구만으로 초회 인사와 대련 중 무엇을 골랐는지는 구분할 수 없었다. alpha.20의 원본 Lua 검사는 직렬화 조건을 합성 횟수형으로 구성했고 240회 이후 최종 결과만 검사했다. 실제 설치판의 조건 자료·세이브를 읽은 결과가 아니며 모든 반복 안내 문제가 해결됐다는 근거로 사용할 수 없다.

추가 조사에서 초회 필요 조건이 NotMet이어도 경로 준비 중에는 `currentRoot`를 쓰지 않아 Unknown 후보로 표시하는 것을 재현했다. 별도로 바깥 사사형 → 대련의 ActivityResponse 구조가 부모 횟수형 조건의 플래그 독립성을 증명하지 못해 Unclassified가 되고, 다시 일반 대화의 가능성으로 선택되는 경로를 확인했다. 횟수형 비교는 FlagData를 참조하지 않는데 기존 검증은 `_useCount=true`만으로 독립성 증명을 거부했다. 내부 대련 메뉴에서 시작한 경로와 바깥 인물 메뉴부터 이어 온 경로의 결과가 달랐다. 자료 누락과 준비 슬라이스에 따라 탐색 상한에 남는 경로가 달라질 수 있으므로 최종 행 하나만 확인하지 않는다.

이는 원본 Lua와 합성 상태·자료 누락·관찰한 Lua 환경 경계를 연결한 재현이다. 사용자 Windows 세이브의 정확한 선택 근거는 아직 확인하지 않았다.

## 변경

1. 실제 메뉴 위치가 모호하거나 경로/색인이 준비 중이면 임시 일반 이야기 툴팁을 자동 표시하지 않는다. 상세에 준비/위치 확인 대기와 표본을 남긴다. 전체 준비 후에는 기존 닫힌 현재 루트의 불가 전용 표본으로 완료 항목을 제외한다. 불명 메뉴를 임의로 현재 메뉴라고 확정하거나 오래된 조건값을 저장하지 않는다.
2. 플래그 독립성을 `true=독립 증명`, `false=실제 영향을 받는 입력 확인`, `null=미지원/누락/상한`으로 구분한다. 고정 활동 구조에서 독립성이 미확정이면 자동 일반 이야기 안내를 보류하고 상세에 남긴다. 자신의 해금 조건을 소모하는 것으로 확인한 주제는 개별 이야기 후보로 유지한다. 모든 Unclassified 대화나 대련을 일괄 제거하지 않는다.
3. 횟수형 Switch는 정확한 직렬화 정수/비교 목록 형식·상한을 확인하면 플래그 쓰기와 독립임을 증명한다. 이것은 값 판정과 별개다. 일반 Switch 결과는 계속 미확정이며 `_count+1` 값 읽기는 alpha.20의 안전한 첫 루트 호출 범위에만 허용한다. 원래 Switch/Check/Execute·Lua·RNG·플래그 초기화를 호출하지 않는다.
4. 명시적 선택 안내 상세에 실제 표시한 스크립트·대사 ID 한 건과 제외한 표본 한 건, 제외 사유·현재 필수 조건 진단을 붙인다. 선택된 근거가 없으면 표시 근거를 꾸미지 않는다. 진단에는 기존 조건기의 원본 Switch/Condition 키·횟수 모드·현재 값·미확정 사유가 포함된다. 자동 툴팁에는 이 진단을 만들거나 붙이지 않는다. 한 표본은 전체 제외 사유의 완전한 목록이 아니다.

특정 인물·조건 키 예외 목록은 없다. 일반 난수 이야기·별도 조건부 이야기·조건을 소모하는 주제를 유지하고, 기존 후속 선택 해금 필터와 마커의 현재 대기 임무 또는 엄격한 1회성 증명·현재 조건·경로를 보존한다. 배지가 없거나 툴팁이 보류돼도 모든 이야기 부재를 뜻하지 않는다.

## 비용·설정·조작

동적 독립성은 같은 예약 갱신 Reader/캐시와 기존 분류 예산 32개에서 읽고 다음 갱신까지 값을 보관하지 않는다. 횟수 비교 목록 상한은 256개이며 일반 조건기 작업 상한을 공유한다. 명시적 상세 진단은 최대 표시 한 건·제외 한 건, 각각 기존 조건기 진단 상한을 따른다. 정상 .25초/실패 5초·숨김/OFF 조회 중단·렌더링 중 조회 없음·정상 주기 Lua 재분석 없음 계약을 유지한다.

새 설정과 cfg 변경이 없다. EnableMapGuide가 기존 선택 경로도 제어하며 네 기능의 영구 설정·상위 EnableOptionInfo·OFF/기록 초기화 계약을 유지한다. 원래 게임 버튼·Xbox/XInput/키보드/마우스/터치·입력 소유권·해제/중립·네 로그 탭·이벤트/미션 예약·주사위·상점·실제 분기 기록은 보존한다. 게임 상태에 쓰지 않는다.

## 자동 검사와 남은 Windows 확인

`tests/ChoiceStoryTests/ActivityEvidenceCases.cs`는 독립/영향/미확정 구분, 부모 횟수형 조건을 거친 고정 활동, 완료/미완료/자료 누락 전환과 정확한 상세 근거를 검사한다. 원본 `room_001`·`talk_brother4` 검사는 SHA를 대조하고 관찰한 대화 플래그 초기화 환경을 연결하며, 정상·무관한 파일 누락에서 각 갱신마다 완료 인사와 반복 대련의 자동 안내 부재를 검사한다. 기존의 조건 소모·독립된 전투 후 이야기·난수·패드 포커스 검사를 유지한다. 실제 후보 DLL IL도 독립성의 세 결과와 카운터 무변경을 검사한다.
