# PRD #6 후속 — 상점 설명에서 사용·학습 효과 바로 보기

[사용자 안내](../README.md) · [개발 안내](DEVELOPMENT.md) · [패드](GAMEPAD.md) · [공개 alpha.2 기록](ISSUE-6-SELECTED-MAP-SHOP.md)

상태: **미게시 로컬 후속 후보 / 새 실제 Windows 확인 대기**. 원래 작업 폴더의 main에서 구현·검증한다. 공개 시험판 v1.0.7-alpha.2와 Latest 정식 v1.0.6의 태그·파일은 변경하지 않는다. #6 전체 완료나 이슈 종료로 처리하지 않는다.

## 사용자 요청과 원인

2026-10-21 사용자는 상점에 `사탕수수 · 일반 물품 · 사용 효과 일부 확인`처럼 아이템 효과 대신 분석 결과가 보인다고 알렸다. 조사 결과 사용 메뉴에서 효과 수치와 물품 소모를 읽어도 자동 문구를 이름·종류·상태로 제한해 상점에는 효과를 넣지 않고 로그 상세에만 넣고 있었다. 화면 연출·대사·대기 같은 미지원 호출이 같은 분기에 있으면 전체 분석이 부분 확인으로 바뀌어 이 진단이 효과를 대신했다.

이어 사용자가 **“상점 설명에서 아이템의 사용·학습 효과를 바로 볼 수 있게 수정해줘.”**라고 요청했다. 이전 PRD의 자동 이름·종류·상태 제한을 상점에서 바꾸는 명시적 후속 결정이다. 지도·1회성·분기 자동 표시와 다른 제품 범위는 유지한다.

## 상점에서 읽는 내용

기존 게임 설명을 그대로 보존하고 아래의 `사용 효과:` 또는 `학습 효과:`에 여러 줄로 효과를 추가한다. 효과를 얻은 경우 분석 상태만으로 대체하지 않는다.

| 물품 | 설명 순서와 범위 |
| --- | --- |
| 일반·특수 물품 | 종류·ID로 연결한 사용 메뉴의 효과 수치·소모. 여러 사용 선택지와 조건부·난수 효과는 해당 조건·가능성 표기를 유지 |
| 책·비급 | 다음 한 단계의 학습 효과를 먼저, 이어서 현재·다음 단계와 학습 진행·소모·학습 조건. 미래 모든 단계나 장비 착용 결과를 확정하지 않음 |
| 최대 학습 단계 | 최대 단계임을 표시하고 존재하지 않는 다음 효과를 만들지 않음 |
| 확인된 변화 없음 | 분석한 범위에서 변화가 없음을 표시. 연결 실패와 구분 |
| 미지원·사용 경로 미연결 | 확인하지 못한 이유를 표시. 효과 없음·사용 불가로 단정하지 않음 |

해석 가능한 효과와 불확실성은 함께 읽는다. 조건부·동적·난수 변화는 실제 적용량 확정으로 바꾸지 않으며 미지원 영향이 남으면 추가 영향 가능성을 유지한다. 전체 조건·효과와 진단은 기존 **Tab 또는 L3/R3 겹침 → 버튼 해제·스틱 중립 → Y 도구 → 상점 효과 조회**에서도 읽을 수 있다.

원래 설명과 줄바꿈을 유지하고 매 갱신에 같은 문구를 중복해서 붙이지 않는다. 선택을 바꾸면 현재 물품의 내용으로 교체한다. 상점을 닫거나 `EnableShopEffectInfo`를 끄면 자신의 추가 문구만 정리하고 원래 설명을 복원한다. 다른 코드가 바꾼 설명을 오래된 원문으로 덮어쓰지 않는다.

## 입력·설정·읽기 전용 계약

- 기존 게임의 `ShopPanel.OnItemHover`는 패드 선택과 포인터가 공유하는 관찰 경계다. 새 버튼·가상 마우스·포커스 이동·입력 소비를 추가하지 않는다. 키보드·마우스·터치와 Xbox/XInput 입력 소유권·해제/중립 보호를 유지한다.
- `EnableShopEffectInfo`는 기본 ON이며 기존 로그 도구에서 즉시 변경·저장한다. 상위 `EnableOptionInfo`는 시작 시 적용한다. 설정 읽기 실패는 해당 기능만 비활성화하고 최초 키 누락의 기본 ON과 구분한다.
- 조회는 사용·학습·구매·게임 조건 실행·세이브를 호출하지 않고 아이템·능력치·학습점·RNG·게임 판정을 바꾸지 않는다. 이미 있는 자료와 로컬 계산만 읽는다.
- 정상 0.25초·실패 5초·숨김/OFF 조회 중단을 유지한다. 사용 메뉴 정의·물품별 연결은 기존 문맥별 캐시를 재사용하며 정상 갱신에 Lua를 다시 분석하지 않는다. 표시 단계는 캐시된 문구만 사용한다.
- 기존 로그 네 탭·이벤트 선택 팝업·미션 예약·주사위와 다른 #6 정보 기능은 유지한다.

## 설치와 복구

검증을 마친 로컬 후보의 설치 파일은 위 후보 절의 경로를 따른다. 게임을 종료하고 기존 DLL/cfg를 백업한 뒤 **plugins/DiceMaster/DiceMaster.dll만 교체**한다. 기존 cfg·단축키·창 배치·글자를 보존한다. 새 버전의 공개 ZIP은 아직 게시하지 않았다.

문제 시 게임 종료 후 백업 DLL과 필요한 cfg를 복원한다. 공개 alpha.2나 확인된 정식 v1.0.6은 각각의 Release에서 받을 수 있다. DLL 복구는 이미 진행하거나 저장한 게임 상태를 되돌리지 않는다.

## 실제 Windows 확인

아래 항목은 **미실행·사용자 확인 대기**다. 새 후보의 통과 기록으로 정식 v1.0.6의 선행 확인이나 다른 DLL의 관찰을 대신하지 않는다.

- [ ] 설치 DLL 해시, 게임·Windows·BepInEx 버전, 해상도·UI 배율, 패드 모델·Steam Input 설정을 기록한다.
- [ ] 상점에서 사탕수수 등 연결된 일반·특수 물품을 패드로 선택한다. 원래 설명 아래에 실제 효과 수치와 소모가 보이고 분석 상태만 표시되지 않는지 확인한다. 마우스 호버가 없어도 같은 내용이어야 한다.
- [ ] 조건부·난수·여러 사용 선택지가 있는 물품에서 가능성·조건·추가 영향 표기를 확인한다. 사용 경로 미연결을 효과 없음으로 표시하지 않는지 확인한다.
- [ ] 학습 가능한 책·비급, 조건 미충족 책, 최대 단계 책을 비교한다. 다음 학습 효과가 먼저 보이고 현재·다음 단계와 학습 진행·소모·조건이 구분되는지 확인한다. 긴 책 설명과 큰 글자·작은 화면에서 잘림·가독성을 기록한다.
- [ ] 같은 물품을 유지한 반복 갱신, 빠른 물품 전환, 상점 닫기/재진입에서 문구 중복·이전 물품 잔류가 없는지 확인한다. 기존 게임 설명과 줄바꿈이 보존되어야 한다.
- [ ] 로그 도구의 상점 기능 OFF·ON과 재시작을 확인한다. OFF 때 원래 설명으로 복원하고 ON 후 현재 선택부터 다시 읽으며 다른 기능 설정은 유지되어야 한다.
- [ ] 기존 Y 도구 → 상점 효과 조회에서 긴 상세와 조건을 읽는다. 조회만으로 돈·재고·아이템·능력치·학습점·게임 RNG가 바뀌지 않아야 한다.
- [ ] 키보드·마우스·터치와 Xbox/XInput의 기존 선택·구매, 로그 열기/닫기·네 탭·팝업·예약·주사위를 확인한다. 도구에서 사용한 입력이 뒤의 게임으로 재사용되지 않아야 한다.
- [ ] 상점 표시와 숨김/OFF·선택 변경의 실제 성능·오류를 확인한다. 자동 검사 시간·할당량을 실제 Unity 프레임 비용으로 해석하지 않는다.

실제 Windows 확인이 남아 있어 #6 전체 완료·이슈 종료로 처리하지 않는다.
