# DiceMaster v1.0.5-alpha.6 — 게시 준비

alpha.5 이후 요청한 읽기 화면과 **양쪽 스틱 클릭으로 로그 열기**를 모은 테스트용 prerelease를 준비합니다.
로컬 전체 소스 빌드·12개 검사는 통과했으며 고정 커밋 재빌드·실제 게시·인증 없는 공개 다운로드 확인은 별도 진행 후 기록합니다.
실제 Windows 게임의 패드·터치·배치 확인은 대기 중이며 [이슈 #4](https://github.com/jungpaeng/dicemaster/issues/4)는 미완료로 유지합니다.

## 이번 변경

- **창·글자 기본값:** 1920×1200에서 872×960px·본문 20px를 기준으로 맞춥니다. 창 너비는 화면의 `872/1920`, 높이는 80%이며 글자는 화면 높이 `/1200` 배율을 사용합니다. 1080p는 872×864·18px, 1440p는 1163×1152·24px입니다. 기존 사용자 지정 배치와 첫 표시 초기화 보호를 유지합니다.
- **선택지 읽기:** 접기·선택 버튼 모양과 강조를 없애고 모든 문장·효과를 계속 보여 줍니다. 항목 사이에 간격을 두며 ↑↓·오른쪽 스틱으로 본문을 읽습니다. A·좌우·제목 누르기는 선택이나 접기를 만들지 않습니다.
- **조건 분기 구분:** 오른쪽 상세를 `분기 1`·`분기 2`·`그 외` 블록으로 나누고 검사 순서와 각 분기의 맥락을 표시합니다. 한 분기 안의 복합 조건은 같은 블록에 남깁니다. 게임의 실제 항목 구조를 게시 모델로 전달하며 설명 문자열을 다시 잘라 분기를 추정하지 않습니다. 상세는 읽기 전용입니다.
- **미션·스크롤:** 정상 미션의 반복적인 `조회 정상`과 빈 상태 줄을 생략하고 대기·실패·이전 값 안내는 유지합니다. 네 탭의 목록·상세·도구는 내용이 영역을 넘을 때만 스크롤바를 표시합니다.
- **패드로 열기:** 같은 패드에서 한쪽 스틱 클릭을 누른 채 **300ms 미만**에 반대쪽도 눌러 겹치면 로그를 엽니다. L3+R3 동시 클릭도 가능하며, 겹치지 않는 연속 클릭은 조합이 아닙니다. 조합은 열기 전용이고 기존 Tab·`LogMenuToggleKey`와 B 복귀·닫기를 유지합니다. 이 기능은 초기 PRD의 패드 열기 제외를 대체한 사용자 후속 지시입니다.

새 `[DiceMaster].EnableGamepadLogOpen`의 기본값은 `true`이고 주사위 패드 조정 옵션과 독립적입니다.
**옵션 켜짐·게임 창 초점·로그 닫힘에서는 L3/R3 단독 클릭도 게임에 전달하지 않습니다.** 첫 클릭이 게임 기능을 함께 작동시키지 않도록 두 클릭을 로그 열기용으로 예약하는 제약입니다.
기존 스틱 클릭 기능이 필요하면 옵션을 `false`로 끄세요. 남은 누름은 해제 후 반환하며, 초기화·상태 재설정의 전체 중립 대기에서는 다른 버튼·스틱·트리거의 남은 입력도 소비합니다.

전체 입력 해제·중립 뒤 같은 소유자의 새 조합만 받아들이고 열린 뒤에도 조합을 해제한 다음 새 탐색 입력을 받습니다.
패드 열기 의도를 로그 내부에 전달해 KM·불명 모드나 자동 scheme 변경 때문에 첫 새 탐색 입력을 다시 잃지 않게 합니다. 단순 포인터 이동·호버는 이 진입을 취소하지 않으며 실제 클릭·터치·휠·키 조작에는 기존 전환 보호를 적용합니다. **게임 입력 모드나 액션 맵은 변경하지 않습니다.**

기존 터치·마우스·키보드, 네 탭·한국어·읽음·분석·자동 갱신, 도구 17개와 이벤트·미션 예약을 유지합니다. 예약은 즉시 발생을 보장하지 않습니다.
대상 소멸·새 문맥·실패는 오래된 실행 권한을 취소하고 실패 중 읽을 수 있는 마지막 정상 값은 보존합니다. 읽음 상태를 조건 충족이나 실제 선택된 분기로 바꾸지 않습니다.

## 확인한 범위와 남은 확인

로컬 12개 검사 프로그램·입력 153개 일치·ZIP CRC·정확히 두 파일·내부 바이트·SHA-256을 확인했습니다. 전체 모드 컴파일은 오류 0개·기존 경고 7개입니다.

| 주요 검사 | 결과 |
| --- | --- |
| 패드 열기 통합 | 28개 격리 시나리오·993개 단언. 실제 native hook·filter·bridge·controller·action gate 소스 연결 |
| UI·입력 / 모델 / 실제 DLL 연결 | 2,720개 / 372개 / 47개 검사 |
| 실제 DLL helper·게시·모델 통합 | 203개 단언 |
| 게임 API / 선택지 / 주사위·패드 | 관리 동작 3,914개·메타데이터 1,047개 / 통합 1,453개 / 262,831개 단언 |

나머지 갱신·수명주기·한국어·주사위 검사를 포함한 [전체 12개 결과](ISSUE-4-PAD-OPEN.md#후보와-자동-검사), [manifest](../artifacts/issue-4/pad-open/build-manifest.json), [독립 검증 영수증](../artifacts/issue-4/pad-open-evidence/local-verification.json)을 보존합니다.
게임·Win32·XInput 원래 export·Unity는 명시적인 검사 대역입니다. 자동 검사는 실제 Windows 후킹 적용·한글 배치·스크롤·터치·게임 입력 중복이 정상이라는 증거가 아닙니다.

- **Tab 진입의 기존 모드 전환·첫 패드 입력 소비 문제는 별도 미해결 경로입니다.** 새 패드 조합으로 연 경로의 검사 결과로 이를 해결했다고 주장하지 않습니다.
- 게임의 직렬화된 입력 바인딩 자료가 없어 L3/R3가 미사용이라고 확정하지 못했습니다. 원래 클릭 기능과 Steam Input 구성은 사용자 환경에서 확인해야 합니다.
- 패드 열기는 실제 지원되는 게임 XInput 폴링·차단 경로를 확인한 경우에 사용합니다. 실패·미지원 시 기존 Tab·마우스·키보드로 접근합니다.
- 이 후보의 Windows 게임은 에이전트가 설치하거나 실행하지 않았습니다. 이전 Windows 확인 기록을 이번 후보에 승계하지 않습니다.

## 설치 파일·적용·복구

게시 예정 설치 자산은 `DiceMaster-v1.0.5-alpha.6.zip`입니다. GitHub 자동 `Source code` 압축 파일과 구분합니다.
ZIP에는 `config/DiceMaster.cfg`와 `plugins/DiceMaster/DiceMaster.dll` 두 파일만 포함하며 게임 DLL·소스는 포함하지 않습니다.

| 파일 | 크기 | 검토 후보 SHA-256 |
| --- | ---: | --- |
| `DiceMaster.dll` | 582,656바이트 | `4bcce037713407e25378ecbd2113649c9f9e52968659b1b748a6bec795645efa` |
| `DiceMaster-v1.0.5-alpha.6.zip` | 245,066바이트 | `fe26f96e3c9512c7a31c10226ff3ba13a13f81b5ec8c6916c44d3376184f5cb0` |
| ZIP 내부 `config/DiceMaster.cfg` | 11,084바이트 | `efd4847eb096aad70bfb7c3399534caab6becf71daca75fc5359100b0638cbf8` |

1. 게임을 종료하고 현재 `BepInEx/plugins/DiceMaster/DiceMaster.dll`과 `BepInEx/config/DiceMaster.cfg`를 게임 폴더 밖에 백업합니다.
2. 설치 ZIP을 임시 폴더에 풀고 위 해시를 확인한 뒤 **DLL만 교체**합니다. 기존 cfg를 보존하며 전체 cfg를 덮어쓸 필요는 없습니다. 새 패드 열기 키는 기본 `true`로 바인딩합니다.
3. Tab 또는 양쪽 스틱 클릭으로 로그를 엽니다. 새 창 기본값이 필요하면 도구의 **창 위치·크기·글자 기본값 복구**를 사용합니다. 1920×1200에서 872×960px·20px입니다.
4. 패드 열기를 끄려면 종료 후 기존 `[DiceMaster]` 섹션의 `EnableGamepadLogOpen=false`로 바꾸고 재시작합니다. 문제 시 게임 종료 후 백업 DLL과 필요한 cfg를 복원합니다. 공개 [alpha.5](https://github.com/jungpaeng/dicemaster/releases/tag/v1.0.5-alpha.5) 또는 정식 [v1.0.4](https://github.com/jungpaeng/dicemaster/releases/tag/v1.0.4)로도 복구할 수 있으며 새 패드 열기는 제공하지 않습니다.

```powershell
Get-FileHash .\DiceMaster-v1.0.5-alpha.6.zip -Algorithm SHA256
Get-FileHash .\plugins\DiceMaster\DiceMaster.dll -Algorithm SHA256
```

## 게시 검증 상태

로컬 검토 후보는 2026-10-19 06:14:54 KST에 생성했으며 위 해시·12개 검사는 그 후보의 결과입니다.
그 뒤 게시 검증기의 필수 검사 목록을 12개로 보완하고 검증기 회귀 8개를 통과했습니다. 생산 소스 입력 63개는 그대로이고 빌드 도구 2개의 해시만 달라졌으므로, 앞의 입력 153개 영수증은 생성 당시 스냅샷으로 보존하고 최종 입력 근거는 고정 커밋 재빌드 manifest를 사용합니다.
사용자의 커밋·prerelease 지시에 따라 고정 구현 커밋을 재빌드하고 `artifacts/releases/v1.0.5-alpha.6/`에 검증 결과를 분리합니다.
**고정 커밋 재빌드·태그·실제 GitHub 게시와 인증 없는 공개 페이지/ZIP 검증은 현재 준비 단계입니다.** 완료 후 실제 커밋·게시 시각·Release/asset 식별과 검증 영수증을 추가합니다.
기존 Release·태그·자산과 Latest 정식 v1.0.4를 보존하고 이슈 #4는 닫지 않습니다.
