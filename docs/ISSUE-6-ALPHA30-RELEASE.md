## 변경과 지원 범위

새 게임에서는 보이지만 게임 프로세스를 종료하고 저장된 지도로 바로 들어오면 흰색 대화 배지가 빠질 수 있는 자료 준비 차이를 보완했다. 현재 스토리 관리자가 없을 때 이미 로드된 조건·분기·이벤트 풀 설정과 실제 대화 초기화 목록을 읽는다. 현재 유효한 관리자가 있으면 우선하며 손상된 현재 자료를 다른 자료로 우회하지 않는다.

실제 해금·완료·반복 활동·확정 false 조건과 금색 기회/1회성 기준을 유지한다. 설정 자산이 없거나 충돌하면 미확정이며 owner 없는 횟수형 분기는 현재 실행 횟수를 추측하지 않는다. 모든 세이브에서 표시를 보장하지 않는다. [원인·구현·제약·측정](ISSUE-6-COLD-MAP-LOAD.md).

정상0.25초/실패5초, 준비 후 Lua 재읽기/재분석 없음, 숨김/게임 창 가림/OFF 조회 중단과 읽기 전용을 유지한다. 로드된 정의 참조는 재사용하고 현재 값은 새로 읽는다. 새 게임/로드/장면/OFF/종료에서 캐시를 정리한다. 새 키·기본값·cfg 바이트 변화는 없다. Xbox/XInput·키보드·마우스·터치·입력 소유권/해제/중립, #5 이벤트 선택·예약·로그 네 탭·주사위·상점·실제 분기 회귀를 포함한다.

## 자동 검증

검토 후보는 전체21개 검사·294개 빌드 입력·118개 소스/리소스·16개 고정 게임 참조를 확인했다. MapGuideRouteIntegrationTests3688개·InformationRuntimeTests5931개·ChoiceStoryTests7719개·MapRouteTests6884개·UI5454개·Gamepad262831개를 포함한다. 설치 ZIP 두 경로·CRC·내부 DLL/cfg 바이트도 확인했다. 배포 검증기 회귀20개도 통과했다. 고정 커밋 재빌드·후보 동일성·공개 다운로드 결과는 게시 후 보충한다.

owner 없는 합성 지도500회 warm 조회에서 배지1개를 유지하고 native 경계 검색0회·Lua 읽기0회·게임 실행/State 쓰기0회를 확인했다. p95 0.016125ms·최대0.087208ms·할당9000B/회다. .NET8/macOS 관리 경계이며 native Unity 검색은 fixture다. 8/32/64장소 warm 측정도 안내와 Lua 추가 읽기0을 유지했다. 실제 최초 검색 시간·Windows FPS/GC 확인은 대기다. native 동기 검색은 협력식 예산으로 중간 취소할 수 없다.
