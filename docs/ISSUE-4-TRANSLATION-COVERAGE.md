# PRD #4 후속: 한국어 표시 경로 통일

2026-10-19 KST. 사용자가 [앞선 번역 감사](../artifacts/issue-4/translation-audit/audit.json)에서 발견한 누락 가능 경로 전체에 표시 번역 적용을 요청했다. 이전 감사는 원인 확인 당시 기록으로 보존한다. 이번 후보는 [정상 조회 문구 생략](ISSUE-4-STATUS-LABELS.md)과 [시간 제한 없는 L3/R3 겹침 열기](ISSUE-4-PAD-OVERLAP.md)를 포함한다.

## 적용 범위와 보존 경계

| 영역 | 적용 |
| --- | --- |
| 조건·이벤트·미션 목록과 상세 | 실제 이름은 같은 `Display.TranslateLabel` 변환을 사용. `P_大成功_n`, `P_大失敗_n`, `P_成功_n`, `P_失敗_n`, `P_正常_n`, `P_特殊_n`, `P_其他_n`을 각각 대성공·대실패·성공·실패·일반·특수·기타로 표시 |
| 선택지 제목 | 실제 선택 문장 우선순위와 제목 fallback을 유지하며 같은 표시 변환 적용 |
| 이벤트 이름 캐시 | 저장한 표시 키를 반환할 때 최종 표시 번역. 목록과 게임 기본 서술 로그의 이벤트명에 함께 적용 |
| 게임 기본 서술 로그 | `UiTextMapper.ApplyTranslations` 뒤 표시 변환을 적용한 문자열을 기존 서술 로그에 전달 |
| 게임 선택지의 효과 요약 | 같은 변환 뒤 기존 태그 제거·한 줄화·50자와 말줄임 정책 적용 |
| 미번역 진단 | 공통 `TranslateLabel` 경계에서 중복 억제된 기존 진단을 수행. 버튼 제목도 진단 경로에 연결 |
| 이스케이프 등호 번역 항목 | 홀수 개 역슬래시로 이스케이프한 `\=`를 원문/번역 구분자로 취급하지 않으며 전체 원문·번역을 적재 |

번역은 표시용 문자열에만 적용한다. `LogItem.Id`, `RawId`, 게임 데이터 이름·스크립트 키, 원본 객체와 예약 target/context/tab/id는 그대로다. `원본 ID:` 줄과 비활성 안내 행에 붙는 원본 ID를 번역하지 않는다. 표시 이름이 없어 원본 ID로 대신 보여줄 때도 같은 원칙을 적용한다. 목록 버튼 전체 문구를 한꺼번에 번역하지 않는다.

이름의 최종 변환 뒤에는 제목을 다시 번역하지 않고 출력해 원본 ID fallback의 이중 번역을 막는다. 기존 본문·조건 분기·상태 문구는 기존 표시 번역 경로를 유지한다. 정상 시 `조회 정상`을 생략한 변경과 실패·대기·이전 값·예약 보호도 유지한다.

## 번역 파일의 전체 문장 매칭

`ModTranslation.txt` 164행은 원문 안의 `\=`를 첫 등호 구분자가 잘못 잘라 원문·번역이 모두 깨지는 항목이었다. 첫 번째 **이스케이프하지 않은 등호**를 구분자로 사용한다. 기존 원문/번역의 literal escape 형태와 개행 형태를 유지하면서 실제 등호·역슬래시·개행 복원 형태도 등록한다. 중복 키는 기존의 먼저 등록한 값 우선 정책을 유지한다.

이 행을 올바르게 읽기만 하면 `Display.PreTranslate`가 문장 앞부분을 먼저 번역해 전체 키 매칭이 다시 실패한다. 이스케이프 등호 항목에 한해 그 중간 표기의 별칭도 등록한다. 기존 주 번역 사전 우선순위와 일반 항목의 처리 순서를 바꾸지 않는다. 실제 번역 호출에서 한글과 중국어가 섞이지 않는 완전한 문장으로 나오는지 검사한다.

이미 고정된 내장 리소스 8개와 게임 참조는 수정하지 않는다. 게임 소스·DLL을 저장소·설치 ZIP에 추가하지 않는다. 사전에 없는 신규 게임 문구까지 번역됐다고 보장하지 않으며, 그런 문구는 기존 원문 보존·미번역 진단 정책을 따른다.

## 적용·복구

게임을 종료하고 현재 DLL과 cfg를 게임 폴더 밖에 백업한다. 새 ZIP에서 `plugins/DiceMaster/DiceMaster.dll`만 꺼내 `BepInEx/plugins/DiceMaster/DiceMaster.dll`로 교체한다. 기존 `BepInEx/config/DiceMaster.cfg`를 보존하며 설정 변경은 필요 없다.

문제 시 게임 종료 후 백업 DLL을 복원한다. [직전 status-labels 후보](ISSUE-4-STATUS-LABELS.md)로 돌아가면 이번 번역 수정 전 상태이며 정상 조회 문구 생략과 시간 제한 없는 패드 열기는 유지한다. 공개 [alpha.6](ISSUE-4-ALPHA6-RELEASE.md)으로 복구하면 기존 300ms 패드 열기와 당시 문구로 돌아간다.
