# DiceMaster v1.0.4-alpha.1 — 선택지 결과 미리보기 확장

PRD [#2](https://github.com/jungpaeng/dicemaster/issues/2)의 로컬 구현을 포함한 prerelease입니다. 사용자가 2026-10-19 KST에 commit·push와 새 prerelease 게시를 승인했습니다. 이 문서는 게시할 설명이며, 실제 게시 식별값과 공개 다운로드 검증 결과는 [구현·검증 기록](https://github.com/jungpaeng/dicemaster/blob/main/docs/ISSUE-2-IMPLEMENTATION.md)에 별도로 남깁니다. 정식 최신 버전은 [v1.0.3](https://github.com/jungpaeng/dicemaster/releases/tag/v1.0.3)으로 유지합니다.

## 변경 사항

- 선택지 효과를 문자열·주석·괄호·명령 순서·조건 분기·출처를 보존하며 분석합니다. 일부 미지원, 전체 미지원, 확인된 효과 없음, 실제 읽기 실패를 구분해 선택지 요약과 로그에 함께 표시합니다.
- StatModifyManager 16개와 LuaManager 12개 함수를 추가하고 직접 설정·가산·제거·기술·장비·시간·미션 시간의 실제 의미를 구분합니다. 숫자 상수의 사칙연산·괄호·단항 부호를 지원하며 정수로 안전하게 변환할 수 없는 식은 미지원으로 남깁니다.
- `center`·`mental`은 현재 상태와 선행 효과를 안전하게 해석할 수 있을 때 예상 변경량을 표시합니다. 조건·실행 순서·상태가 불확실하면 수치를 확정하지 않고 효과의 의미를 설명합니다.
- 리터럴 `SetNextScript` 대상을 여러 단계 읽어 다음 사용자 선택 전까지 추적합니다. 등록은 즉시 실행으로 취급하지 않으며 후속 효과에는 `후속 스크립트`·`조건부`를 표시합니다. 덮어쓰기·동적 흐름·순환·읽기 실패·한도 초과를 구분합니다.
- 요약 50자·로그 전체 설명, 미지원 최초 진단, 실제 실패의 5초 재시도·수동 복구, 문맥 캐시와 기존 로그·독립 난수·수명주기·주사위·패드 계약을 유지합니다. 전체 소스 빌드와 기존 injector에 같은 분석 구현을 연결합니다.

표시를 위해 게임 Lua, 게임 상태 변경 API, 게임 RNG, 원래 조건 실행 사슬을 실행하지 않습니다. 전체 Lua 원문·인자 원문·세이브 내용은 새 진단 로그에 남기지 않습니다. 설정·세이브 형식과 네 탭을 유지하며 새 설정·통신·계정·영구 저장을 추가하지 않습니다.

## 검사와 미확인 범위

검사에는 실제 후보 DLL의 관리 IL과 읽기 경계 대역을 사용했습니다. 실제 게임 실행 결과와 구분합니다.

- 새 미리보기 통합 373개, 기존 파서·로그·선택지 통합 134개 단언 통과.
- 실제 게임 조회 IL의 관리 동작 3,914개와 메타데이터 계약 1,021개 단언 통과.
- 소스/교차 최종 DLL의 패드 계약 525,430개와 최신 HEAD 기준 번역·주사위 비교 4,341개 단언 통과.
- 기존 injector의 최초·반복·패드 교차 검사, 리소스 보존, ZIP CRC·두 파일·소스 빌드 DLL/설정 바이트 일치 검사 통과.

실제 Lua 리소스가 아직 없어 선택지·후속 연결·로더 식별 규칙과 최종 추적 한도를 실제 자료로 대조하지 못했습니다. 현재 개발 안전 한도는 루트 0 기준 후속 깊이 **8**, 루트 포함 고유 스크립트 **32개**, 누적 원문 **UTF-16 262,144자**, 누적 토큰 **65,536개**, 결정적 순회 작업 **131,072회**, 구문 분기 중첩 **64단계**입니다. 산술은 재귀 **128단계**, 중간 절댓값 **2^53−1 이하**로 제한합니다. 경계 검사는 통과했으나 실제 Lua 분포·실게임 비용으로 검증한 최종값은 아닙니다. 한도 도달 시 이미 확인한 효과를 유지하며 미지원 이유를 표시합니다.

**이번 DLL의 Windows, Unity/native, 실제 Harmony·다른 모드·UI·게임 진행과 실제 시간·할당량 검증은 미실행입니다.** 관리 대역의 합성 측정은 실제 게임 성능 보장이 아닙니다. 과거 `v1.0.3-alpha.4`에 대한 사용자 Windows 확인을 이번 후보의 검증으로 승계하지 않습니다. 이번 게시로 게임 설치·실행·오류 주입이나 런타임 검증을 수행하거나 요청하지 않습니다.

PRD #2 전체와 기능 완료를 선언하지 않으며 이슈 #2는 open으로 유지합니다. 상세 의미·보존 검사·남은 조건은 [구현·검증 기록](https://github.com/jungpaeng/dicemaster/blob/main/docs/ISSUE-2-IMPLEMENTATION.md)과 [게임 API 의미 대조](https://github.com/jungpaeng/dicemaster/blob/main/docs/ISSUE-2-API-SEMANTICS.md)를 참조하세요.
