# v1.0.7-alpha.29 — 대화·경로 안내 배지

일반 대화·해금된 후속 경로의 툴팁을 포커스 전에도 발견하도록 아이보리 두루마리 배지를 추가한다. 기존 어두운 금색 기회 배지는 그대로 유지하고 같은 항목에는 금색 하나를 우선한다. 밝은 배지는 ‘대화/경로 안내 있음’이며 이벤트 발생·1회성·현재 실행을 보장하지 않는다. [설계·측정·구현 경계](ISSUE-6-GUIDANCE-BADGES.md).

## 사용자 변화·설정·성능

지도는 장소를 하나도 포커스하지 않아도 보이는 미선택 장소를 순환 준비한다. 포커스한 장소가 있으면 먼저 처리하며, 선택 메뉴는 실제 현재 활성 선택지의 기존 안내 결과를 사용한다. 확인한 항목에 미리 배지를 붙이고 패드/키보드 포커스 또는 마우스 호버 옆에 설명 하나를 표시한다. 기존 A/Enter/클릭/터치와 Xbox/XInput 입력 소유권·해제/중립 보호는 유지한다.

잠김·해금 미확정·완료 대화·고정 반복 활동과 안전하게 확정한 거짓 조건은 이전처럼 제외한다. 한 화면의 준비 예산을 공유해 초기 표시는 순차적으로 나타난다. 조건 정의 이름 색인만 같은 갱신에서 공유하고 현재 값은 새로 읽는다. 정상0.25초/실패5초·warm Lua 재읽기/재분석 없음·창 가림/숨김/OFF·읽기 전용을 유지한다.

EnableMapGuide가 밝은 배지/배경 준비를 함께 제어한다. 설정 키·기본값·저장 값은 바꾸지 않으며 패키지 cfg 설명 주석만 변경했다. DLL만 업데이트해 기존 cfg를 보존한다.

macOS 관리 코드/합성 게임 경계의 8/32/64장소 측정에서 warm p95 약0.08–1.83ms·Lua 추가 읽기0을 관측했다. 이전 버전은 미선택 일반 경로를 준비하지 않으므로 같은 출력의 성능 대결은 아니다. 최초 준비·JIT 비용과 장소 수에 따른 할당/초기 지연이 늘며 실제 Windows FPS를 보장하지 않는다. 측정 도구·환경·원자료·이전 대비 비용은 설계 문서에 기록했다.

## 설치와 실제 Windows 확인

활협전용 BepInEx 모드 베이스가 필요하다. 게임 종료 후 DLL/cfg를 백업하고 설치 ZIP의 plugins/DiceMaster/DiceMaster.dll만 교체해 기존 cfg를 보존한다. 최초 설치는 config·plugins를 모드 베이스 아래에 넣는다. 문제 시 종료 후 백업 DLL과 필요한 cfg를 복원한다. GitHub 자동 Source code는 설치용이 아니다.

아무 장소도 포커스하지 않은 지도에서 밝은 배지가 순차적으로 나타나는지, 남제자방→사사형의 초회 인사/실제 해금 주제와 유학 활성 선택지의 안내, 금색 우선·완료/잠김 제거·행동력/임무 우선·창/로드/OFF/ON·기존 입력을 확인한다. 최초/warm 지연·가독성·FPS/GC와 읽기 전용 경계는 실제 Windows에서 별도로 확인해야 한다. [새 확인표](ISSUE-6-WINDOWS-VALIDATION.md#alpha29--밝은-안내-배지-확인-대기).

새 DLL의 Windows·물리 입력·프레임 확인과 #6 전체 완료는 대기다. 기존 Latest v1.0.6·이전 Release/태그/자산과 #6 open을 보존한다. 검토/측정 기록은 artifacts/issue-6/guidance-badges/, 고정 소스·게시·익명 검증 영수증은 artifacts/releases/v1.0.7-alpha.29/에 구분한다.
