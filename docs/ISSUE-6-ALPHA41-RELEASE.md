# v1.0.7-alpha.41 — 지도 안내 준비·반복 조회 개선

## 사용자 변화와 범위

동일한 정보의 로그 재발행을 생략하고, SHA-256으로 검증한 순수 설치 정의를 재사용하면서 현재 세이브의 참조만 필요한 부분에 연결한다. 짧은 이야기 경로는 최대 네 번의 조회까지 이어 준비한 뒤 다른 장소에 순서를 넘겨 첫 마커의 대기를 줄인다. 정상 0.25초·실패 5초·공유 준비 예산·원문 읽기 상한·현재 상태 재검증·숨김/OFF 중단과 기존 입력 보호를 유지한다.

alpha.39·40의 주사위 자동 이야기 마커·요약은 main의 네 revert 커밋으로 제거된 상태를 포함한다. 기존 주사위 값 지정·효과 조회·실제 분기 기록과 지도/선택지 배지는 유지한다. 이전 태그/Release/자산은 삭제하거나 덮어쓰지 않는다.

## 자동 측정과 한계

macOS .NET8 관리 경계/실제 설치 파일의 참고 측정이다. Unity/게임 Lua/Windows FPS를 실행한 결과가 아니다. 정상 갱신 간격을 늘리지 않았다.

| 항목 | 기준 | 변경 |
| --- | ---: | ---: |
| 동일 상점 2,000회 조회의 재발행 | 2,000회 | 0회 |
| 상점 틱당 할당량 | 3,224 B | 2,656 B |
| 지도 틱당 할당량 | 5,392 B | 4,616 B |
| 설치 정의 재준비 | 46.34ms / 15.61MB | 30.74ms / 1.72MB |
| 64곳·3단계 경로 첫 마커 | 129번째 조회 | 3번째 조회 |
| 같은 사례의 전체 마커 | 192번째 조회 | 192번째 조회 |

54개 마커 사례의 최종 이름·종류·상태·자동 문구·기회/경로 비트가 SHA-256으로 기준과 일치했다. 준비 후 원문 추가 읽기는 0회, cold 원문 읽기는 조회당 최대 1회다. 효과가 일관되지 않은 필드 캐시와 추가 노드 분류는 최종에서 제외했다.

**최초에 17,829개 정의를 모두 강제로 조회하는 검사에서는 59.79→75.47ms, 17.86→26.11MB로 증가했다.** 정의 재사용은 현재 지도처럼 필요한 일부를 읽고 같은 설치 자료를 다시 준비하는 경로에 적용한다. 전체 일괄 조회·전체 상주 메모리·실게임 FPS의 보편적 개선으로 확대하지 않는다.

## 검토 후보·고정 커밋 검증

검토 후보의 21개 검사 프로그램과 실제 설치 파일/원문 경계 회귀가 통과했다. 고정 참조 16개와 사용자 게임 복제본을 연결한 API 검사, ZIP의 두 경로/CRC/내부 바이트를 대조했다. 새 DLL의 실제 Windows/Unity/Harmony·사용자 세이브·물리 입력 실행은 미실행이다.

빌드 입력은 314개, 생산 소스/리소스는 126개다. 소스 태그는 `v1.0.7-alpha.41`이며 커밋 후 그 커밋만 추출해 관리 모드 DLL 0개에서 재빌드한다. 검토 후보의 전체 입력 SHA·SDK·DLL/cfg/ZIP·21개 검사 통과를 대조하고 결과는 게시 후 아래에 확정한다. 동적 반복 검사 단언 수는 실행마다 달라질 수 있어 전체 성공 기록을 원문으로 보존한다.

## 설치·복구와 Windows 확인 대기

활협전용 BepInEx 모드 베이스가 필요하다. 게임을 종료하고 DLL/cfg를 백업한 뒤, 업데이트는 DLL만 교체해 기존 cfg를 보존한다. 최초 설치는 ZIP의 config·plugins를 BepInEx 아래에 넣는다. GitHub Source code 압축 파일은 설치용이 아니다. 문제 시 게임 종료 후 백업 DLL과 필요한 cfg를 복원한다. DLL 교체는 이미 저장한 게임 진행을 되돌리지 않는다.

- [ ] 새 게임과 게임 완전 종료 후 저장 불러오기에서 남제자방·연단방 첫 마커/스피너의 대기와 깜빡임을 확인한다.
- [ ] 초회 대화 완료·조건 변화·불러오기 뒤 마커 제거/복구와 선택지 툴팁·배지의 일치를 확인한다.
- [ ] 상태/로그 등 다른 창·OFF 뒤 복귀와 키보드·마우스·터치·Xbox/XInput 소유권·해제/중립 보호를 확인한다.
- [ ] 전체 배경 준비 시간·프레임 p95·GC 정지를 확인한다. 자동 조회 번호를 실게임 초 단위로 환산하지 않는다.
- [ ] 주사위에 자동 이야기 마커·요약이 없고 기존 값 조정·원래 효과·실제 분기 기록이 유지되는지 확인한다.

새 파일의 사용자 Windows 확인 전 #6 전체 완료나 이슈 종료로 처리하지 않는다. v1.0.6의 사용자 확인은 착수 근거이며 이 새 DLL의 확인으로 승계하지 않는다.

## 게시 준비 상태

검토 후보는 검증을 마쳤고 고정 커밋 재빌드·annotated tag/main push·새 prerelease 게시·익명 공개 ZIP 대조는 커밋 후 순서대로 진행한다. 기존 82개 Release·기존 태그/자산·Latest 정식 v1.0.6과 #5/#6 open을 보존한다. 게시 후 결과 문서는 별도 main 커밋으로 남기고 소스 태그·패키지는 바꾸지 않는다.
