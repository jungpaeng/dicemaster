## 사용자 증상과 재현

사용자는 alpha.21에서 초회 사사형 인사를 보지 않았는데도 툴팁이 없다고 보고했다. 상세에는 내부 분기 미확정·잠긴 후속 주제 `talk_brother4_option_01`의 제외 표본이 있었고, ‘진입 대화의 횟수·완료 판정을 확인하지 못함’ 문구는 없었다. ‘경로를 전부 확인하지 못했다’는 공통 설명은 준비 중뿐 아니라 분석 상한·자료 누락에도 사용되므로, 그것만으로 준비 대기나 초회 완료 오판이라고 결론 내릴 수 없다.

추가 검사에서 잠긴 후속 경로 32개가 먼저 수집되고 조건을 충족한 직접 인사가 33번째에 들어오면, 첫 32개만 조회하여 인사도 표시하지 않는 것을 재현했다. 상세에는 잠긴 후속 주제의 표본만 남고 완료 판정 불가 문구는 생기지 않았다. 사용자가 준 조합과 일치하는 누락 경로지만 사용자 Windows 세이브의 전체 경로 목록을 직접 읽은 것은 아니므로 동일 원인으로 확정하지 않는다.

## 수정과 경계

`Index`가 정의를 수집할 때 현재 원문 선택지에서 **추가 선택 없이 바로 이어지는 대사 경로**를 조회 목록 앞에 우선 배치한다. 뒤쪽 선택을 요구하는 이야기가 먼저 발견돼도 직접 인사가 기존 조회 상한 밖으로 밀리지 않게 한다. 같은 그룹 안에서는 발견 순서를 유지하며, 특정 인물·대사 ID·플래그 예외 목록이나 현재 상태에 따른 정렬은 없다.

우선 배치는 최대 32개다. 모든 원래 경로는 보존하며 공통 불가 조건은 우선 경로만이 아니라 전체 관찰 경로의 교집합으로 유지한다. 현재 상태 조회는 기존처럼 최대 32개 경로·16단계와 조건/분류 예산을 사용한다. 준비 중/모호한 메뉴 보류, 후속 선택지 해금 확인, 완료 인사 제외와 반복 활동 분류, 미확정 완료 자료 보류를 약화하지 않는다. 우선순위만으로 진행 가능·1회성·기회 마커를 부여하지 않는다.

이 방식이 모든 경로 탐지를 보장하지는 않는다. 직접 대사 자체가 수집되지 않거나 우선 경로가 상한을 넘고 조건 자료가 미지원/누락이면 표시가 생략될 수 있다. 미표시를 전체 이야기 부재로 해석하지 않는다. 상세에 전체 수집 경로 수와 ‘현재 선택 뒤 직접 대사 우선 배치’ 수(최대 32)를 추가해, 직접 후보가 수집됐는지와 표시/제외 표본을 함께 확인할 수 있게 한다. 수집된 직접 대사가 모두 개별 이야기라는 뜻은 아니며 이후 조건·활동 필터도 통과해야 한다.

## 검증·비용·보존

`tests/ChoiceStoryTests/DirectChoiceCases.cs`는 실제 공급자의 정의 등록 경계에 잠긴 후속 경로 31/32/64개를 먼저 넣고, 실제 준비된 직접 인사 경로를 나중에 등록한다. 공개 Read 결과에서 미완료 인사 표시·완료 뒤 제거·다시 미완료 전환·자료 누락 보류·패드 포커스·마커 미부여·warm 자원/파싱/횟수/게임 호출 무변경을 검사한다. 특정 설치판의 세이브를 실행한 검사와 구분한다. 기존 원본 SHA 검사·준비 중 매 갱신·무관한 파일 누락·기존 기능 검사도 유지한다.

순서 조정은 정의 준비에만 수행하고 정상 갱신이나 렌더링에서 전체 경로를 정렬/추가 분석하지 않는다. 정상 .25초/실패 5초·숨김/OFF 중단·Lua 정의 캐시·정상 주기 재분석 없음 계약과 입력 소유권/해제/중립, 이벤트/미션 예약·로그 네 탭·주사위·상점·실제 분기 기록을 유지한다. 새 설정과 cfg 변경은 없으며 게임 판정·Lua·RNG·카운터·플래그·세이브·능력치·아이템을 변경하지 않는다.
