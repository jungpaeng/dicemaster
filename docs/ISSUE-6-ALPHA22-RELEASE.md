## 변경과 한계

잠긴 후속 경로가 먼저 32개 이상 발견되면 나중에 수집된 유효한 직접 인사가 조회 상한 밖으로 밀리는 누락을 보완한다. 정의 준비에서 현재 선택 뒤 추가 선택 없이 이어지는 대사를 최대 32개 먼저 배치하고, 기존 경로 조회/조건 예산을 유지한다. 전체 관찰 경로의 공통 불가 조건은 우선 항목만으로 줄이지 않는다.

초회 인사의 미완료 표시·완료 후 제거, 반복 활동·잠긴/해금 미확정 주제 제외와 기존 대기 임무 또는 엄격한 1회성/현재 조건/경로 마커 기준을 유지한다. 우선 배치가 조건이나 마커의 새 증명은 아니다. 상세에 수집 경로 수와 직접 대사 우선 배치 수(최대 32)를 추가한다. 특정 인물/조건 예외 목록이나 게임 상태 쓰기를 추가하지 않는다.

사용자 alpha.21 로그와 같은 조합을 경로 상한 사례에서 재현했지만 사용자 Windows 세이브의 전체 후보를 읽어 동일 원인으로 확정한 것은 아니다. 직접 인사가 수집되지 않거나 조건/자료/상한을 확인할 수 없으면 표시가 생략될 수 있으며 모든 이야기 탐지를 보장하지 않는다. [설계·근거·검사](ISSUE-6-DIRECT-CHOICE-PRIORITY.md) · [새 Windows 확인표](ISSUE-6-WINDOWS-VALIDATION.md#alpha22--직접-대화-누락-확인-대기).

## 자동 검사와 파일

전체 소스 빌드의 21개 검사 프로그램·274개 입력·112개 소스/리소스·16개 고정 참조·실제 후보 DLL 연결·설치 ZIP의 두 경로/CRC/바이트 대조를 통과했다. 고정 커밋 재빌드·공개 다운로드는 별도로 기록한다. **새 DLL의 실제 Windows·물리 입력·화면·프레임 성능 확인과 #6 전체 완료는 대기다.** 선택지 집중 검사와 전체 검사에 실제 공급자의 정의 등록 경계에서 후속 31/32/64개 뒤 직접 대사가 도착하는 경우·완료 전환·자료 누락·패드 포커스·warm 캐시/카운터 무변경을 포함한다. 원본 Lua·실제 후보 IL·합성 게임 경계의 자동 검사이며 사용자 Windows 게임 실행 결과가 아니다.

## 설치와 실제 Windows 확인

게임을 종료하고 현재 DLL/cfg를 백업한 뒤 설치 ZIP의 **plugins/DiceMaster/DiceMaster.dll만 교체해 기존 cfg를 보존**한다. 최초 설치는 기존 활협전용 BepInEx 모드 베이스 아래에 config·plugins를 넣는다. 문제 시 게임 종료 후 백업 DLL/cfg를 복원한다. GitHub 자동 Source code 압축은 설치용이 아니다.

새 DLL에서 초회 인사 표시와 완료 인사/반복 대련 제외를 모두 확인해야 한다. 기존 조작·가독성·창 가림·최초/반복 프레임과 사용자 세이브의 정확한 근거 확인은 대기다. 최신 정식 v1.0.6과 #6 open을 유지한다.
