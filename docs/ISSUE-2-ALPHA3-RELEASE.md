# DiceMaster v1.0.4-alpha.3 — 미리보기 문구 정리

선택지 결과의 중복 안내를 줄인 prerelease입니다. 정식 Latest는 [v1.0.3](https://github.com/jungpaeng/dicemaster/releases/tag/v1.0.3)으로 유지합니다.

## 변경 사항

- 현재 선택에서 발생 여부가 불확실한 효과는 **가능한 변화**, 연결된 이야기의 효과는 **이후 가능한 변화** 아래에 묶습니다. 효과마다 `조건부`를 반복하거나 `이어서 진행 시`라는 별도 안내를 붙이지 않습니다.
- 같은 조건문의 갈래는 **[경우 A] / [경우 B · 그 외]**로 표시합니다. 여러 조건문이나 중첩 경로를 구분해야 할 때는 번호도 남깁니다. 중립색은 갈래 구분용이며 현재 조건의 충족 여부를 뜻하지 않습니다.
- `+5 가산` / `-3 가산`은 **+5 / -3**으로 줄입니다. 직접 지정은 **10으로 설정**처럼 구분합니다. 기능의 하위 초기화 가능성, center/mental의 의미·상태 조건과 능력치 제한은 유지합니다.
- 현재 효과와 가능한 효과가 번갈아 나오더라도 원래 순서를 유지합니다. 후속 효과의 추적·다음 사용자 선택 경계·캐시·오류 재시도와 50자 요약·로그 전체 설명 계약은 유지합니다.

표시 형태 예시입니다. 아래 수치가 실제 특정 선택지의 결과라는 뜻은 아닙니다.

```text
체력 +3

이후 가능한 변화
  [경우 A] 호감도 +5 | 체력 +3
  [경우 B · 그 외] 호감도 -3 | 체력 +10
```

같은 조건문의 실제 갈래만 묶습니다. 능력치·플래그·미션·이야기 흐름의 조건을 임의로 추론하거나 어느 갈래가 실행될지 확정하지 않습니다. 부분 미해석 안내인 `추가 영향 가능`과 전체 미해석 안내인 `결과는 진행 후 확인`은 유지합니다.

## 검사 범위

전체 소스 후보를 새로 빌드하고 다음 관리 코드 검사를 통과했습니다.

- 실제 후보 DLL 미리보기 **508단언**, 실제 파서·요약·로그 통합 **139단언**.
- 갱신 보호 **19단언**, 갱신 엔진 **16개 시나리오·70단언**, 수명주기 **4,023단언**.
- 실제 게임 관리 IL 동작 **3,914단언**, 메타데이터 계약 **1,021단언**.
- 패드 **262,715단언**, 번역·주사위 **2,170단언**.
- 기존 injector 신규·반복 적용의 미리보기·통합·관리 동작·메타데이터 검사와 내장 리소스 8개 보존.
- 설치 ZIP의 CRC·정확히 두 파일·소스 빌드 DLL/설정의 바이트·해시 일치.

**실제 Lua 대조와 이번 DLL의 Windows·Unity/native·실제 게임 화면·게임 진행 검증은 미완료입니다.** 과거 사용자 Windows 확인을 이번 DLL에 승계하지 않습니다. 이번 작업은 문구 정리이며 PRD #2 전체나 기능 완료를 선언하지 않습니다. 이슈 #2는 open으로 유지합니다. 자세한 검사·게시 기록은 [구현 기록](https://github.com/jungpaeng/dicemaster/blob/main/docs/ISSUE-2-IMPLEMENTATION.md)에 구분합니다.

표시를 위해 게임 Lua·상태 변경 API·게임 RNG·원래 조건 실행 사슬을 실행하지 않습니다. 전체 Lua 원문·세이브를 진단 로그에 남기지 않습니다. 설정·세이브 형식과 기존 로그·난수·수명주기·주사위·패드 계약은 유지합니다.
