## alpha.2 소스 변경

- 난수 참조를 일반 조회 오류와 구분해 안전한 범위와 `실행 시 판정`을 표시합니다. 지원할 수 없는 형태는 `난수 조건 · 미리보기 미지원`으로 구분합니다.
- 게임 RNG를 호출하거나 샘플·임의 정수·bool을 만들지 않습니다. 같은 행의 고정 설명과 확정값은 가능한 범위에서 유지합니다.
- `Sum`의 직접 난수 1개(`L ≤ U < int.MaxValue`)와 `Sum`의 직접 정수 상수 1개의 단일 비교에만 여섯 연산자·좌우 순서를 지원해 `균등 정수 기준 이론 확률 N/D`를 제공합니다. 복합 AND/OR의 전체 확률·여러/중복/중첩 난수에는 확률을 계산하지 않습니다. 실제 native 분포·다음 판정·이벤트 발동 확률의 측정값이 아닙니다.
- 실제 조회 오류의 이전 값·5초 재시도·복구 로그와 문맥 차단·공유 파서·입력 계약은 보존하고 별도 회귀 검사합니다.

실제 조회 오류는 보호된 로그 엔진의 기존 5초 재시도로 전달하고, 보호 깊이 0의 내러티브 설명 오류는 `읽기 실패` 텍스트·중복 억제/복구 로그로 처리합니다. 설명 오류가 원래 게임 진행 호출을 중단하지 않게 하며 이벤트 설명의 진입 보호 깊이는 `finally`에서 복원합니다.

구현 범위와 제외 조건은 [난수 미리보기 후속 구현](RANDOM-PREVIEW-FOLLOWUP.md), 현재 확인 상태는 [검증 기록](ISSUE-1-VALIDATION.md)을 따릅니다.

### alpha.1 개발 후보 변경

v1.0.2에서 공유 Lua 분석 결과를 비우면서 파싱 완료 표시를 남기던 표시 갱신 경로를 분리했습니다. 실제 파서·분석 캐시·표시·선택지 옆 요약을 연결하는 회귀 검사와 별도의 이벤트 고정 설명 파서를 유지합니다.

- 열린 현재 탭의 정상 행만 0.25초 간격으로 평가합니다. 실패 행은 현재 탭이 보일 때 5초 간격으로 재시도하며 재열기·탭 전환으로 대기를 초기화하지 않습니다.
- `게임 데이터 대기 중`, `읽기 실패`, 마지막 정상 값과 `갱신 실패 · 이전 값`으로 상태를 구분합니다. 준비된 문맥의 수동 새로고침은 고정 분석을 다시 만들고 실패 대기를 건너뜁니다.
- 실제 API 분석에서 확인한 게임 RNG 진입과 조건 실행 카운터 증가를 피하도록 알려진 모드 설명 호출을 읽기 전용 평가로 연결합니다. 실제 17개 값 종류를 다루며 난수 조건은 샘플링·임의 값 생성 없이 해당 행의 실패/이전 값으로 처리합니다. 미지원 enum·변환 타입·순환 자료도 거부합니다.
- `ConditionResultItem`의 null 목록은 실패, 정상 빈 목록은 false로 구분합니다. 내러티브 중 보호 깊이 0에서 생성하는 모드 설명에도 순수 평가를 적용하며 원본 게임 어셈블리·실제 게임 진행 코드를 교체하지 않습니다.
- 실제 `SaveSystem`의 새 게임·로드 6개 함수와 공통 씬 시작 경계에서 이전 문맥을 지우고, non-null 결과로 성공한 새 Lua 컴파일까지 조회를 차단합니다. void 로드 반환·씬 코루틴 생성은 준비 완료로 취급하지 않습니다. 새 Lua가 없는 제자리 복원은 다음 실제 성공 Lua까지 대기할 수 있습니다.
- 기존 BepInEx 로그에 같은 세션·항목·원인의 실패 최초 1회와 복구 1회를 남깁니다. 전체 Lua·세이브와 예외 메시지 전체를 기록하지 않습니다.

기존 `EnableOptionInfo`, 네 탭, 주사위·패드·번역·선택지 요약 계약을 보존하는 것이 범위입니다. 새 설정은 추가하지 않습니다. 난수 자료의 현재 결과를 확정해서 보여 주는 기능은 제공하지 않습니다.

### alpha.1 검증 상태와 남은 조건

읽기 전용 수신 자료 159/159개 파일의 크기·해시 일치와 ZIP CRC·경로 검사를 확인했습니다. 기존 파일·로그의 식별값은 Steam appid `1859910` / buildid `26021712`, Unity `2020.3.49f1`, BepInEx `6.0.0-be.692`입니다. 설치 모드 메타데이터는 DiceMaster `1.0.0`이나 해시는 저장소 `e7d6dfe` 기준 DLL과 같습니다. 새 Windows 실행 결과는 아닙니다.

실제 관리 DLL의 메서드·하위 호출과 새 게임·로드 경계를 정적 분석했습니다. 최종 로컬 후보는 패드→로그 재적용·반복 패치를 포함한 자동 검사를 통과했습니다.

다음은 계속 미실행이며 기능 완료·정식 Release 공개의 차단 조건입니다. 이번 승인된 prerelease에는 이 제한을 명시합니다.

- 실제 Unity/native `AnimationCurve` 등의 실행과 게임 리소스·Lua·세이브에 대한 동작
- 런타임 Harmony 적용, 다른 모드와의 상호작용, 새 게임·로드·제자리 복원·실제 UI와 진행
- 사용자 Windows 검증과 실제 게임의 시간·할당량 측정

macOS 독립 표시 엔진 벤치마크는 실제 파서·리플렉션·새 순수 평가·수명주기·Unity·게임을 포함하지 않습니다. 실제 게임 성능 검증으로 기재하지 않습니다. 향후 실행 검증은 별도 승인 전에는 요청하거나 수행하지 않습니다.

v1.0.2로 롤백하면 선택지 결과 소실 문제가 다시 나타날 수 있고 v1.0.1에는 자동 로그 갱신이 없습니다. 실제 업데이트·롤백 확인은 미승인·미실행 상태입니다.
