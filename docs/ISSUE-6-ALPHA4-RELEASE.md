# v1.0.7-alpha.4 — 짧은 상점 효과·가벼운 지도 안내

## 사용자 피드백과 원인

사용자는 상점의 학습 효과·조건 표시를 확인했으나 긴 글이 잘리고, 지도 안내가 나타나는 화면에서 게임이 크게 느려지며 안내의 뜻을 이해하기 어렵고, 거의 모든 선택지에 `1회성 확인 불가`가 붙는다고 보고했다. 설치한 DLL 해시·게임/로더 버전·장치·프레임 측정값은 별도로 제공하지 않았다. 이 부분 확인을 PRD #6 전체 또는 새 후보의 Windows 확인으로 확대하지 않는다.

- 상점은 짧은 요약용 `AutoText`에 조건·소모·학습점·주의 문단까지 넣어 원래 설명 영역을 넘었다. 비교한 조활 시스템 0.3.33, 소스 `b6edf70a90f9cd7b84ca0ccbd6db0aa94ea4c8c2`의 책 표시는 관련 능력치 현재/만렙 수치와 중복 제거한 성장 방향만 덧붙인다. 상점 전용 스크롤·자동 높이 조절은 없다.
- 지도는 자동 안내만 보일 때도 전체 이벤트의 조건 설명·결과 분석·1회성 증명을 준비하고 상세 목록을 다시 만들었다. 기존 Lua 캐시가 있어 정상 주기의 원문 재분석은 없지만, 새 결과 루트 하나의 동기 분석과 반복 판정·문자열 구성이 남아 있었다. Windows 프로파일 없이 비용별 실제 프레임 기여도를 확정하지 않는다.
- 일반 선택지 버튼에는 안전하게 연결할 원래 활성 조건이 없어 판별이 Unknown인데, 캐시된 Unknown 상태를 자동 제목에 그대로 붙였다. 미확인을 반복 가능으로 바꾸지 않고 표시 위치를 분리한다.

## 변경된 화면과 조회

상점에는 효과 항목을 한 줄로 짧게 붙인다. 책·비급은 관련 능력치의 현재/만렙 수치와 중복 제거한 성장 방향을 표시한다. 소모품은 사용 효과와 필요한 짧은 조건부·가능성 표지만 표시한다. 항목 단위로 길이를 제한하고 남은 것은 `외 N개`로 알리며 수치 중간을 잘라내지 않는다. 학습 조건·소모·필요 학습점·다음 단계의 실제 정적 변화와 해석 한계는 **로그 → 도구 → 상점 효과 조회**에 남긴다. 원래 설명 보존과 OFF·닫기·선택 변경의 소유 문구 복원을 유지한다.

지도 패널은 `선택 장소: …` 아래 최대 세 개의 이름·종류·상태를 표시한다. `진행 가능`은 기존 대기 임무의 현재 진행 상태, `발생 조건 충족`은 현재 단계 조건이 충족됐지만 아직 대기 등록을 확인하지 못한 임무다. 차단 또는 불명은 `지금 진행 불가`·`진행 여부 확인 필요`로 구분한다. 작은 화면에서는 실제 텍스트 높이를 측정해 항목을 통째로 줄이고 상세 조회 안내를 보존한다. 원시 경로 진단과 혼합 집계는 자동 화면에서 제외하고, 전체 이름·나머지 항목·장소 무관 임무·조건·효과는 **로그 → 도구 → 지도 안내 조회**에서 읽는다. 자동 패널의 글자 크기는 12~24이며 로그 본문의 글자 설정은 유지한다.

선택지·이벤트 제목에는 안전하게 증명한 `1회성`만 붙인다. 미확인·실패 이유는 로그 본문 또는 선택한 이벤트 팝업의 스크롤 상세에서 읽는다. 표식 없음은 반복 가능이라는 뜻이 아니다. 미독·영구 유일 기회·미래 재활성화 불가까지 증명하는 기능으로 확대하지 않는다.

## 갱신 비용과 유지 계약

지도 자동 조회와 명시적 지도 상세 조회를 구분한다. 상세 진입은 다른 표시 문맥으로 즉시 새로 읽으며, 닫으면 가벼운 자동 조회로 돌아온다. 자동 조회에서는 전체 조건 설명과 긴 결과 분석을 하지 않는다. 작은 선형 결과만 제한적으로 준비하고, 복잡한 결과는 명시적 상세 조회에서 분석한 증명을 재사용한다. 동일 조회의 경로 조건을 공유하고, 같은 결과·활성 조건 정의의 1회성 증명은 재평가하지 않는다. 공급 게임의 조건은 직렬화된 정의이며 현재 플래그값은 증명 캐시의 입력이 아니다. 결과·조건 참조 교체와 기존 Lua/지도 수명 경계에서 캐시를 무효화한다. 판별 실패는 성공 캐시로 굳히지 않는다.

자동 조회는 신규 리소스와 신규 풀 준비를 각각 한 번으로 제한한다. 작은 증명 후보는 8KiB·256토큰 이하의 허용된 선형 호출, 조회당 최대 네 개 정의 검사와 새 결과 분석 한 개로 제한한다. 현재 이벤트/비대기 임무는 각각 대표 16개까지, 자동 현재 조건 그래프는 128개 발생 노드·목록 32개·가중치 조건 16개 범위에서 읽는다. 상한에 걸린 항목을 진행 가능으로 추측하지 않고 명시적 상세 조회로 넘긴다.

정상 0.25초·실패 5초·숨김/OFF 조회 중단·정상 주기 Lua 재분석 없음, 게임 RNG/판정/세이브/아이템/능력치 불변을 유지한다. 기존 #5 이벤트 선택·로그 네 탭·예약·분기 5초/20건·주사위와 키보드·마우스·터치·Windows Xbox/XInput 입력 소유권·해제/중립 보호를 보존한다. 네 개별 bool 키와 기본 ON, 상위 `EnableOptionInfo`의 시작 시 적용 규칙도 유지한다. 기존 cfg를 덮어쓸 필요가 없다.

지도 전체를 실시간으로 완전 해석하지 않는다. 복잡한 경로와 큰 결과는 자동 안내에서 표식이 없을 수 있고, 전체 조건·결과 분석의 동기 비용은 명시적 상세 조회에 남는다. 자동 검사에서 작업량 감소를 확인해도 실제 Windows 프레임 개선이나 모든 환경의 렉 해소를 보장하지 않는다.

## 설치와 실제 Windows 확인

게임을 종료하고 DLL·cfg를 백업한다. 업데이트는 설치 ZIP의 `plugins/DiceMaster/DiceMaster.dll`만 교체해 기존 cfg를 보존한다. 최초 설치는 BepInEx 아래에 ZIP의 config·plugins 두 경로를 넣는다. 문제 시 게임 종료 후 백업 DLL과 필요한 cfg를 복원한다. DLL 복원은 이미 진행·저장한 게임 상태를 되돌리지 않는다.

- [ ] 같은 책·비급에서 짧은 현재/만렙 수치·성장 방향이 잘리지 않고, 조건·소모·학습점은 상점 효과 로그의 스크롤 상세에서 읽힌다.
- [ ] 사탕수수 등 사용품이 짧은 효과로 표시되고 조건부·무작위·가능성 표지가 사라져 확정 효과로 오해되지 않는다.
- [ ] 같은 지도·장소에서 자동 오버레이 표시 전후의 체감 속도를 비교한다. 최초 선택·다른 장소 이동·재방문·지도 로그 열기/닫기를 구분하고, 렉이 남으면 장소·상황과 설치 DLL 해시를 기록한다.
- [ ] 선택 장소명·임무명과 현재 진행 상태를 이해할 수 있고, 조건 충족 후보를 이미 발생한 임무로 오해하지 않는다. 긴 목록은 세 항목과 나머지 안내로 읽힌다.
- [ ] 일반 선택지에 `1회성 확인 불가`가 붙지 않으며, 확인된 양성 표식은 유지된다. 미확인·실패 이유는 선택지 로그/선택 이벤트 상세에서 읽힌다.
- [ ] Xbox/XInput만으로 로그 열기·도구 선택·항목 이동·상세 스크롤·복귀가 가능하고 입력이 뒤의 게임에 재사용되지 않는다.
- [ ] 네 기능 OFF/ON·상위 설정·로드/장면·실패 재시도·기존 이벤트 선택/로그/예약/분기/주사위가 유지된다.

새 후보의 사용자 Windows 확인과 PRD #6 전체 수용은 대기다. 이 문서의 수정·자동 검사·게시만으로 이슈를 종료하지 않는다.
