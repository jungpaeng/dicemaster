# 지도 배지 크기·원래 게임 창 가림 수정 후보

2026-10-21 사용자 제공 1920×1200 지도/상태 창 화면에서 작은 금색 핀과 상태 창 위에 남는 핀을 확인했다. 현재 main 작업 폴더의 미게시 수정이다. 공개 alpha.17의 태그·릴리스·파일 해시는 변경하지 않는다.

## 원인과 변경

기존 배지는 로그 글자 크기에서 20–28px로 계산해 큰 화면에서도 작았다. 이제 로그 글자 설정과 분리하고 1920×1080을 기준으로 화면 가로/세로 비율 중 작은 비율에 맞춘다. 지도는 기준 40px(28–64px), 선택 메뉴는 기준 32px(24–48px)이며 1920×1200에서도 각각 40/32px다. 4K에서는 64/48px로 제한해 원본 아이콘 해상도/메뉴 공간을 넘지 않는다. 같은 확대 크기를 실제 그리기·호버 영역·설명창 회피에 사용한다. 금색 테두리·바탕·두루마리 이미지와 지도 핀/메뉴 모서리 구조는 유지한다. 새 설정이나 단축키는 추가하지 않는다.

기존에는 활성 지도 컨트롤과 모드 로그/팝업/현재 메뉴만 확인해, 게임 상태 창 뒤에서 살아 있는 지도 객체의 표식을 계속 그렸다. InformationVisibility는 게임의 기존 FreeManager/StoryManager 인스턴스와 현재 창 상태만 읽는다. FreeManager의 _menuOpen/_statOpen/_saveOpen 및 StoryManager의 _panelOpen/_menuOpen/_statusOpen/_logOpen 중 열림이 있으면 지도·선택 안내의 배지와 설명을 숨긴다. Update의 조회 경계와 OnGUI의 표시 경계에서 각각 확인하므로 이전 게시 스냅샷도 다른 게임 창 위에 그리지 않는다.

지도 컨트롤은 자기 FreeManager의 EnableHotKey/IsProcessing도 읽어 준비·진행 중/창이 막은 상태에서는 가시성이 없는 것으로 처리한다. 이 지도 준비 조건을 선택 메뉴 전체에 대입하지 않으므로 지도의 행동 진행 중 생긴 정상 선택 메뉴는 허용한다. 비활성 이전 장면의 인스턴스는 무시하고, 확인할 필드가 없거나 읽기가 실패하면 안내를 숨긴다.

## 읽기 전용·성능·입력

창 상태는 고정 두 인스턴스·최대 일곱 bool 필드만 확인하며 메타데이터는 처음 한 번 구한다. Instance getter를 호출해 객체를 생성하거나 씬 전체 탐색/레이캐스트를 하지 않는다. 원래 창 열기/닫기·시간 배율·게임 선택 상태·게임 판정/RNG/세이브/능력치/아이템에 쓰지 않는다. 게임의 창과 입력 상태가 그대로 표시 권한의 근거다.

가려진 동안 지도/선택 경로/전체 표식 및 자동 1회성 선택 조회를 멈춘다. 창을 닫으면 기존 RefreshEngine의 숨김→표시 경계에서 현재 자료를 다시 읽는다. 정상 0.25초·실패 5초·캐시·미선택 장소의 새 Lua 분석 없음·정상 주기 재분석 없음·개별 OFF·상위 설정 계약을 유지한다. 관련 두 기능이 OFF면 창 상태 읽기도 생략한다. 아이콘 텍스처는 기존처럼 한 번 업로드해 재사용한다.

기존 실제 실행 분기의 5초 알림/최근 20건과 상점 요약은 그대로다. 게임 창을 감지해 새 포커스/클릭 대상을 만들거나 입력을 소비하지 않는다. 패드/키보드 포커스와 움직인 마우스 호버, 정지 포인터 소유권, L3/R3·해제/중립·Y 상세·오른쪽 스틱·B 복귀와 이벤트/예약/네 로그 탭/주사위를 유지한다.

## 근거·검증과 설치

원래 게임의 고정 참조 DLL IL에서 FreeManager의 OnPanelOpen/OnPanelClose가 EnableHotKey를 false/true로 바꾸고, 상태·메뉴·저장 동작과 StoryManager의 창 동작이 해당 bool을 갱신함을 확인했다. Start 코루틴의 초기 false→true도 확인했다. 읽기 전용 조사 기록은 artifacts/issue-6/badge-visibility/native-gates.il.txt·panels.il.txt·free-coroutines.il.txt에 보존한다. 이것은 실제 Windows 실행 결과가 아니다.

확대 크기·화면 가장자리·호버/설명 일치, 실제 지도 객체가 활성인 상태의 창 열림/닫힘, 선택 메뉴 가림, 이전 장면 무시·처리 중 지도와 정상 선택 구분, 가려진 100회 갱신의 조회 0회·복귀/개별 OFF, 실제 DLL의 조회/표시 연결·고정 원본 필드·무변경 경계를 검사한다. 전체 21개 검사 프로그램·269개 입력·112개 소스/리소스·16개 고정 참조와 실제 DLL 연결/읽기 전용 IL·설치 ZIP의 정확한 두 경로/CRC/바이트 검사를 통과했다. UI 5,447개·정보 런타임/연결 4,485개·지도 677개·기존 패드 262,831개 검사를 포함한다. 기존 컴파일 경고 7개·오류 0개다. 로컬 검토 기록은 artifacts/issue-6/badge-visibility/validated/build-manifest.json 및 build-run.log다.

[새 Windows 확인 항목](ISSUE-6-WINDOWS-VALIDATION.md#alpha18--툴팁배지게임-창-확인-대기)은 모두 대기다. 새 그림의 실제 가독성, 상태/속성/행낭/전기/관계 탭과 설정·저장·중첩 창에서 잔류 여부, 닫은 뒤 복귀, 선택 메뉴/패드·포인터, 해상도와 최초/반복 프레임을 확인해야 한다. 이전 사용자 확인을 새 DLL의 통과로 대체하거나 #6을 완료/종료하지 않는다.

이 변경은 아직 커밋/새 prerelease로 게시하지 않았다. 설치 후보가 확정되면 게임 종료 후 DLL만 교체해 기존 cfg를 보존한다.
