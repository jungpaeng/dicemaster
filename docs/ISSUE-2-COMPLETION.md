## 유지하는 지원 경계

깊이 8·고유 이야기 32·누적 1,310,720자·262,144토큰·524,288작업의 유한 추적, 한도 영향 54개 선택지의 부분 분석, 동적 대상·지원 밖 구문과 미입증 콜백/조건의 중립 표시는 기존 지원 범위다. 현재 제공된 실제 선택지는 `RootConditional`로 현재 조건 힌트를 켜지 않는다. 사용자 확인이 이 정적 경계를 제거하거나 모든 미래 효과·환경·수치의 확정을 입증한 것은 아니다.

문서의 과거 “Windows 미확인 / 이슈 open / 완료로 처리하지 않음”은 각 구현·게시 당시 기록이며 이번 완료 기록이 현재 상태를 보완한다. 이전 원본 증거·배포 태그·DLL·ZIP·Release·정식 Latest v1.0.3과 기존 Windows 기준 정책은 변경하지 않는다. 새 정식 Release를 발행하거나 승격하지 않았다.

영수증은 `artifacts/issue-2-completion/{before,completion-request,update-response,completion}.json`에 보존한다. 이번 변경은 문서·이슈 관리이며 소스·검사·설정·배포 파일을 바꾸지 않았다.
