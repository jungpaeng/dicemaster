# PRD #4 후속: 네 탭의 검색과 관련 로직 제거

2026-10-19 KST. 사용자가 각 탭의 검색창과 관련 로직을 모두 제거하도록 요청했다.
이 최신 요청은 원 PRD #4와 이전 후보의 검색·한글 화면 자판 접근성 요구를 대체한다.
이번 작업은 로컬 후보이며 커밋·태그·공개 게시·이슈 #4 완료를 수행하지 않는다.
에이전트는 게임을 설치하거나 실행하지 않았으며 실제 Windows 확인은 유지보수자가 수행한다.

## 제거하는 범위

- 네 탭의 검색창, 검색 문자 입력과 검색 지우기, 로컬 한글·영문·숫자/ID 화면 자판을 제거한다.
- 검색 도구·자판 탐색·조합·확정/취소와 검색 입력 포커스 상태를 제거한다.
- UI/모델의 검색 필터, 검색 문자열 캐시와 정규식, 검색 상태 변경과 검색 밖 오류 집계를 제거한다.
- 검색 결과 없음·검색 지우기 유도 문구, 검색 행과 자판에 배정하던 레이아웃 공간을 제거한다.

검색어로 행을 숨기는 경로가 없으므로 현재 문맥에 게시된 **모든 항목과 오류 상태**를 표시한다.
이는 새 게임 항목을 추가로 발견하거나 분석 범위를 바꾸는 변경이 아니다. 실제 게시 순서와 행의 읽음·분석·조회 상태를 유지한다.
정상적으로 행이 없으면 빈 목록 안내를, 준비되지 않았으면 게임 데이터 대기를 표시한다.
조회 실패·이전 값은 기존 상태로 남기고 자동 재시도·수동 새로고침 계약을 유지한다.

검색 행이 차지하던 높이는 본문에 돌려준다. 선택지의 연속 비교 본문과 조건·이벤트·미션의 목록/설명이
고정 제목·탭·상태·하단 안내를 제외한 나머지 공간을 사용한다. 작은 창·큰 글자의 복구 경로도 유지한다.

## 유지하는 탭별 표시와 조작

| 탭 | 표시 | 탐색과 작동 |
| --- | --- | --- |
| 선택지 | 전체 문장·읽음/분석 상태·원본 ID·전체 효과를 항상 공개 | ↑↓와 헤더로 선택, 오른쪽 스틱 본문, A는 선택만, 좌우로 접지 않음, B 닫기 |
| 조건 | 왼쪽 체크포인트 전체 목록·오른쪽 전체 설명과 읽음 상태 | 포커스는 목록, ↑↓ 항목 이동, 오른쪽 스틱 상세 읽기, 조작 없는 상세에 진입하지 않음, B 닫기 |
| 이벤트·미션 | 전체 목록과 선택한 행의 상세·예약 상태 | 활성 예약 버튼에 A·→로 진입, 다음 새 A로 예약, ←·B로 목록 복귀 |

상세의 제목·설명은 조작 포커스 대상이 아니다. 대기·실패·대상 없음·게시 실패의 예약 버튼에는 진입하지 않는다.
`이벤트 우선 예약`과 `미션 조건 통과 예약`은 기존 예약이며 즉시 실행·발생을 보장하지 않는다.
성공 뒤 같은 유효 버튼의 포커스는 유지하되 이전 티켓은 폐기한다. 새 문맥·대상 소멸·교체·게시 실패는 이전 실행 권한을 취소한다.
검색을 제거해도 실제 대상·문맥·최신 게시·예약 티켓 검증과 별도 새 입력 요구는 유지한다.

로그 열기는 기존 `[DiceMaster].LogMenuToggleKey`이며 기본값은 Tab이다. 패드 열기 조합을 추가하지 않는다.
LB/RB 탭, 십자키·왼쪽 스틱 탐색, A 확인, B 복귀/닫기, 오른쪽 스틱 본문, Y 도구, X 새로고침을 유지한다.
물리 키보드의 방향키·Enter/Space·Escape·Y·X는 대응하는 탐색·확인·복귀·도구·새로고침에 계속 사용한다.
제거 대상은 검색 문자 입력이며 일반 키보드 탐색을 제거하는 변경이 아니다.

## 검색 항목을 뺀 도구 17개

기존 19개 도구에서 검색 문자 입력과 검색 지우기 두 항목만 제거한다. 빠른 탭 이동은 유지한다.
아래 인덱스는 구현·검증 기준이며 화면에는 도구 이름을 표시한다.

| 인덱스 | 도구 |
| --- | --- |
| 0 | 게임 데이터 새로고침 [X] |
| 1 / 2 | 본문 글자 작게 / 크게 |
| 3 / 4 | 창 너비 줄이기 / 늘리기 |
| 5 / 6 | 창 높이 줄이기 / 늘리기 |
| 7 / 8 | 창 왼쪽 / 오른쪽 |
| 9 / 10 | 창 위 / 아래 |
| 11 | 창 위치·크기·글자 기본값 복구 |
| 12 | 패드 소유자 다시 선택 |
| 13 / 14 | 선택지 / 이벤트 탭으로 |
| 15 | 이전 영역으로 돌아가기 |
| 16 | 로그 창 닫기 |

위치·크기·글자는 기존 BepInEx 설정에 저장한다. 첫 유효한 로그 표시에서 새 기본 배치를 화면 너비 약 60%·높이 약 70%로 적용하고,
기존 사용자 지정 물리 픽셀 값은 보존한다. 최소 540×440과 화면 경계 보정이 작은 화면의 비율보다 우선한다.
첫 표시 이후 해상도가 바뀔 때마다 자동 비율을 다시 계산하지는 않으며 도구의 기본값 복구로 현재 화면의 배치를 적용한다.
선택과 스크롤은 실행 중 상태이며 새 문맥에서 이전 선택·실행 초점을 취소한다. 새 영구 설정 키는 추가하지 않는다.

## 입력과 이전 수정의 보존

패드 모드에서도 열린 로그와 활성 게임 창에 한정한 임시 커서 접근을 유지한다.
닫기·초점 상실·비활성화·종료의 커서 복원과 외부 커서 요청 우선 처리를 유지하며 게임 모드·액션 맵을 강제로 바꾸지 않는다.
일반 터치·마우스 누름→해제는 원래 문맥·컨트롤 ID와 실제 GUI 버튼 결과를 확인한다. 예약은 티켓 검증도 필요하다.
키보드 명령과 마우스 이동이 같은 프레임에 겹쳐도 새 키보드 초점을 지우지 않고, 이전 포인터 해제가 별도 작동을 만들지 않게 한다.

입력 소유권은 `로그 > 주사위 조절 > 게임`이다. 모드 전환·재연결·Alt-Tab·창 닫기·새 문맥 뒤
버튼 해제·스틱 중립·트리거 해제와 남은 터치 해제를 기다린다. 실제 XInput 차단 경로가 확인되지 않으면 위험한 패드 조작을 중지한다.
게임 액션 콜백 차단 밖의 직접 입력 폴링, 실제 OS 터치 전달과 Steam Input 구성까지 자동 검사로 보장하지 않는다.

앞선 [첫 표시·화면 비율](ISSUE-4-VIEWPORT-DEFAULTS.md), [탭 배치](ISSUE-4-TAB-LAYOUT.md),
[예약 버튼 초점](ISSUE-4-ACTION-FOCUS.md), [터치·커서 복구](ISSUE-4-TOUCH-INPUT.md) 변경을 함께 보존한다.
이 문서가 대체하는 검색·자판 요구 외에 기존 분석·갱신·한국어·읽음 표시·주사위·예약의 의미는 바꾸지 않는다.

## 후보 적용과 복구

1. 게임을 종료하고 현재 `BepInEx/plugins/DiceMaster/DiceMaster.dll`과 `BepInEx/config/DiceMaster.cfg`를 게임 폴더 밖에 백업한다.
2. 아래 최종 후보 ZIP을 임시 폴더에 풀고 해시를 확인한다. 기존 설정을 유지하려면 **DLL만** 플러그인 경로에 교체한다. cfg 전체 교체는 새 설치용이다.
3. 기본 Tab 또는 기존 열기 키로 로그를 열고 네 탭과 17개 도구를 확인한다. 기존 사용자 지정 배치가 작으면 도구의 기본값 복구를 사용한다.
4. 문제가 있으면 게임 종료 후 백업 DLL을 복원한다. 배치 설정까지 되돌리려면 백업 cfg도 복원한다. 세이브 형식은 변경하지 않는다.

설치 ZIP은 기존처럼 `config/DiceMaster.cfg`, `plugins/DiceMaster/DiceMaster.dll` 두 파일로 구성한다.
수신 게임 DLL은 읽기 전용 외부 참조로 사용하며 게임 소스·DLL을 저장소나 설치 ZIP에 추가하지 않는다.
