# DiceMaster v1.0.5-alpha.7 — 패드 겹침 열기·상태 문구·한국어 표시

2026-10-19 KST. alpha.6 이후 요청한 세 후속 변경을 모은 **prerelease 게시 준비 기록**이다. 사용자가 이번 커밋·prerelease 게시를 승인했다. 이 문서 작성 시점에는 고정 커밋 재빌드와 실제 공개 게시를 확정하지 않았으며, 아래 해시는 검토한 로컬 후보의 값이다. 고정 커밋 재빌드·후보 일치·게시·공개 다운로드 검증 결과는 확인한 뒤 별도로 기록한다.

실제 Windows 게임은 에이전트가 설치하거나 실행하지 않았다. 패드 탐색·스크롤·버튼·터치와 주요 회귀는 사용자 확인 대기이며 [이슈 #4](https://github.com/jungpaeng/dicemaster/issues/4)를 완료 처리하지 않는다. 이전 Windows 확인 기록을 이번 후보에 승계하지 않는다.

## alpha.6 이후 변경

| 변경 | 이번 동작 |

기존 창·글자 배치, 읽기 전용 선택지·조건 분기, 넘칠 때만 표시하는 스크롤바, 터치·마우스·키보드·패드 탐색을 유지한다. 실제 예약 대상의 원본 ID·객체·문맥은 표시 번역으로 바꾸지 않는다. 이벤트·미션 예약은 즉시 발생을 보장하지 않는다.

## 패드 열기와 입력 보호

L3/R3는 왼쪽·오른쪽 스틱을 아래로 누르는 클릭이다. 스틱 기울이기와 구분한다. 두 클릭이 겹쳐야 하며, 먼저 누른 클릭을 뗀 뒤 반대쪽만 누르는 연속 클릭이나 서로 다른 패드의 클릭을 합치지 않는다. 조합은 **열기 전용**이며 기존 B 복귀·닫기, `[DiceMaster].LogMenuToggleKey`(기본 Tab)와 닫기 버튼을 유지한다.

`[DiceMaster].EnableGamepadLogOpen=true`의 기본값을 유지하고 새 설정 키를 추가하지 않는다. 주사위 패드 옵션과 독립적이다. **옵션 켜짐·게임 창 초점·로그 닫힘에서는 단독 L3/R3도 게임으로 보내지 않는다.** 첫 클릭이 게임 기능에 함께 전달되지 않도록 두 클릭을 로그 열기용으로 예약하는 기존 제약이다. 원래 클릭 기능이 필요하면 게임 종료 후 이 옵션을 `false`로 바꾸고 재시작한다. 남은 누름은 해제한 뒤 게임에 반환하며 초기화·상태 재설정의 전체 중립 대기에서는 다른 버튼·스틱·트리거의 남은 입력도 소비한다.

전체 해제·스틱 중립·트리거 해제 뒤 같은 소유자의 새 조합만 받는다. 다른 버튼·스틱 기울임·트리거가 동반되거나 초점·연결·차단 준비가 끊기면 후보를 취소하고 전체 해제·중립을 다시 기다린다. 열린 뒤에도 조합을 모두 해제·중립으로 돌린 다음 새 탐색 입력을 받는다. 조합 홀드·창 닫기 뒤 남은 누름으로 반복 열기·탐색·예약이나 게임 대화·취소·주사위 조정을 만들지 않는 보호를 유지한다.

기존 **native 게임 폴링의 1초 신선도 보호**는 그대로다. 이는 두 클릭 사이의 제한 시간이 아니다. 게임의 실제 XInput 폴링이 정상으로 이어지는 동안 첫 클릭을 길게 유지할 수 있다. 오래된 폴링은 후보를 취소하는 입력 경계다.

패드 열기 의도를 로그 내부에 전달해 KM·불명 모드나 자동 scheme 변경 때문에 첫 새 탐색 입력을 다시 잃지 않도록 한다. 게임 입력 모드나 액션 맵을 강제로 변경하지 않는다. **Tab으로 열 때의 기존 모드 전환·첫 패드 입력 소비 문제는 별도 미해결 경로**이며 이번 결과로 해결됐다고 주장하지 않는다. 실제 지원되는 게임 XInput 폴링·차단 경로에서 사용하고 실패·미지원 시 기존 Tab·마우스·키보드로 접근한다. 게임의 직렬화된 바인딩 자료가 없어 L3/R3가 미사용이라고 확정하지 않는다.

## 상태와 한국어 표시의 의미

`조회 정상`은 조회·갱신에서 오류나 대기가 감지되지 않았다는 뜻이며 조건 충족·이벤트 발생·모든 정보의 완전한 확보를 보장하지 않는다. 이번에는 정상 행의 반복 안내만 생략한다. 선택지·조건의 `미독`은 추출한 대표 이야기 중 열람 기록에서 확인하지 못한 것이 있다는 뜻이고, `읽음 정보 없음`은 이야기 연결이나 읽음 정보를 얻지 못한 상태다. 조건 충족 판정과 구분한다. 이벤트·미션은 알 수 없는 읽음 배지를 숨기는 기존 계약을 유지한다.

결과명의 `P_成功_n`·`P_大成功_n`·`P_失敗_n`·`P_大失敗_n`·`P_正常_n`·`P_特殊_n`·`P_其他_n`은 각각 성공·대성공·실패·대실패·일반·특수·기타로 표시한다. 선택지의 실제 문장 우선순위, 본문·조건 분기 번역과 효과 요약의 태그 제거·한 줄·50자 말줄임 정책은 유지한다.

번역 파일 `ModTranslation.txt` 164행의 `\=`를 원문/번역 구분자로 잘못 자르지 않도록 첫 번째 이스케이프하지 않은 등호를 사용한다. 기존 literal escape 형태와 복원 형태를 함께 등록하고 해당 항목의 중간 사전 변환 별칭도 보완해 실제 호출에서 문장 전체가 번역되도록 한다. 기존 사전 우선순위와 먼저 등록한 값 우선 정책을 유지한다.

표시 이름만 번역한다. `LogItem.Id`·`RawId`, 게임 데이터 이름·스크립트 키·원본 객체·예약 target/context/tab/id, `원본 ID:`와 이름 없는 항목의 ID fallback은 보존한다. 공통 표시 번역 경계에 기존 중복 억제 미번역 진단을 연결한다. 사전에 없는 신규 문구까지 번역됐다고 보장하지 않으며 원문 보존·진단 정책을 따른다. 내장 리소스 8개와 외부 게임 참조는 수정하지 않는다.

## 적용·복구

1. 게임을 종료하고 현재 `BepInEx/plugins/DiceMaster/DiceMaster.dll`과 `BepInEx/config/DiceMaster.cfg`를 게임 폴더 밖에 백업한다.
2. 게시 검증이 끝난 **설치 자산 `DiceMaster-v1.0.5-alpha.7.zip`**을 임시 폴더에 푼다. GitHub 자동 `Source code` 압축 파일과 구분한다. 위 SHA-256을 확인한다.
3. **`plugins/DiceMaster/DiceMaster.dll`만 `BepInEx/plugins/DiceMaster/DiceMaster.dll`로 교체**한다. 기존 cfg를 보존한다. 이번 후속은 새 설정 키·값을 추가하지 않으므로 cfg 전체 덮어쓰기가 필요 없다.
4. 기본 Tab·기존 설정 키 또는 같은 패드의 스틱 클릭 겹침으로 로그를 연다. 배치 변경이 필요할 때만 도구의 `창 위치·크기·글자 기본값 복구`를 사용한다. 기존 사용자 배치와 설정 저장을 유지한다.
5. 문제 시 게임 종료 후 백업 DLL과 필요한 cfg를 복원한다. 공개 [alpha.6 설치·해시](ISSUE-4-ALPHA6-RELEASE.md)로 복구하면 패드 열기는 300ms 미만 계약이며 이번 상태·번역 변경 전으로 돌아간다. 패드 열기만 끄려면 기존 `[DiceMaster]`의 `EnableGamepadLogOpen=false`로 변경하고 재시작한다.

```powershell
Get-FileHash .\DiceMaster-v1.0.5-alpha.7.zip -Algorithm SHA256
Get-FileHash .\plugins\DiceMaster\DiceMaster.dll -Algorithm SHA256
```
