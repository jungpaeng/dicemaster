## 사용자에게 달라지는 점

지도에서 불확실한 후속 대화를 `진행 가능성 있음`으로 계속 예측하던 범위를 줄인다. 자동 목록은 **이번 클릭에 실행 가능한 기존 대기 임무**와 **1회성 증명·현재 조건·경로를 모두 확인한 항목**으로 제한한다. 행동력·장소 활성·주/부 임무 순서를 반영하며, 이후 단계 후보·일반 인물 대화는 현재 분석 결과가 참이어도 상세 조회에 남긴다. 도달 가능성이 미확정인 1회성은 증명 표식과 별개로 자동 목록에서 제외한다. 최대 세 행·외 N개·패널 양성 색도 이 필터를 통과한 항목으로 계산한다.

**로그 → 도구 → 지도 안내**에서는 미등록 임무 단계·일반 후속 대화·불확실한 결과와 조건·효과·전체 경로를 계속 읽는다. 지도 자동 갱신에서 후속 인물 대화 조건이나 미등록 단계의 전체 색인을 읽지 않는다. 이미 등록된 대기 목록을 먼저 읽고, 전체 색인과 선택 장소의 준비 상태를 분리한다. 빈 장소가 무관한 전체 임무 준비를 기다리며 확인 중 문구를 오래 남기지 않는다. 선택 장소의 최초 Lua 경로 준비 자체가 없어지거나 실제 Windows 프레임 비용이 검증됐다는 뜻은 아니다.

선택 화면의 이야기 안내는 **게임이 실제로 만든 현재 메뉴의 활성 선택지**를 출발점으로 유지한다. 숨김·비활성·다른 메뉴의 버튼은 제외한다. 다음 선택 경로를 읽을 수 있지만 중간 상태 변경·난수·지원하지 않는 구조가 있으면 후속 이야기 발생을 보장하지 않는다. 지도 자동 예측의 제한은 이 선택 화면 안내를 끄는 기능이 아니다.

중첩된 조건의 `난수 AND 확정 거짓`은 거짓, `난수 OR 확정 참`은 참으로 부분 판정한다. 명시적 지도 상세에는 원본 Condition/Switch 키, Switch useCount·횟수, 현재 플래그 ID/값과 난수 미추첨·선행 변경 사유를 제한된 표본으로 제공한다. 게임의 원래 판정·RNG·조건 횟수·세이브·능력치·아이템은 변경하지 않는다. 특정 인물·플래그 예외 목록은 없다.

상점의 짧은 사용·학습 효과와 학습 조건 상세, 실제 선택 분기의 5초 알림·실행 중 메모리 20건 기록을 유지한다. 기존 이벤트 선택·예약·주사위·로그 네 탭과 Xbox/XInput·키보드·마우스·터치·입력 소유권·해제/중립 보호도 유지한다. 네 정보 설정은 기본 ON이고 새 설정·단축키를 추가하지 않는다. 정상 0.25초/실패 5초·숨김/OFF 조회 중단·warm Lua 재분석 없음 계약은 유지한다.

## 설치·업데이트와 복구

활협전용 BepInEx 모드 베이스가 필요하다. 새 설치 ZIP은 게시 확인 뒤 이 문서에 연결한다. 업데이트는 게임 종료 후 현재 DLL/cfg를 백업하고 **DLL만** `BepInEx/plugins/DiceMaster/DiceMaster.dll`에 교체해 기존 cfg를 보존한다. 최초 설치는 ZIP의 `config`·`plugins`를 기존 BepInEx 아래에 넣는다. GitHub 자동 Source code ZIP은 설치용이 아니다. 문제 시 게임 종료 후 백업 DLL과 필요한 cfg를 복원한다.

## 새 후보 실제 Windows 확인 — 모두 대기

- [ ] 상점의 짧은 효과·조건 상세, 실제 실행 분기 5초 알림·20건 기록이 유지된다.
- [ ] 지도에서 우소매·사사형·소사매의 일반 후속 대화와 미등록 단계는 자동으로 나타나지 않고, 상세 조회에는 경로와 현재 상태가 남는다. 우소매 없음의 실제 조건 표본도 대조한다.
- [ ] 기존 대기 임무는 등록 여부·행동력·장소 활성·주 임무/앞선 대기 임무 우선순위에 맞춰 자동 표시된다.
- [ ] 증명된 1회성도 현재 조건·경로가 미확정/불가이면 지도 자동 표시에서 빠지고 상세에는 독립적인 표식/근거가 남는다. 자동 대상 0개인 준비 완료 지도는 숨는다.
- [ ] 현재 선택 화면의 실제 활성 버튼에서만 연결 이야기와 선택 경로를 안내한다. 숨김·비활성·이전 메뉴 안내가 남지 않고 후속 발생을 보장하는 것으로 읽히지 않는다.
- [ ] Xbox/XInput 장소 선택 → L3/R3 겹침 → 해제/중립 → Y 도구 → 지도 안내 → 오른쪽 스틱 상세 → B 복귀와 기존 네 탭·팝업·예약·주사위·키보드/마우스/터치를 확인한다.
- [ ] 최초/warm 지도 프레임·할당량과 0.25초/5초·숨김/OFF 중단을 관찰한다. 상세에서 지도 복귀·다른 장소·로드·OFF/ON 뒤 이전 연구 행이나 값이 남지 않고 조회로 RNG·횟수·세이브·능력치·아이템이 변하지 않는다.

새 DLL의 사용자 Windows 확인 전에는 #6 전체 완료나 이슈 종료로 처리하지 않는다. 기존 v1.0.6 Windows 확인은 #5 안정화 착수 근거이며 이 DLL의 새 검증 결과가 아니다.
