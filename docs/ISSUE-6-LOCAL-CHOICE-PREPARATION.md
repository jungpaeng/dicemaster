# 선택 안내 — 현재 스크립트의 직접 대화 먼저 표시

2026-10-22 03:30:55 KST에 소스 [`4849759`](https://github.com/jungpaeng/dicemaster/commit/484975971727410de78ec0bedc6c4ab089b4d0c1)의 [alpha.24](https://github.com/jungpaeng/dicemaster/releases/tag/v1.0.7-alpha.24)를 게시했다. 전체·고정 커밋 자동 검사 21개와 실제 후보 DLL 연결·설치 ZIP·익명 공개 다운로드 검증을 통과했다. **새 DLL의 실제 Windows·화면·물리 입력·FPS 확인과 PRD #6 전체 완료는 대기다.**

## 사용자 확인과 남은 지연

2026-10-22 사용자는 alpha.23의 완료 인사 잔존은 해결된 것 같다고 확인했지만, 지도 마커에 비해 남제자방 사사형 툴팁이 느리다고 보고했다. 이 부분 확인을 alpha.23 전체 Windows 검증 완료로 확대하지 않는다.

지도 마커 조회는 등록된 대기 임무와 준비된 1회성 자료를 읽고 자체적으로 새 Lua 경로 분석을 시작하지 않는다. 기존 선택 툴팁은 현재 스크립트에서 직접 인사를 찾아도 후속 메뉴·스크립트·풀의 전체 제한 분석과 경로 색인이 끝날 때까지 보류했다. 같은 원문 선택지가 다른 메뉴에도 있는지 확인하려던 전역 대기가 직접 대화의 첫 표시까지 묶었다.

## 준비 범위와 안전 경계

ChoiceStorySource만 MapRouteDefinitions.PrioritizeRootPreparation을 켠다. 현재 원문의 작업과 후속 스크립트/풀 작업을 분리하되 **기존 하나의 8192 작업 예산·약 5ms 양보 지점·자원/풀 각 1회 읽기·누적 작업/문맥/깊이 상한**을 공유한다. 현재 스크립트의 작업을 먼저 마치면 그 갱신에서 직접 근거를 공개하고 후속 작업은 다음 갱신부터 같은 예산으로 처리한다. 일반 지도 분석의 스케줄은 기본값 그대로다. 표시를 위해 한 프레임 분석량을 늘리거나 별도 분석기를 병렬로 추가하지 않는다.

RootPreparationComplete는 현재 스크립트의 관찰 가능한 메뉴 작업이 끝난 정의 상태다. 루트 구문/작업/문맥 상한, 중단 경로, 생략한 함수/반복 본문, 미해석 선택 라벨·인덱스·희소 배열은 먼저 표시할 때의 메뉴 유일성 근거로 사용하지 않는다. 기존 64개 경로 색인 예산도 끝나고 원문 노드가 유일하며 첫 루트 메뉴의 안전한 현재 조건 표본이 있는 경우만 먼저 표시한다.

후속 작업이 남아 있을 때는 **현재 스크립트 안에서 현재 선택 뒤 추가 선택 없이 이어지는 대사**만 기존 최대 32개 조회 범위에서 고른다. 다른 스크립트의 대사나 추가 선택이 필요한 경로는 이 먼저 표시하는 범위에 넣지 않는다. 후속 선택 경로는 전체 준비와 각 단계의 해금 확인이 끝난 뒤 기존 방식으로 추가한다. 대기 임무/증명 1회성 마커의 기준과 준비 완료 요구는 완화하지 않는다.

직접 대화도 완료 횟수/현재 불가 조건·미확정 완료 자료·반복 활동 필터를 통과해야 한다. 난수와 확정 거짓 AND 조합, 알 수 없는 선행 변경을 충족으로 바꾸지 않는다. 후속 분석이 남았다는 이유로 새 진행 가능/1회성 증명을 만들지 않으며 상세에는 직접 준비 완료와 후속 준비/읽기 대기를 구분한다. 후속 항목을 생략한 상태를 전체 이야기 부재나 불가로 판정하지 않는다. 특정 인물·조건 키 예외 목록은 없다.

## 자동 재현과 성능 해석

동일한 원본 room_001 Lua와 합성 직렬화 조건을 사용한 별도 조사 기록은 다음과 같다. 이는 사용자 Windows 세이브나 게임 프레임 실측이 아니다.

| 지표 | alpha.23 원문 분석 | 현재 후보 |
| --- | ---: | ---: |
| 첫 직접 인사 표시 | 10회 갱신 뒤 | 4회 갱신 뒤 |
| 전체 후속 준비 종료 | 10회 갱신 뒤 | 13회 갱신 뒤 |
| 읽은 자원 | 6개 | 6개 |

이 실행에서는 직접 안내가 먼저 나왔지만 전체 후속 준비는 더 늦게 끝났다. 현재 메뉴 우선 처리와 공개 시점 분리의 교환이며 전체 분석량 감소나 FPS 상승을 주장하지 않는다. 시간 양보 지점에 따라 갱신 횟수는 달라질 수 있다. 최초 구문 준비·늦은 중복/미해석 메뉴·색인 상한 때문에 모든 툴팁의 즉시 표시를 보장하지 않는다.

LocalPreparationCases는 느린/실패한 후속 자원을 아직 읽기 전 직접 인사 공개, 매 갱신 원래 작업/읽기 예산, 완료·복구·자료 누락 전환, 잠긴 후속 주제 제외/해금 뒤 추가, 패드 포커스, 정상 캐시·5초 실패 재시도, 늦은 중복·생략 본문·동적 라벨·루트 상한을 검사한다. 원본 SHA를 대조하는 NativeEntryServices도 실제 원문 캡처 후킹 경계에서 **준비 중 초회 인사 유지와 완료 인사 제외를 모든 갱신에 걸쳐** 확인한다. 생산 DLL IL에서 이 선택 전용 준비가 연결되고 지도는 옵트인하지 않는지도 확인한다. 물리 게임 조작이나 Windows 실행 검사가 아니다.

## 유지하는 계약

상위 EnableOptionInfo와 개별 EnableMapGuide/EnableOneShotHints·OFF/숨김 중단, 정상 .25초/실패 5초·정상 주기 Lua 재분석 없음·정의 구문 캐시·문맥 교체 시 현재 값 재조회 계약을 유지한다. 새 설정/cfg 변경은 없다. #5의 실행용 변환과 alpha.23의 원문 캡처, 완료/해금/활동 필터·기회 마커, Xbox/XInput·키보드·마우스·터치·소유권/해제/중립·창 가림, 로그 네 탭·이벤트 선택/예약·주사위·상점·실제 분기 기록을 유지한다. 조회가 게임 판정·Lua·RNG·횟수·플래그·세이브·능력치·아이템을 변경하지 않는다. 현재 값은 RootPreparationComplete나 구문 캐시에 저장하지 않는다.
