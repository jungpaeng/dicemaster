## 문제와 범위

실제 현재 메뉴의 사사형 버튼을 관찰했더라도 후속 `예전에 부탁했던 일`은 Lua에서 찾은 정의일 뿐 현재 열린 선택지라는 증거가 아니다. alpha.18은 확정 거짓인 경로를 제외하지만, 선행 처리로 해금이 미확정이 된 경로도 이름을 붙여 `진행 가능성 있음`으로 표시할 수 있었다. 상세는 분석한 연결 경로를 최대 32개까지 조건과 무관하게 나열했다.

마커는 이미 실제 등록 대기 임무의 실행 연결 또는 엄격한 1회성 증명·현재 조건·확정 경로를 요구하므로 이 일반 대화 툴팁보다 엄격했다. 일반 대화의 미확정만으로 마커가 생기는 동일 증상을 확인한 것은 아니다. 이번에는 후속 선택지 해금을 별도 공통 요건으로 추가해, 툴팁과 마커의 선택 경로 기준이 갈리지 않도록 한다.

## 표시 기준

| 선택 경로·이야기 상태 | 표시 |
| --- | --- |
| 현재 화면의 실제 활성 버튼 | 현재 안내의 출발점으로 사용 |
| 남은 모든 선택 단계의 해금 조건이 안전하게 참 | 그 경로를 툴팁·기본 상세 목록에 표시 가능 |
| 하나라도 잠김 또는 해금 미확정 | 해당 경로·추가 개수·자동 툴팁에서 제외 |
| 선택지는 해금 확인, 이야기 내부에 난수 등 미확정 | 별도 확정 거짓이 없다면 `진행 가능성 있음` 유지 |
| 모든 안내 경로가 제외됨 | 자동 행·힌트·패드/포인터 툴팁을 숨김. 상세에는 경로 없음/제외 이유만 제공 |
| 등록 대기 임무 또는 증명 1회성 | 해금 확인에 더해 기존 등록·조건·경로·증명 요건을 모두 유지해야 마커 표시 |

현재 선택 화면은 실제 관찰한 버튼 다음 단계부터 확인한다. 이전에 캡처한 현재 버튼의 해금 조건을 무조건 재해석하지 않는다. 이미 존재하는 안전한 현재 필수 조건의 거짓 제외도 유지한다. 실제 다음 메뉴가 열리면 그 메뉴의 현재 활성 버튼으로 새로 관찰한다. 게임의 선택·비활성화·진행을 실행하지 않는다.

선택 화면 상세는 툴팁에서 사용한 같은 경로 목록을 사용한다. 지도 상세와 이벤트/기회 경로 목록도 잠김·해금 미확정 경로를 제외한다. 제외된 주제 이름을 수십 개씩 나열하지 않고 제외 이유를 설명한다. 다른 이야기 조건이 불가인 이벤트 자체의 상세와 현재 필수 조건 설명은 유지한다.

## 구현과 한계

`MapChoiceStep.ReadAvailability`는 하위 메뉴의 닫힌 진입과 기존 `topicGate`를 사용한다. 해당 조건은 정의 시점의 선행 쓰기와 대화 플래그 초기화의 영향이 이미 반영된 식이다. 영향 범위를 확인할 수 없으면 Unknown이며 참으로 취급하지 않는다. `MapRoutePath.ReadChoiceAvailability`는 마지막 주제만 검사하지 않고 남은 모든 단계를 확인한다.

`ChoiceStorySource`는 실제 현재 버튼의 원문·스크립트 위치 다음부터 해금을 확인한 뒤 이야기 조건을 판단한다. 표시 경로·인물·추가 개수와 상세 목록은 같은 확인 결과를 사용한다. `ChoiceOpportunities.PathMet`와 지도 이벤트의 `MapRouteEntry.ReadCurrent`에도 공통 해금 확인을 AND로 추가한다. 지도에 복잡한 일반 대화 예측을 자동으로 복구하지 않는다.

선택 조회당 새로 읽을 해금 조건은 32개로 제한하고, 기존 32경로/16선택 단계 상한과 `MapRouteRead`의 조건·체크포인트 메모화를 재사용한다. 지도 이벤트도 한 경로 집합의 해금 조회를 32개로 제한한다. 예산 초과·읽기 불가·복잡한 동적 메뉴는 해금 미확정으로 제외한다. 실제로 가능한 주제가 덜 표시될 수 있으며 게임 전체 기회 없음을 보장하지 않는다. 이를 줄이기 위해 게임을 미리 실행하거나 RNG·플래그·세이브를 변경하지 않는다.

캐시된 정의와 현재 읽기만 사용한다. 정상 0.25초/실패 5초, 숨김/OFF 중단, 정상 주기 Lua 재로드·재분석 없음, 렌더링 시 현재 조건 조회 없음, 입력 소유권·해제/중립 보호를 유지한다. 새 설정 키나 cfg 변경, 인물·플래그 예외 목록은 없다.

## 자동 검사

선택지 회귀는 잠김/열림 대안, 모두 잠김, 현재 값 왕복, 누락된 조건, 임의 콜백, 대화 플래그 초기화, 관련 선행 쓰기, 잠긴 중간 선택·열린 마지막 선택, 이미 캡처된 활성 현재 버튼, 내부 난수와 독립 부재 조건, 현재 비활성/숨김, 대기 임무/1회성 메뉴 마커를 포함한다. 기존 원본 남제자방 corpus 검사는 실제 조건 정의가 없는 후속 주제를 안내하도록 요구하던 기대를 제거한다. 지도 상세의 선행 변경 경로도 새 제외 기준을 검사한다.
