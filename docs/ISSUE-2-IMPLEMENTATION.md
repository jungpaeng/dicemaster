같은 `if/elseif/else`의 효과는 분기 그룹·갈래·중첩 경로를 보존하여 인접 효과끼리 묶는다. 예를 들어 `[분기 1-A] 호감도 +5 | 체력 +3`, 다음 줄 `[분기 1-B · 그 외] 호감도 -3 | 체력 +10`이다. 독립적인 두 조건문은 서로 다른 그룹으로 표시하고 `or` 관계로 합치지 않는다. 갈래 제목만 청록·연보라·금색의 중립색으로 구분하며 기존 효과의 증감 색상은 유지한다. 색상은 조건 충족 판정이 아니며 조건 원문·변수·능력치 조건을 임의로 노출하거나 추론하지 않는다. 단락 평가·선행 미지원 등 실제 조건문으로 분류할 수 없는 불확실성은 `조건부`로 남긴다.

## 분석과 표시의 경계

고정 구문 분석·후속 연결을 문맥 메모리에 캐시하고 표시 때 현재값만 읽는다. 문자열·주석을 건너뛰는 토큰 경계에서 호출·괄호·쉼표·순서·분기를 유지한다. 구조화한 효과와 이유를 선택지 요약과 로그가 공유한다. 미지원은 읽기 실패로 재시도하지 않는다. 일부/전체 미지원 안내는 정상 효과 앞에 배치하고 로그는 전체 설명을 유지한다. 효과가 발견되지 않으면 `확인된 효과 없음`으로 표시한다.

상수식은 숫자·사칙연산·괄호·단항 부호만 처리한다. 정수가 아닌 결과, 0 나누기, 비유한 값·범위 초과·지원 밖 연산은 미지원이다. 변수를 실행·추론하지 않는다. 현재값 예상은 읽기 전용으로 검증할 수 있는 경로에 한하며 선행 변경·조건·부가 능력치·제한을 확정할 수 없으면 의미 설명을 사용한다.

`SetNextScript`와 로컬 후속의 `SetCurrentStoryScript`는 예약 대상 등록으로 추적한다. 연결된 효과는 `이후 가능한 변화`에 묶고 다음 사용자 선택에서 멈춘다. 덮어쓰기·순환·동적 흐름을 즉시 실행 결과로 합치지 않는다. 실제 리소스 읽기는 기존 Resources의 `story/chinesetraditional/` 안에서만 수행한다. 경로 탐색·URL·파일 읽기 인터페이스를 추가하지 않는다. 정상 빈 대상, 누락, 미준비, 읽기 실패, 순환, 한도 도달을 구분한다.

실제 읽기 오류는 기존 열린 현재 탭의 5초 재시도·수동 복구·이전 값 정책을 따른다. 첫 실패에도 이미 해석한 효과는 유지한다. 요약 표시는 실패 상태와 부분 설명을 사용하며 스스로 재시도하지 않는다. 미지원 진단은 같은 문맥·스크립트·선택지·함수·원인마다 최초 1회이며 Lua 원문·세이브·인자 원문을 기록하지 않는다.

정확한 서명·게임 DLL token·하위 호출과 설명 경계는 [API 의미 대조](ISSUE-2-API-SEMANTICS.md)에 기록한다. 직접 설정은 가산과 구분하며 제거 함수는 1개 감소다. `UpdateSetPlayerStat`·`GetModifyString`·`GetDisplayTime`은 상태 변경 효과로 표시하지 않는다. `SetPlayerBattleSkill`의 index와 `SetMissionTime`의 year가 무시되는 동작, 활성값 1, 장비 종류별 백업·음수 레벨 유지, 시간 진행의 하위 효과를 설명한다.

## 완료 범위와 별도 실행 확인

위 alpha.1 게시 당시 남았던 실제 Lua 정적 대조와 유한 추적 정책은 [최신 정적 검증 기록](ISSUE-2-REAL-LUA-VALIDATION.md)으로 보완한다. 현재 오프라인 정책은 깊이 8·루트 포함 고유 스크립트 32·누적 UTF-16 1,310,720자·262,144토큰·524,288작업과 최대 128입장 문맥이다. 합성 경계와 실제 자료·비용을 근거로 고정했으며 Unity 프레임 예산 인증과 구분한다.

유한 한도·동적 대상·미지원 문법과 조건의 불확실성은 명시한 지원 경계다. 이것들을 모두 해소하거나 Lua를 실행해야 비Windows 구현이 완료된다는 조건을 추가하지 않는다.

남은 실행 확인은 해당 후보의 Unity/native·실제 Harmony·다른 모드·UI 가독성·실제 현재 상태의 수치와 게임 진행·프레임 비용이다. 사용자가 이번 작업에서 Windows 확인을 제외했으므로 후보 설치·게임 실행·오류 주입·런타임 검증을 수행하거나 요청하지 않는다. 이 확인 없이 PRD 전체·이슈를 완료 처리하지 않는다.

기존 로그·난수·수명주기·주사위·패드·번역·설정·세이브 계약을 보존한다. 새 설정·통신·계정·영구 저장은 추가하지 않는다. 사용자가 승인한 배포는 `v1.0.4-alpha.1` prerelease이며, 문제가 있으면 이전 DLL 복원과 기존 설정·세이브 유지가 롤백 경로다. v1.0.2의 선택지 캐시 소실, 기존 로드 후 다음 성공 Lua까지 대기하는 제한은 해당 버전의 알려진 문제로 구분한다.
