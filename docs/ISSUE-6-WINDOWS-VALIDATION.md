## 주사위 결과별 안내 — 로컬 후보 확인 대기

2026-10-23 [alpha.39 설치 후보·자동 검사·게시 기록](ISSUE-6-ALPHA39-RELEASE.md). alpha.38은 소스에서 되돌렸으며 공개 alpha.38 DLL로는 아래 새 기능을 확인할 수 없다. 게임 종료 후 새 후보의 DLL만 교체해 기존 cfg를 보존한다. **아래 항목은 아직 Windows에서 실행하지 않았다.**

- [ ] 마커를 보고 들어온 주사위와 다른 경로로 연 주사위에서, 굴리기 전에 각 결과 행의 아이보리 연결 후보/엄격한 금색 기회가 해당 결과에만 붙는지 확인한다. 결과를 굴릴 필요 없이 이름·짧은 이야기를 읽을 수 있어야 한다.
- [ ] 표시한 결과를 실제로 얻은 경우 연결 인물/주제와 원래 진행이 일치하는지 확인한다. 잠김·완료·반복 활동·조건 미충족 이야기는 제외하고, 난수 미확정 AND 현재 false인 조건이 마커를 만들지 않아야 한다. 미래 선택/추가 판정까지 발생을 보장하는 표시는 없어야 한다.
- [ ] 기존 선택지 효과·결과 임계값·긴 한국어·해상도/배율/TMP 폰트·다른 모드 조합에서 글자와 마커가 겹치지 않는지 확인한다. 공간이 부족하면 새 요약만 생략하며 로그 → 도구 → 지도 안내로 내용을 읽을 수 있어야 한다.
- [ ] Xbox/XInput·키보드·마우스·터치로 원래 주사위 조작·직접 값/음수·자동 복귀·패드 LB 조정과 입력 소유권/해제/중립 보호를 확인한다. 마커가 결과 버튼을 클릭/포커스 가능한 새 조작으로 만들지 않아야 한다.
- [ ] 로그 네 탭·#5 이벤트/분기 팝업과 일회 예약·미션 예약·실제 분기 5초/20건·상점·기존 지도/카드 마커가 유지되는지 확인한다. 주사위 안내를 읽어도 예약이 소비되거나 게임/RNG/세이브가 바뀌면 안 된다.
- [ ] 로그/다른 창/팝업·포커스 상실·설정 OFF·게임/세이브 불러오기·주사위 재진입에서 이전 마커/요약/스피너가 남지 않아야 한다. 빈 결과·미지원 연결은 준비가 끝나면 스피너를 지운다. `EnableBranchNotices` OFF에서도 지도 안내 ON이면 결과 연결은 표시되어야 한다.
- [ ] 최초 표시 지연·안정 상태 FPS/GC를 확인하고 새 DLL의 SHA-256·게임/모드 베이스·입력 장치·남은 문제를 기록한다. 자동 관리 코드 검사·5ms 양보 기준은 실제 Unity 프레임 측정을 대신하지 않는다.

위 확인 전까지 새 후보와 PRD #6을 전체 완료/종료로 처리하지 않는다.

## 네 기능과 수명

- [ ] **미실행** — 현재 지도에서 활성 장소의 후보 0/1/복수를 비교한다. 후보 수·진행 가능 수와 진행 가능한 이름이 장소 옆에 보이며 불가·불명을 가능 수에 넣지 않는다. 도구의 지도 안내에서 가능 우선·같은 상태 원래 순서를 대조한다. 후보 수를 실제 발생 보장으로 안내하지 않는지 확인한다.
- [ ] **미실행** — 패드로 장소를 바꿔 현재 선택이 갱신되는지 확인한다. 장소/지도/임무 단계·원본 데이터가 바뀌거나 씬을 떠나면 이전 대상 이름·조건·수가 새 대상에 남지 않는다. 숨은 다른 지도 정보가 반복 조회되지 않는다.
