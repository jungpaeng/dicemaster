# PRD #6 — 새 후보 실제 Windows 확인표

[후보·설치·파일 확인](ISSUE-6-CANDIDATE.md) · [구현·지원 한계](ISSUE-6-IMPLEMENTATION.md) · [사용자 안내](../README.md) · [패드](GAMEPAD.md)

대상은 **[공개 prerelease v1.0.7-alpha.1](https://github.com/jungpaeng/dicemaster/releases/tag/v1.0.7-alpha.1)**이다. [설치 ZIP](https://github.com/jungpaeng/dicemaster/releases/download/v1.0.7-alpha.1/DiceMaster-v1.0.7-alpha.1.zip)의 익명 다운로드·CRC·두 파일·내부 바이트·해시는 검토 후보와 일치했다. 아래 실제 게임·장치 항목은 아직 미실행이다. 자동 검사나 v1.0.6 사용자 Windows 확인 완료·잔여 문제 없음 답변을 새 후보 통과로 바꾸지 않는다. 최종 후보 DLL/ZIP의 식별값과 고정 소스 재빌드 검증은 후보 기록에 확정했으며 실제 설치한 파일의 해시는 아래에 남긴다. 이 문서 자체로 #6을 완료로 닫지 않는다.

## 환경과 파일

| 기록 항목 | 실제 확인 값 |
| --- | --- |
| 시험 날짜·시간·확인자 | 미기록 |
| 후보 버전·소스 커밋/매니페스트 | 미기록 |
| 설치 DLL SHA-256·바이트 | 미기록 |
| 설치 ZIP·cfg SHA-256 | 미기록 |
| 활협전 버전/빌드·Unity·BepInEx/모드 베이스·Windows 버전 | 미기록 |
| Xbox/XInput 패드 모델·연결·컨트롤러 슬롯 | 미기록 |
| Steam Input 활성/프로필·다른 입력 모드 | 미기록 |
| 마우스·트랙패드·터치 장치·마우스 에뮬레이션/별도 터치 | 미기록 |
| 창/전체화면·해상도·UI 배율·로그 글자 설정 | 미기록 |
| 다른 모드와 관련 조합 | 미기록 |

장치가 없거나 오류를 안전하게 재현할 수 없으면 미실행과 사유를 그대로 남긴다. 실제 관찰·원래 대상 ID·재현 순서·관련 BepInEx 진단을 적고 전체 게임 소스/Lua/세이브를 기본 증거로 요구하지 않는다.

## 네 기능과 수명

- [ ] **미실행** — 현재 지도에서 활성 장소의 후보 0/1/복수를 비교한다. 후보 수·진행 가능 수와 진행 가능한 이름이 장소 옆에 보이며 불가·불명을 가능 수에 넣지 않는다. 도구의 지도 안내에서 가능 우선·같은 상태 원래 순서를 대조한다. 후보 수를 실제 발생 보장으로 안내하지 않는지 확인한다.
- [ ] **미실행** — 패드로 장소를 바꿔 현재 선택이 갱신되는지 확인한다. 장소/지도/임무 단계·원본 데이터가 바뀌거나 씬을 떠나면 이전 대상 이름·조건·수가 새 대상에 남지 않는다. 숨은 다른 지도 정보가 반복 조회되지 않는다.
- [ ] **미실행** — 안전하게 증명되는 1회성의 지도·현재 선택지·이벤트 팝업 표시와 로그 근거가 같은 원본을 가리킨다. 미독·첫 방문·유일 기회와 구분한다. 현재 선택지 버튼은 활성 조건 참조를 제공하지 않으므로 기본 선택지는 1회성 확인 불가로 표시한다. 지도·실제 이벤트 팝업의 명시 조건/확정 상수 결과만 양성 근거로 사용하고, 미독·비활성·동적/미지원 항목을 반복 가능 또는 1회성으로 단정하지 않는다.
- [ ] **미실행** — 원래 게임 Position/Switch 실제 반환 결과와 우측 상단 최신 알림 1건을 대조한다. 5초 뒤 사라지고 빠른 연속 결과는 최신 결과로 교체되어 새 5초를 시작한다. 표시가 게임을 멈추거나 초점을 바꾸지 않는다.
- [ ] **미실행** — 분기 기록이 실제 진행 순서의 최신순이며 20건을 넘지 않는다. 같은 제목·같은 분기의 별도 실제 실행은 각각 남고 같은 실행의 중복 관찰은 추가되지 않는다. 원본 매칭 실패는 실제 결과와 확인 불가 상태를 구분한다.
- [ ] **미실행** — 수동 저장·자동 저장·로드·새 게임·장면 전환·분기 기능 OFF 각각에서 알림과 기록이 즉시 비워진다. ON·게임 재시작 뒤 이전 알림을 재생/복원하지 않는다. 저장·조회 선택·기록 파일을 추가하지 않는다.
- [ ] **미실행** — 패드로 소모품·책/비급·지원 밖 물품을 연속 선택하면 이름·종류·상태와 로그 상세가 같은 대상에 붙는다. 기존 설명이 보존되고 요약이 중복 추가되지 않으며 상점 종료·물품 교체·OFF에서 이전 요약이 남지 않는다.
- [ ] **미실행** — 소모품 효과 자료·정상 빈 배열·미지원/동적·사용 실행 경로 미확인을 구분한다. 자료상 수치가 실제 적용량 확정처럼 표시되지 않는다. 책은 현재 학습 조건·1회 소모·다음 단계 효과와 학습 완료를 구분하고 실제 학습량·미래 결과를 예측하지 않는다.
- [ ] **미실행** — 알려진 책의 조건 묶음 OR/묶음 간 AND·중앙 50 방향 변화·무공 25 경계와 비급 등급·소모 선택 순서·상하한을 실제 자료와 비교한다. 미지원·연동 수치는 확인 불가로 남고 읽기만으로 학습점·레벨·능력치·아이템·가격·재고가 변하지 않는다.

## 패드·화면·기존 기능 회귀

- [ ] **미실행** — 마우스 호버 없이 Xbox/XInput으로 지도/선택지/상점 물품을 선택한다. 기존 같은 패드 L3/R3 겹침→버튼 해제/스틱·트리거 중립→Y 도구→세 조회 선택→↑↓ 목록·오른쪽 스틱 상세→B 도구 복귀를 수행한다. 새 행 A/Enter·클릭·터치가 구매·사용·학습·예약·이벤트를 실행하지 않는다.
- [ ] **미실행** — LB/RB 기존 네 탭 이동, X 새로고침, Y 도구, B/Esc 닫기·이전 화면과 Tab/설정 로그 키가 유지된다. 팝업에서 로그를 열면 로그만 입력을 받고 Lua 판정·예약 소비가 보류되며 닫기 B/Esc·누른 A가 뒤에서 재사용되지 않는다.
- [ ] **미실행** — A/B 유지·동시 입력·길게 누르기·Alt-Tab·패드 분리/재연결·여러 슬롯·소유자 재선택·터치 뒤 패드 전환에서 기존 입력 소유권과 버튼 전체 해제·스틱/트리거 중립 보호가 유지된다. 단일 native XInput 차단 실패/미확인 때 위험한 패드 확정을 막고 키보드·마우스로 복구한다.
- [ ] **미실행** — 키보드·마우스·트랙패드·마우스 인식 터치와 가능한 별도 터치의 새 조회 선택·설정·스크롤·복귀를 별도로 확인한다. 한 경로 성공을 다른 장치 성공으로 옮기지 않는다.
- [ ] **미실행** — 긴 한국어·이름 자료 없음/원문 ID·큰 글자·긴 목록·작은 창·화면 가장자리·해상도 변화에서 이름·한국어 상태·선택 표시·전체 상세 스크롤이 읽힌다. 자동 표시가 기존 UI와 겹치면 조정되고 포커스/클릭 영역을 추가하지 않는다. 색만으로 상태를 구분하지 않는다.
- [ ] **미실행** — 기존 선택지 요약·한국어/읽음, #5 이벤트·조건 팝업 일반/명시 조건 무시/B/Esc 원래 판정, 조건·이벤트·미션 예약·해제·한 번 소비, 주사위 임의 정수·음수·0 자동과 패드 조정을 회귀 확인한다.

## 설정·읽기 전용·실패·비용

- [ ] **미실행** — 새 키 없는 기존 cfg와 새 cfg에서 네 키가 true로 추가된다. 로그 도구 각각 ON/OFF가 즉시 적용·저장·재시작 유지되며 다른 개별 키·기존 단축키·배치·글자값을 바꾸지 않는다.
- [ ] **미실행** — 각 OFF는 해당 표시·수집·스냅샷을 비우며 분기는 이력도 지운다. 다시 ON은 현재 유효 문맥부터 표시하고 과거 결과를 재생하지 않는다. `EnableOptionInfo=false` 시작은 네 저장값을 보존하면서 전체 비활성화하고 상위 옵션을 켜는 재시작 규칙을 따른다.
- [ ] **미실행** — 안전하게 재현 가능한 설정 읽기 실패는 해당 기능만 비활성화한다. 키 누락의 최초 기본값과 실패를 구분하고 게임 진행·다른 기능은 유지한다.
- [ ] **미실행** — 데이터 대기·대상 없음/빈 목록·확인 불가·첫 읽기 실패·같은 대상 갱신 실패의 이전 값을 구분한다. 대상 소멸·ID 재사용·오래된 콜백·로드/장면 뒤 예전 결과가 새 대상에 붙지 않는다. 일부 실패가 정상 후보/다른 기능을 막지 않는다. 최초 실패/복구 진단만 남고 매 프레임 로그가 생기지 않는다.
- [ ] **미실행** — 자동·상세 표시의 모든 가시성 조합을 확인한다. 보일 때 정상 0.25초·실패 5초, 모두 숨김/OFF 표시용 조회 0과 정상 주기 Lua 재분석 없음을 관찰한다. 활성 분기의 실제 결과 관찰은 표시용 주기 조회와 구분한다.
- [ ] **미실행** — 조회·행 이동·정렬·스크롤·설정 조회 전후 RNG·조건 실행 횟수·예약·세이브·능력치·아이템이 그대로다. 원래 분기 실행이 만든 정상 변화와 표시가 만든 변화를 구분하고 원래 반환값이 바뀌지 않는다.

| 실제 Windows 비용/할당량 기록 | 환경·방법·관찰 |
| --- | --- |
| 같은 지도·상점·긴 후보의 표시 전/후 비용 | 미기록 |
| 보이는 정상 갱신/실패 재시도 횟수·시간 구간 | 미기록 |
| 자동·상세 모두 숨김/OFF의 조회 횟수 | 미기록 |
| 정상 주기 분석 캐시 재사용·재분석 횟수 | 미기록 |
| 실제 Unity 프레임 시간·할당량 관찰 방법과 결과 | 미기록 |

합성 검사 수치를 실제 프레임 성능으로 바꾸지 않고 근거 없는 고정 ms 합격선을 두지 않는다.

## 설치·복구와 최종 판정

- [ ] **미실행** — 후보 설치 ZIP의 정확한 두 파일(DLL/cfg), CRC·바이트·해시와 실제 설치 DLL을 대조한다. 업데이트 시 DLL만 교체해 기존 cfg를 보존하고 신규 네 키가 추가되는지 확인한다. 게임 종료 뒤 백업 DLL과 필요한 cfg 또는 정식 v1.0.6으로 복구할 수 있다.

자동 검사 영수증과 실제 사용자 결과·남은 문제를 함께 확인한 후 #6 완료 여부를 판단한다. 미실행 항목은 미실행으로 유지한다. 실제 사용자 확인이 남아 있으면 설치 후보와 이 표를 전달하고 전체 완료·이슈 종료로 처리하지 않는다.
