# DiceMaster v1.0.5-alpha.4

선택지·조건 카드 탐색, 기본 창 크기, 미션 목록 잘림과 상태 안내를 수정한 **prerelease 후보**입니다. 사용자 후속 요청 네 가지를 반영했으며 **이 후보의 실제 Windows 게임 검증은 아직 진행하지 않았습니다. [이슈 #4](https://github.com/jungpaeng/dicemaster/issues/4)는 미완료로 유지합니다.**

사용자 지시에 따라 새 태그와 설치 ZIP으로 게시를 준비 중입니다. 기존 Release·자산과 Latest 정식 [v1.0.4](https://github.com/jungpaeng/dicemaster/releases/tag/v1.0.4)를 보존하는 범위이며, 아래 자동 검사는 게시 성공 기록이 아닙니다. 에이전트는 게임을 설치하거나 실행하지 않았습니다.

## 이번 수정

- **펼친 카드에서도 위·아래 탐색:** 선택지·조건에서 ↑↓로 다른 항목을 선택하고 →는 현재 카드 펼침, ←는 현재 카드만 접기로 동작합니다. A는 현재 카드의 펼침·접기를 전환하며 다른 카드의 펼침은 유지합니다. 펼친 영역에서 B는 먼저 목록으로 돌아가고 목록에서 다시 B를 누르면 닫습니다. 키보드 방향키와 패드에 같은 규칙을 적용합니다.
- **더 넓은 기본 창:** 1080p 기준을 **1280×960, 본문 20px**로 늘렸습니다. 1440p는 약 1707×1280/27px, 4K는 2560×1920/40px입니다. 창은 화면 안으로 보정하고 본문 글자 범위 12~64px를 유지합니다.
- **미션 목록 줄바꿈과 높이:** 스크롤바를 제외한 실제 열 너비로 제목·상태의 필요한 높이를 계산해 여러 줄이 잘리지 않도록 수정했습니다. 이벤트 목록에도 같은 행 배치를 적용합니다.
- **읽음·조회·분석 상태 구분:** 이벤트·미션의 불명확한 읽음 배지를 정리하고 조회 대기 안내를 바꿨습니다. 정확한 의미는 아래와 같습니다.

카드는 자동 갱신으로 앞 카드의 길이나 순서가 바뀌어도 선택한 제목을 따라갑니다. 휠·스크롤바·오른쪽 스틱으로 직접 읽는 동안에는 강제로 되돌리지 않으며 다음 항목 이동부터 따라가기를 재개합니다. 이벤트·미션 상세의 위·아래는 기존대로 본문/예약 버튼 이동입니다.

이전 기본 배치와 위치·너비·높이·글자 크기가 모두 같은 설정만 새 기본값으로 이행합니다. 사용자 지정 위치·크기·글자와 540×440 같은 작은 설정은 유지합니다. 기존 크기가 작으면 **도구 → 창 위치·크기·글자 기본값 복구**로 현재 화면의 새 기본값을 적용하세요. 창·글자 설정은 기존 BepInEx 설정에 저장하며 검색·선택·펼침·스크롤은 실행 중 상태입니다.

## 상태 문구의 뜻

| 표시 | 의미 |
| --- | --- |
| 이벤트·미션에 읽음 배지 없음 | 읽음 정보 `Unknown`의 배지만 생략합니다. 미션 완료 여부를 판정한 결과가 아닙니다. 명시적인 읽음/미독은 계속 표시합니다. |
| 선택지·조건의 `읽음 정보 없음` | 읽음 정보가 `Unknown`인 상태입니다. 읽음·미독을 임의로 확정하지 않습니다. |
| `설명 조회 대기` | 현재 설명을 조회하지 못한 상태입니다. 현재 미션 단계가 없거나 필요한 자료를 얻지 못했을 수 있으며, 항상 로딩 중이라는 뜻은 아닙니다. 미션 미완료·조건 미충족도 뜻하지 않습니다. |
| `분석 대기` | 분석기의 상태이며 위 설명 조회 상태와 별개입니다. |

기존 게시 모델의 `Unknown`은 이야기 없음과 읽음 정보 미제공을 구분하지 않으므로, 이번에 어느 쪽인지 새로 확정하지 않습니다. 설명 조회 대기의 개별 원인도 진단 없이 단정하지 않습니다. 정상 문맥의 대기·실패 행은 열린 현재 탭에서 5초 간격으로 재조회하며 수동 새로고침으로 즉시 다시 조회할 수 있습니다. 정상 행의 0.25초 갱신과 닫힌 창·비활성 탭을 조회하지 않는 계약은 유지합니다.

## 검사와 Windows 확인

전체 C# 소스 빌드와 **11개 자동 검사 프로그램**을 통과했습니다. UI 렌더러·키보드·카드 탐색·설정 이행·행 높이·상태 안내·갱신 추종 검사는 **11,996개 단언**, 실제 새 DLL의 게시·입력·창 연결 검사는 **23개 단언**입니다. 수신 게임 DLL은 읽기 전용 참조로만 사용하며 설치 ZIP에 포함하지 않습니다.

검사는 관리 코드·실제 DLL의 IL·Unity 배치 계약 모델을 대상으로 합니다. **실제 Unity의 한글 줄바꿈·클리핑·마우스 포착·창 드래그·native XInput·게임 입력 중복이 정상이라는 증거는 아닙니다.** 자동 검사만으로 전체 패드 지원이나 기능 완료를 선언하지 않습니다.

[이번 변경의 Windows 확인표](https://github.com/jungpaeng/dicemaster/blob/v1.0.5-alpha.4/docs/ISSUE-4-CARD-NAVIGATION.md)에 따라 여러 카드를 펼친 상태의 ↑↓←→·A·B, 자동 갱신·수동 스크롤, 새 기본값 복구와 설정 보존, 미션의 긴 한글 제목·여러 줄 상태, 대기 안내·새로고침·예약 차단을 확인해 주세요. 이어서 [기존 Windows 검증표](https://github.com/jungpaeng/dicemaster/blob/v1.0.5-alpha.4/docs/ISSUE-4-WINDOWS-VALIDATION.md)의 홀드 상태 닫기·모드 전환·재연결·Alt-Tab·주사위 왕복·입력 중복도 확인합니다. **사용자가 실제 게임의 패드 탐색·스크롤·버튼 조작과 주요 회귀를 확인한 뒤 완료 여부를 결정합니다.**

로그 열기는 기존 `[DiceMaster].LogMenuToggleKey`(기본 **Tab**)이며 패드 열기 조합은 없습니다. 이벤트·미션 버튼은 즉시 발생을 보장하지 않는 기존 **예약** 기능입니다. 키보드·마우스 직접 상태 폴링은 보조 콜백 차단 범위 밖이고, 미확인 Steam Input 구성·모든 패드의 호환성을 보장하지 않습니다. 자세한 조작·지원 경계는 [패드 안내](https://github.com/jungpaeng/dicemaster/blob/v1.0.5-alpha.4/docs/GAMEPAD.md)를 따릅니다.

## 설치와 복구

설치 파일은 **`DiceMaster-v1.0.5-alpha.4.zip`**입니다. GitHub의 자동 `Source code` 압축 파일과 구분해 주세요. ZIP에는 `config/DiceMaster.cfg`, `plugins/DiceMaster/DiceMaster.dll` 두 파일만 포함합니다.

1. 게임을 종료하고 현재 DLL과 `BepInEx/config/DiceMaster.cfg`를 게임 폴더 밖에 백업합니다.
2. ZIP을 임시 폴더에 풀고 해시를 확인한 뒤 **DLL만** `BepInEx/plugins/DiceMaster/DiceMaster.dll`에 교체합니다. 기존 설정을 유지하며 설정 파일을 임의로 삭제하거나 패키지 기본 설정으로 덮어쓰지 않습니다.
3. 새 기본 크기가 필요하면 도구의 **창 위치·크기·글자 기본값 복구**를 사용합니다. 1080p에서는 1280×960/20px가 됩니다.
4. 문제가 있으면 게임을 종료하고 백업 DLL과 필요한 설정을 복원합니다. 기본값 이행으로 저장된 창 설정까지 되돌리려면 백업 설정도 복원하세요. 필요하면 이전 [alpha.3](https://github.com/jungpaeng/dicemaster/releases/tag/v1.0.5-alpha.3) 또는 정식 [v1.0.4](https://github.com/jungpaeng/dicemaster/releases/tag/v1.0.4)의 DLL로 돌아갈 수 있습니다. 세이브 형식은 변경하지 않습니다.

| 파일 | 크기 | SHA-256 |
| --- | ---: | --- |
| `DiceMaster.dll` | 582,144바이트 | `06485af8929579f6f7d3744f183aa3359ec40545a6d155257c4bfebadc3b7d44` |
| `DiceMaster-v1.0.5-alpha.4.zip` | 244,710바이트 | `a9a63593a85d78324975c6e989293a8b582a48d1589c0213425d2e17eb79aa7a` |
| ZIP 내부 `config/DiceMaster.cfg` | 10,614바이트 | `b351703e2b0f1b5ea6b4a5894c1f5309a13dece5d6b06ed909330c0771801259` |

다운로드한 ZIP과 압축을 푼 폴더의 DLL을 Windows PowerShell로 대조합니다.

```powershell
Get-FileHash .\DiceMaster-v1.0.5-alpha.4.zip -Algorithm SHA256
Get-FileHash .\plugins\DiceMaster\DiceMaster.dll -Algorithm SHA256
```

결과에는 DLL 해시·해상도/배율/창 모드·게임/로더/패드/Steam Input 환경·재현 순서·탭/항목 ID와 관련 BepInEx 최초 실패/복구 로그를 남겨 주세요.
