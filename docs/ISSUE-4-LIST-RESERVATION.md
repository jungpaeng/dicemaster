# PRD #4 후속 — 목록에서 바로 예약

이벤트·미션에서 선택된 목록 항목에 새 A 입력을 주면 기존 예약을 바로 건다. 상세의 예약 버튼과 상세 진입 단계를 없애고, 포커스는 목록에 유지한다. 이 문서는 alpha.7 이후의 **미게시 로컬 후보**를 설명한다. 이전 공개 자산과 후보는 보존한다.

## 조작과 상태 표시

| 조작 | 동작 |
| --- | --- |
| ↑↓ / 왼쪽 스틱 | 선택 가능한 목록 항목 이동. 실제 값이 없는 최하단 미션 안내 행은 건너뜀 |
| 선택된 이벤트·미션에서 새 A / Enter / Space | 최신 유효 대상의 기존 예약을 한 번 설정 |
| 선택이 없을 때 A / Enter / Space | 첫 선택 가능한 항목만 선택. 같은 입력으로 예약하지 않음 |
| 마우스·터치 | 다른 항목을 누르면 선택만 변경. 선택된 항목을 다시 누르고 같은 항목에서 떼면 예약 |
| ← / → | 상세로 포커스를 이동하거나 예약하지 않음 |
| 오른쪽 스틱 | 선택이 있으면 상세 본문, 선택이 없으면 목록 스크롤 |
| B / Escape | 목록에서 바로 닫기. 도구에서는 목록으로 복귀 |
| Y / X / LB·RB | 기존 도구 / 한 번 새로고침 / 탭 이동 |

상세는 전체 남은 높이를 쓰는 읽기 전용 영역이다. 예약 상태와 예약 가능한지를 별도로 표시한다.

- `활성화 (예약 중)` / `비활성화 (예약 없음)`: 해당 원본 대상이 현재 예약 필드에 남아 있는지 표시한다. 게임이 예약을 소비하면 다음 그리기에서 바뀐다.
- `예약 가능`: 현재 게시된 최신 정상 대상에 새 확인 입력으로 예약할 수 있다.
- `예약 불가`: 조회 대기·실패·이전 값·대상 없음·게시 실패 등의 이유를 표시한다. 읽을 수 있는 실제 항목은 계속 선택할 수 있다.

`이벤트 우선 예약`은 다음 해당 판정의 가중치를 높이는 기존 예약이며, 지정 이벤트의 즉시 발생을 보장하지 않는다. `미션 조건 통과 예약`은 기존 조건 통과 예약이며 즉시 실행·행동 재개를 보장하지 않는다. A를 다시 누르는 동작은 기존 예약을 다시 설정한다. 별도 예약 취소·켜기/끄기 기능은 추가하지 않는다.

선택지는 접기·선택 없는 읽기 전용 본문을 유지한다. 조건은 목록 선택과 오른쪽 스틱 설명 스크롤을 유지하며 A·좌우로 예약하거나 읽기 전용 상세에 진입하지 않는다. 검색 없는 네 탭, 한국어 표시·조건 분기·읽음 표시·주사위·설정·전체 창 드래그와 필요한 경우에만 보이는 스크롤바를 유지한다. 패드 열기는 alpha.7의 시간 제한 없는 같은 패드 L3/R3 겹침과 해제·중립 보호를 그대로 사용한다.

## 입력과 예약 경계

`LogRenderer`의 상세 영역 상태를 제거했다. 새 확인 입력마다 현재 선택에서 일회 티켓을 만들고 `LogTabState.CanActivate` → `LogBridge.TryReserve`로 검증한다. 성공·거부·예외 후 `finally`에서 실행 권한을 해제한다. 제목·본문·상태 텍스트를 그리거나 포커스를 이동하는 것만으로 예약하지 않는다.

마우스·터치는 이미 선택된 행의 **누름 시점**에만 티켓을 캡처한다. 해제 시 티켓을 새로 만들지 않으며 원래 컨트롤·문맥과 대상을 다시 확인한다. 다른 행 선택·키/패드 조작·도구·탭·새로고침·포커스 상실·새 문맥은 진행 중 포인터 예약을 취소한다. 같은 ID라도 대상 객체가 교체되면 이전 티켓을 거부한다.

모델과 Bridge의 기존 선택 버전·문맥·탭·ID·원본 객체·현재 게시/게임 데이터 멤버십 검증은 변경하지 않는다. 실제 대상이 없거나 대기·실패·이전 값·게시 실패인 상태에서는 예약하지 않는다. 자동 갱신에서 유효 선택은 유지하되 대상 소멸·교체와 새 문맥은 이전 선택/권한을 취소하며 회복만으로 예약하지 않는다.

실제 controller의 새 버튼 에지·홀드 반복 방지·소유권·연결/초점 변경·해제/스틱 중립 대기와 게임 입력 차단을 유지한다. 도구에서 돌아왔다는 이유로 실행 권한을 만들지 않는다. Tab 진입 시 게임의 입력 모드가 바뀌는 기존 경로는 이번 변경의 수정 범위에 포함하지 않는다.

1. 게임을 종료하고 기존 `BepInEx/plugins/DiceMaster/DiceMaster.dll`과 `BepInEx/config/DiceMaster.cfg`를 게임 폴더 밖에 백업한다.

## Windows 확인표

다음 항목은 모두 **사용자 확인 대기**다. 에이전트는 게임을 설치하거나 실행하지 않았다. 자동 검사만으로 실제 패드·화면·이슈 #4 완료를 판단하지 않는다.

| 순서 | 조작 | 확인할 결과 |
| --- | --- | --- |
| 1 | 기존 cfg 보존 적용 후 L3/R3 겹침 또는 설정 키로 열기 | 배치·번역 유지. 패드로 연 뒤 해제·중립 후 첫 새 입력 정상 |
