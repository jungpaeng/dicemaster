# DiceMaster v1.0.5-alpha.5

alpha.4 이후 요청한 창 초기 크기, 탭 배치, 예약 버튼 포커스, 패드 모드의 터치 접근, 검색 제거와 미션 안내 행 처리를 모은 **테스트용 prerelease**입니다. 소스 커밋 `70e045e17351ffd01ff0e19f5f8ba638b2b062c4`의 깨끗한 재빌드·11개 검사와 검토 후보의 DLL·설정·ZIP 해시 일치를 확인했습니다. 인증 없는 공개 다운로드의 바이트·해시까지 확인했습니다. **이 후보의 실제 Windows 게임 확인은 아직 하지 않았으며 [이슈 #4](https://github.com/jungpaeng/dicemaster/issues/4)는 미완료로 유지합니다.**

## 이번 변경

- **창 크기와 첫 표시:** 기본 너비는 화면의 60%, 높이는 70%로 맞춥니다. 유효한 화면에서 로그를 처음 표시할 때 cfg를 읽어 적용하고, 초기화 중 작은 화면 값이나 무효 화면 값으로 설정을 저장하지 않도록 합니다. 1920×1080에서는 1152×756·본문 20px입니다. 1440p에서는 1536×1008·27px, 4K에서는 2304×1512·40px입니다. 창과 주요 조작은 화면 안으로 보정합니다.
- **선택지·조건 배치:** 선택지는 여러 효과를 비교하도록 본문을 항상 보여줍니다. 접기·펼침 조작은 제거했습니다. 조건은 왼쪽 체크포인트 목록과 오른쪽 전체 설명으로 나눕니다. 네 탭은 유지하고 남는 본문 영역은 목록·상세·스크롤에 배정합니다.
- **조작 가능한 상세로 바로 이동:** 이벤트·미션에서 A 또는 오른쪽으로 진입하면 현재 사용할 수 있는 예약 버튼에 바로 초점을 줍니다. 상세 제목은 초점을 받지 않습니다. 조건처럼 조작할 버튼이 없는 상세, 대기·실패·이전 값 또는 없어진 대상에는 진입하지 않습니다. 조건은 목록의 ↑↓로 선택하고 오른쪽 스틱으로 상세를 읽습니다.
- **터치와 커서 접근:** 로그가 열리고 게임에 초점이 있을 때 커서 잠금을 임시로 해제하고 표시합니다. 닫기·초점 상실·비활성화 시 관찰한 게임 커서 상태를 복원합니다. 같은 문맥의 새 마우스·터치 조작은 모드 전환 중에도 유지하며, 이전 패드 입력과 무효 대상의 예약 입력은 취소합니다. 실제 Windows 터치 이벤트 전달과 기기 동작은 확인 대기입니다.
- **검색 완전 제거:** 네 탭의 검색창, 검색 지우기, 화면 자판, 필터와 검색 상태를 제거했습니다. 게시된 전체 항목과 진단 행을 표시하며 도구는 17개입니다. 물리 키보드의 탐색·확인·복귀는 유지합니다.
- **미션 안내 행 정리:** 실제 미션 값이 없는 `미션 정보 / 설명 조회 대기` 같은 안내는 일반 미션 뒤 최하단에 모으고 비활성으로 표시합니다. 마우스·터치·키보드·패드로 선택하거나 예약할 수 없습니다. 실제 미션 값이 남아 있는 대기·실패 항목은 설명을 선택해 읽을 수 있고 예약만 차단합니다.

`설명 조회 대기`는 현재 설명을 얻지 못했다는 뜻입니다. 항상 로딩 중이거나 미션 미완료·조건 미충족이라는 뜻은 아닙니다. 안내에는 원본 ID와 상태·재조회 설명을 남깁니다. 마지막 일반 항목에서 ↓를 누르면 선택을 유지한 채 안내 영역을 읽도록 스크롤하고, 안내 행만 있는 목록도 오른쪽 스틱으로 읽을 수 있습니다.

로그 열기는 기존 `[DiceMaster].LogMenuToggleKey`(기본 **Tab**)를 사용하며 패드 열기 조합은 없습니다. LB/RB 탭, ↑↓ 항목 이동, A 확인, B 복귀·닫기, 오른쪽 스틱 본문 읽기, Y 도구, X 새로고침을 유지합니다. 창은 빈 본문을 포함한 드래그 가능한 영역에서 이동할 수 있습니다. 버튼·스크롤 같은 활성 조작은 우선합니다.

이벤트·미션의 **예약**은 즉시 발생을 보장하지 않습니다. 버튼에 진입한 입력을 해제한 뒤 별도의 새 확인 입력으로 예약합니다. 대상 소멸·새 문맥은 이전 선택과 실행 권한을 취소합니다. 조회 실패·게시 실패는 예약 권한을 취소하되 읽을 수 있는 기존 값과 유효 선택은 보존할 수 있으며, 자동 회복만으로 예약 권한이 되살아나지 않습니다. 자동 갱신 중 같은 유효 항목의 선택·스크롤 유지와 직접 스크롤한 뒤 다음 탐색부터 선택 추종을 재개하는 규칙도 보존합니다.

이전 기본 배치와 위치·너비·높이·글자 크기가 모두 일치하는 설정만 새 기본값으로 이행합니다. 사용자 지정 값은 화면 안에서 보존합니다. 창 위치·크기·글자는 기존 BepInEx cfg에 저장하고, 선택·스크롤과 실행 포커스는 실행 중 상태입니다. 검색 상태와 접힘 상태는 제거했습니다.

고정 소스 커밋의 재빌드는 전체 C# 소스 빌드에서 오류 0개·기존 경고 7개이며 **11개 검사 프로그램을 모두 통과**했습니다.

관리 코드 대역·실제 DLL의 IL·배치 계약 모델 검사는 **실제 Unity의 한글 줄바꿈·클리핑·커서·터치·창 드래그·native XInput·게임 입력 중복이 정상이라는 증거가 아닙니다.** 이전 Windows 확인 기록도 이번 GUI·입력 변경을 검증하지 않습니다. 에이전트는 게임을 설치하거나 실행하지 않았습니다. 자동 검사만으로 전체 패드 지원이나 이슈 완료를 선언하지 않습니다.

## 설치와 복구

설치 자산은 **[DiceMaster-v1.0.5-alpha.5.zip](https://github.com/jungpaeng/dicemaster/releases/download/v1.0.5-alpha.5/DiceMaster-v1.0.5-alpha.5.zip)**입니다. GitHub의 자동 `Source code` 압축 파일과 구분합니다. ZIP에는 `config/DiceMaster.cfg`, `plugins/DiceMaster/DiceMaster.dll` 두 파일만 포함합니다.

1. 게임을 종료하고 현재 `BepInEx/plugins/DiceMaster/DiceMaster.dll`과 `BepInEx/config/DiceMaster.cfg`를 게임 폴더 밖에 백업합니다.
2. ZIP을 임시 폴더에 풀고 아래 해시와 대조한 뒤 **DLL만** 플러그인 경로에 교체합니다. 기존 cfg를 보존합니다. 패키지 cfg 전체 교체는 새 설치용이며 이번 업데이트에 필요하지 않습니다.
3. Tab 또는 기존 열기 키로 로그를 엽니다. 새 기본 배치가 필요하면 도구 → **창 위치·크기·글자 기본값 복구**를 사용합니다. 1080p에서 1152×756·20px가 됩니다.
4. 문제 발생 시 게임을 종료하고 백업 DLL과 필요한 cfg를 복원합니다. 기본값 이행으로 저장된 배치까지 되돌리려면 백업 cfg도 복원합니다. 이전 [alpha.4](https://github.com/jungpaeng/dicemaster/releases/tag/v1.0.5-alpha.4) 또는 정식 [v1.0.4](https://github.com/jungpaeng/dicemaster/releases/tag/v1.0.4) DLL로 복구할 수 있습니다. 세이브 형식은 변경하지 않습니다.

| 파일 | 크기 | 검토한 후보 SHA-256 |
| --- | ---: | --- |
| `DiceMaster.dll` | 577,024바이트 | `1ce1f0fa8d4d0dba626102c787c5e382cea5414861c050397ab4e506fe2b50d0` |
| `DiceMaster-v1.0.5-alpha.5.zip` | 242,186바이트 | `4b15898c0c2eee42c6680839fb884403d93f779429d8452a6aa98e4965c61c8c` |
| ZIP 내부 `config/DiceMaster.cfg` | 10,729바이트 | `fce24616e5380004bc87aa992871407386d90bf1b6ec6f30116a29347fe0f046` |

Windows PowerShell에서 ZIP과 압축을 푼 폴더의 DLL을 확인합니다.

```powershell
Get-FileHash .\DiceMaster-v1.0.5-alpha.5.zip -Algorithm SHA256
Get-FileHash .\plugins\DiceMaster\DiceMaster.dll -Algorithm SHA256
```
