# DiceMaster v1.0.4-alpha.5 — 정적 분석 공유·안전한 현재 조건 힌트

선택지 사이의 공통 구문·인자·상수 분석을 재사용하는 prerelease입니다. 정식 Latest는 [v1.0.3](https://github.com/jungpaeng/dicemaster/releases/tag/v1.0.3)을 유지합니다.

## 변경 사항

- 공통 본문의 토큰뿐 아니라 호출·분기·블록 경계, 정규화 인자와 상수 검증 계획을 공유합니다. 선택지별 효과·분기 번호·후속 대상·논리 추적 예산은 각각 계산합니다.
- 실제 공유 작업 자료 1,680,299자·294,681토큰에 맞춰 캐시를 **64항목·2,097,152자·524,288토큰**으로 제한합니다. 현재 상태·읽기 실패·선택지 결과는 이 캐시에 저장하지 않으며 기존 문맥 초기화와 5초 읽기 재시도를 유지합니다.
- 안전한 문맥에서 확인되는 현재 조건에만 **현재 조건 충족(녹색) / 현재 조건 미충족(회색)**을 덧붙입니다. 현재값은 표시할 때 읽고 미래 보상이나 실제 진행 분기를 확정하지 않습니다.
- 기존 **가능한 변화 / 이후 가능한 변화**, 50자 선택지 요약·전체 로그, 설정·세이브 형식과 로그·난수·수명주기·주사위·패드 계약을 유지합니다.

## 현재 조건 표시의 적용 제한

**이번에 제공된 실제 Lua의 선택지는 모두 중립 표시를 유지합니다.** 매핑 선택지 3,214개와 전체 후보 선택지 3,530개는 선택과 결과 사이의 생략된 UI 콜백 문맥을 입증하지 못해 `RootConditional` 경계를 유지합니다. 새 색상이 이 선택지들에 나타난다고 주장하지 않습니다.

현재 조건 읽기·색상 기능은 안전한 합성 문맥에서 검사했습니다. 선행 상태 변경·알 수 없는 호출/대입·재바인딩·콜백·후속 이야기·미입증 바깥 문맥·난수·실행 횟수 의존 조건은 판정을 보류합니다. 원본 `Switch/Condition/Execute`나 게임 Lua·RNG·상태 변경 API를 실행하지 않습니다. 전체 Lua·세이브·인자 원문은 진단 로그에 남기지 않습니다.

## 측정한 성능

Mac .NET 대역에서 공개 alpha.4와 순서를 교대한 측정이며 Windows/Unity 프레임 시간이나 상주 메모리 측정이 아닙니다.

| 범위 | alpha.4 | alpha.5 |
| --- | ---: | ---: |
| 무거운 7선택지 사례 정적 추출 평균 | 483.78ms | 335.94ms |
| 같은 추출의 스레드 누적 할당 | 166.81MB | 66.81MB |
| 번체 이야기 2,198개 전체 검사 평균 | 13.124초 | 12.542초 |
| 전체 검사 스레드 누적 할당 합 | 6.141GB | 5.060GB |

선택한 무거운 사례의 추출 시간 약 **30.56%**, 전체 검사 시간 약 **4.43%** 감소입니다. 작은 root의 중앙값은 조금 늘었고 p95는 비슷했습니다. 모든 경로가 30% 빨라졌다는 뜻이 아닙니다. **약 0.34초의 동기 추출 지연은 남으며 프레임 분할은 구현하지 않았습니다.**

## 검사와 남은 확인

- 전체 소스 빌드의 8개 검사 묶음과 미리보기 **1,453개** 단언을 통과했습니다. 1,000개 연속 elseif에서도 효과 1,002개를 보존하고 깊은 현재 판정은 중립으로 제한했습니다.
- 실제 번체 이야기 **2,198본문·3,214선택지·63,967호출 기록**을 두 번 대조했습니다. 루트 검사는 **2,667본문·3,530선택지·14,728호출 기록**입니다. 등록·표시·검증 불가 호출도 포함하며 보상 횟수가 아닙니다.
- alpha.4와 호출·분기·이유·설명 해시·논리 예산이 동일하고 추가/누락 호출은 0개입니다. 독립 원문 호출·출처·인덱스 대조의 실패와 금지 경계 호출은 0개입니다.
- 비교·복구용 injector의 첫/반복 적용, 기존 메서드·내장 리소스 보존 검사도 통과했습니다. 읽기 전용 원본 176개 파일 해시와 설정은 그대로입니다.

추적 한도는 깊이 8·고유 이야기 32·누적 1,310,720자·262,144토큰·524,288작업을 유지합니다. 기존 한도 영향 54개 선택지는 부분 분석으로 남습니다. 호출 보존은 모든 임의 Lua 효과의 완전성·조건의 진리나 실제 실행 결과를 증명하지 않습니다.

실제 게임 UI·현재 상태·Unity/native/Harmony·다른 모드·Windows 실행과 프레임/상주 메모리 비용은 미확인입니다. 과거 Windows 확인을 승계하지 않으며 **PRD #2 전체 완료·이슈 종료로 처리하지 않습니다.** Windows 설치·게임 실행·오류 주입을 수행하거나 요청하지 않았습니다.

상세 근거는 [정적 분석 공유·현재 조건 검증 기록](https://github.com/jungpaeng/dicemaster/blob/main/docs/ISSUE-2-SHARED-ANALYSIS.md)에 있습니다. 게시 전 고정 소스 커밋에서 새로 빌드해 아래 검토한 DLL·설정·ZIP 해시와 같은지 다시 확인합니다.
