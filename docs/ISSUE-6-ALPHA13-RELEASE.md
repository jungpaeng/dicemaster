# PRD #6 alpha.13 — 지도 자동 조회 비용 개선

2026-10-21 18:06:04 KST에 소스·주석 태그 [`53d6f6a`](https://github.com/jungpaeng/dicemaster/commit/53d6f6a2165b3c57f786e1920ff2b114e2144719)의 [alpha.13](https://github.com/jungpaeng/dicemaster/releases/tag/v1.0.7-alpha.13)을 게시했다. 전체·고정 커밋 재빌드 21개 검사·254개 입력·104개 소스/리소스·15개 참조·실제 DLL 연결·공개 ZIP 바이트 대조를 통과했다. 기존 54개 Release·55개 태그·자산·Latest v1.0.6·#6 open을 보존했다. **새 DLL의 실제 Windows·물리 입력·가독성·프레임 성능 확인은 대기다.**

## 바뀐 동작

- 실제 등록된 대기 임무·행동력·우선순위를 Lua 경로 준비보다 먼저 읽는다. 1회성 OFF 자동 지도는 Lua 자료를 읽거나 경로를 준비하지 않는다.
- 1회성 ON에서도 자동 대상이 아닌 미증명 일반 이벤트의 숨은 경로 조건·상세 행은 만들지 않는다. 증명된 1회성의 현재 도달성과 현재 조건은 계속 새로 읽고, 전체 후보는 명시적 상세에서 확인한다.
- 준비는 기존 8,192 작업 상한과 약 5 ms 양보 기준을 함께 적용한다. 구문/프로필 작업은 최대 256단위 사이에서 양보 여부를 확인하고 이어서 재개한다. 동기 리소스 읽기·단일 효과 분석의 완료 시간이나 전체 프레임을 제한하는 보장은 아니다.
- 지도·선택 화면이 같은 원문을 다시 읽으면 완성된 정상 구문만 공유한다. 최대 16개·1,310,720 문자·131,072 토큰 LRU이며 현재값·의미 작업·게임 객체는 공유하지 않는다. 원문 누락/변경·더 작은 분석 한도·미완결/오류는 우회하지 않는다. 전체 OFF·로드/장면 해제 시 공유 구문도 지운다.
- 로그 → 도구 → 지도 안내의 `지도 조회 성능`에서 자동 대기/자동 1회성/상세 각각 최근 64회 p95·최대·단계별 평균과 지원되는 런타임의 스레드 할당량을 읽는다. 값은 실행 중 메모리에만 보관한다. 선택 장소 자료 제공자만 측정하며 메타데이터·진단문 생성·로그 UI·전체 프레임은 제외한다.

자동 안내 범위·현재 활성 선택지 출발점·상점 요약·실제 분기 기록·읽기 전용·정상 0.25초/실패 5초·숨김/OFF 중단·패드/입력 소유권·해제/중립은 유지한다. 새 설정·단축키는 없다. 상세의 전체 설명 생성과 로그 UI 비용은 Windows 표본을 보고 추가 판단할 대상이다.

## 자동 검사와 실제 확인의 경계

회귀는 리소스 읽기 수·현재 플래그 읽기 수·현재값 갱신·캐시의 변경/누락/상한·양보 후 재개를 검사한다. 모형 실행은 Windows/Unity FPS 측정이 아니다. 실제 Windows 확인 항목은 [별도 확인표](ISSUE-6-WINDOWS-VALIDATION.md#alpha13--새-성능-확인-대기)를 따른다.

동일한 원본 경로·일반 이벤트 1개·현재 플래그 조건 fixture에서 40회 준비 후 100회 갱신을 비교했다. 이전 기준은 main `359d3c7`이며 자동 행은 전후 모두 비어 있다. Unity 리소스와 게임 객체는 명시적인 관리 코드 경계로 대체했다.

| 설정 | 이전 최초 자료 읽기 | 수정 후 최초 자료 읽기 | 이전 warm 100회 경로 플래그 읽기 | 수정 후 warm 100회 경로 플래그 읽기 |
| --- | ---: | ---: | ---: | ---: |
| 1회성 OFF | 2 | 0 | 100 | 0 |
| 1회성 ON | 2 | 2 | 100 | 0 |

warm 리소스 읽기와 게임 판정 호출은 전후 모두 0이다. 이 수치는 불필요한 작업을 제거했다는 근거이며 실제 Windows의 ms·FPS 개선율이나 전체 자동 경로 비용이 0이라는 뜻이 아니다. 256개 일반 이벤트의 자동 상세 행은 256개에서 0개로 줄고, 명시적 상세에서 256개를 모두 유지하는 회귀도 추가했다.

## 자동 검증 기록

전체 소스 빌드의 21개 검사 프로그램, 254개 빌드 입력·104개 소스/리소스·15개 고정 참조 검증, 실제 DLL 연결·읽기 전용 IL·기존 패드/팝업/로그/예약/주사위 회귀를 통과했다. prerelease 검증 도구 자체의 20개 검사와 git diff --check도 통과했다. 로컬 검증물은 artifacts/issue-6/performance-scope/reviewed에 보존한다. 고정 커밋 재빌드도 동일한 21개 프로그램을 통과했고 검토 DLL/cfg/ZIP과 일치했다. prerelease 게시 후 익명 ZIP 다운로드·정확한 두 경로·CRC·바이트·해시를 대조했다. 로컬 게시 영수증은 artifacts/releases/v1.0.7-alpha.13/release-verification.json 및 anonymous-verification.json에 보존한다.

모드별 성능 표본은 여러 선택 장소의 최근 64회를 합산하므로 같은 장소에서 64회 이상 모은 뒤 비교한다. UI 전체 비용·선택 화면 자체의 프레임 비용은 별도 측정이 필요하다.
