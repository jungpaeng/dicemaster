# PRD #5 — 실제 Windows 확인표

상태: **v1.0.6-alpha.1의 모든 항목 미실행 · 사용자 확인 대기**. 설치 ZIP·해시·고정 소스와 게시 결과는 [배포 안내](ISSUE-5-ALPHA1-RELEASE.md)를 따른다. 이번 로컬 후보의 팝업·결과 직접 지정·조건 무시·화면 전환을 실제 Windows 게임에서 확인하기 위한 표다. 자동 대역 검사와 기존 v1.0.5 확인은 이 표의 실행 결과가 아니다. [구현·지원 범위·후보 생성](ISSUE-5-IMPLEMENTATION.md)을 먼저 대조한다.

## 선행 확인과 이번 대상

2026-10-20 Asia/Seoul에 사용자가 “v1.0.5에서 Windows 확인 완료”라고 답했다. 선행 기준 v1.0.5의 소스·태그는 `8886309e2a7248fa13544f81546e3c4795ff9611`이며 이번 시작 HEAD는 `40813f9`다. 사용자 환경과 개별 항목 결과는 제공되지 않았다. 이 확인은 PRD #4 선행 조건의 근거이며 **이번 PRD #5 후보의 실제 게임 검증은 아니다.**

| --- | --- |
| 시험 일시·확인자 | 미기록 |
| 후보 DLL SHA-256·매니페스트/소스 식별값 | 미기록 |
| 게임·BepInEx·Windows 버전 | 미기록 |
| Xbox/XInput 패드 모델·연결 방식·슬롯 | 미기록 |

| 정상/강제/무작위 시험의 후보군·대상·결과 ID | 미기록 |
| BepInEx 로그·재현 순서·관찰 결과 | 미기록 |

게임 종료 후 기존 DLL/cfg를 백업하고 후보의 **DLL만 교체**해 설정을 보존한다. 후보 생성 경로는 `artifacts/issue-5/candidate/`이며, 실제 시험에 사용한 파일 해시를 먼저 기록한다. 다른 후보·이전 공개 버전의 해시를 대신 적지 않는다.

## 판정·설정·복구

각 항목에 실제 관찰 결과와 재현 순서·관련 token/ID·BepInEx `EventSelection` 로그를 남긴다. 미실행을 통과로 바꾸지 않는다.

- [ ] **미실행** — 최초 설정 누락은 `EnableEventSelectionPopup=true`; ON 저장·재시작 뒤 유지. OFF는 새 팝업과 선택 대기를 생략한다.
- [ ] **미실행** — `EnableOptionInfo=false`로 시작하면 팝업 저장값은 보존하고 표시·대기는 비활성. 상위 옵션을 켜는 재시작 계약을 확인한다.
- [ ] **미실행** — 미확정 대기 중 큰 로그 도구에서 OFF로 바꾸면 숨은 대기가 남지 않고 원래 판정이 한 번 진행된다. 이후 ON은 다음 판정부터 적용한다.
- [ ] **미실행** — 유효한 설정 읽기/평가 실패는 최초 기본값과 구분해 진단하고 대기 없이 원래 게임으로 진행한다. 안전하게 재현할 수 없는 실패는 미실행과 사유를 기록한다.
- [ ] **미실행** — 실제 게임 선택지 → 지원하는 Lua 직접 리터럴 `Position` 코루틴 → 판정 직전 팝업을 확인한다. 미리보기·관련 이벤트 조회·다른 분기만으로 대기하지 않는다.
- [ ] **미실행** — 별칭·변수/동적 인수·메인 Lua·직접 C# 동기 경로 등 지원 밖 호출은 원래 판정으로 진행한다. 확인한 경로만 기록한다.
- [ ] **미실행** — 후보 0개·군/경로 조회 실패는 원래 진행. 전체 정상 후보 1개는 팝업 생략. 하나라도 미충족·가중치 0·미확인이면 팝업 표시. 복수 후보 중 가능 1개여도 나머지를 유지한다.
- [ ] **미실행** — 일반 지정은 현재 후보의 결과를 직접 적용하며 원래 추첨 결과가 추가 실행되지 않는다. 확정 직전 조건이 바뀌면 안내 후 같은 행동에서 재선택할 수 있다.
- [ ] **미실행** — 조건 미충족·최종 가중치 0·난수/미지원으로 미확인인 읽기 가능한 후보를 각각 명시 강제 지정한다. 선행 능력치·호감도·스토리 플래그 수정 없이 한 번 진행하며 정상 효과·대화·내부 분기는 유지한다.
- [ ] **미실행** — 대상/결과 읽기 실패·이전 값·소속 불일치·대상 소멸은 일반·강제 모두 거부한다. 미확인을 조건 미충족과 구분한다.
- [ ] **미실행** — 무작위는 지정 없이 원래 조건·가중치·난수로 한 번 진행한다. 연속/중첩 판정·동일 프레임 중복 확정·오래된 콜백에서 결과가 중복 적용되지 않는다.
- [ ] **미실행** — 로드·새 게임·씬/실행 문맥 변경·오래된 코루틴은 이전 token을 폐기하며 이전 결과를 새 흐름에 적용하거나 이전 장면을 재개하지 않는다. 부분 실패 뒤 적용한 효과를 재실행하지 않는다.

## 화면·입력 소유권

- [ ] **미실행** — 큰 로그를 자동으로 열지 않고 좌측 하단 작은 팝업을 표시한다. 초기 초점은 무작위, 가능 후보 우선·그룹 내 원래 순서·대상 ID별 초점을 유지한다.
- [ ] **미실행** — 이름·상태·짧은 조건 설명과 현재 조작 안내를 읽을 수 있다. 긴 한국어·긴 목록·큰 로그 글자·해상도/배율 변경에서 현재 행·조건·진행 버튼이 잘리지 않고 스크롤로 접근된다.
- [ ] **미실행** — 패드 ↑↓·왼쪽 스틱 이동/추적, A 일반 또는 무작위 행 진행, X 명시 조건 무시, B 무작위가 작동한다. 키보드 ↑↓/Enter/Shift+Enter/Esc와 마우스 행 선택 후 세 진행 버튼도 확인한다.
- [ ] **미실행** — 기존 `LogMenuToggleKey`로 팝업을 감추고 큰 로그를 읽어도 실제 행동은 계속 대기한다. 로그를 닫으면 같은 유효 문맥·초점으로 돌아오며 B 닫기를 팝업 무작위로 재사용하지 않는다.
- [ ] **미실행** — 큰 로그의 탭·검색·필터·선택·스크롤과 팝업 초점이 따로 유지된다. 이벤트의 이름/표시 이름·원본 ID·설명 검색, 가능만 필터·전체 설명과 도구의 패드 필터/검색 지우기를 확인한다. 다른 탭에는 검색이 없다.
- [ ] **미실행** — 게임 선택지 A를 누른 채 팝업 진입, 팝업 A/X/B를 누른 채 게임·대화·주사위 복귀에서 입력이 재사용되지 않는다. 전체 버튼 해제·스틱/트리거 중립 뒤 새 입력만 받는다.
- [ ] **미실행** — Alt-Tab·입력 모드 불명/변경·패드 분리/재연결·여러 슬롯·소유자 재선택·길게 누르기·동시 입력에서 미확정 입력을 취소하고 한 화면만 조작한다.
- [ ] **미실행** — 실제 native XInput 차단 경로를 확인한다. 미확인/실패 시 위험한 패드 확정을 막고 키보드·마우스로 복구한다. Steam Input은 시험한 구성만 기록한다.
- [ ] **미실행** — 기존 같은 패드 L3/R3 클릭 겹침 열기·설정 키·Tab과 로그 LB/RB·Y 도구·X 새로고침·B 닫기를 회귀 확인한다. 이번 기능용 새 패드 조합이 없다.

## 순수 조회·기존 기능·배포

- [ ] **미실행** — 표시·검색·정렬·필터 전후 게임 RNG·조건 카운터·예약·세이브가 바뀌지 않는다. 보이는 현재 탭/행동의 0.25초 갱신·실패 5초 재시도·항목 실패 격리·정상 주기 Lua 재분석 없음과 모두 숨김 조회 0을 구분한다.
- [ ] **미실행** — 이벤트 예약 UI·`TargetEvent` 99999 보정이 없고 로그에서 사전 요청을 만들지 않는다. 미션 조건 통과 예약·해제·소속 검증·수명과 기존 한국어/선택지 분석·읽음·대화 기록을 유지한다.
- [ ] **미실행** — 주사위 임의 정수·음수·0 자동, 기존 Xbox/XInput 조정과 로그/팝업/주사위 왕복을 확인한다.
- [ ] **미실행** — 시험 DLL·cfg·두 파일 ZIP·매니페스트 해시를 대조한다. 게임 소스·게임 DLL·새 UI 이력/세이브 파일을 배포하지 않는다.
- [ ] **미실행** — 게임 종료 후 이전 DLL만 복원해 이전 모드 동작으로 돌아간다. 필요한 경우에만 백업 cfg를 복원한다. DLL 복원이 이미 진행·저장한 게임 상태까지 되돌리는 것은 아니다.

자동 검사·관리 코드 시간/할당량 측정과 실제 Unity/Windows 프레임 관찰을 별도 기록한다. 확인하지 않은 다른 운영체제·모든 패드·모든 Steam Input 구성을 지원 완료로 표시하지 않는다. **이번 후보의 사용자 확인 전에는 PRD #5를 완료로 닫지 않는다.**
