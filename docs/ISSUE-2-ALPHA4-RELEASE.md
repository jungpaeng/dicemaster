# DiceMaster v1.0.4-alpha.4 — 실제 Lua 대조·후속 미리보기 보강

실제 게임 리소스를 읽어 선택지 미리보기의 누락·구문 경계·후속 추적을 보강한 prerelease입니다. 정식 Latest는 [v1.0.3](https://github.com/jungpaeng/dicemaster/releases/tag/v1.0.3)을 유지합니다.

## 변경 사항

- 큰 Lua의 선택지 누락, 안쪽 인덱스 주석에 의한 분기 잘림, 같은 이름의 지역변수·함수·재대입을 잘못 결합하는 경우를 수정합니다.
- 추출하며 제거된 조건과 choose 뒤 공통 실행 구간의 불확실성을 유지합니다. 현재 상태를 실행 시점 상태로 가정할 수 없으면 확정 예상량 대신 **가능한 변화**로 표시합니다.
- `SetCurrentStoryScript`도 후속 등록으로 추적하고, `SetEnableActions`는 실제 의미에 맞게 이야기 조작 허용·차단으로 표시합니다.
- 가까운 후속 경로부터 분석하는 유한 큐를 사용합니다. 재바인딩 문맥·순환·합류·최종 등록 덮어쓰기를 구분하고 다음 사용자 선택에서 멈춥니다.
- 선택지·이벤트의 공통 본문 토큰을 제한된 캐시로 재사용하고 임시 문자열 할당을 줄입니다. 긴 본문은 예산 안에서 이미 확인한 효과를 유지합니다.
- alpha.3의 **가능한 변화 / 이후 가능한 변화**, **[경우 A] / [경우 B · 그 외]**, 50자 요약·로그 전체 설명을 유지합니다. 색은 갈래 구분이며 조건 충족 판정이 아닙니다.

## 확인한 범위

원본을 수정하거나 게임 Lua를 실행하지 않고 TextAsset 2,685개와 정확한 번체 이야기 리소스 경로 2,198개를 대조했습니다. 실제 후보 DLL의 분석 IL을 읽기 경계 대역에 연결한 검사입니다.

- 번체 이야기 **2,198개·선택지 3,214개**를 두 번 정적 대조하고 동일한 의미 결과를 확인했습니다.
- 공개 alpha.3 및 이전 로컬 후보와 비교한 공통 선택지에서 호출 기록·선택지 손실 **0**을 확인했습니다. 호출 기록은 등록·표시·검증 불가 호출도 포함하며 보상 횟수가 아닙니다.
- 전체 Lua 후보 2,667개에서 선택지 3,530개를 발견했습니다. 기존 독립 인덱스 기준의 미발견 37개와 인위적인 분기 잘림을 해소했습니다.
- 미리보기 **1,231단언**, 파서·요약·로그 통합 **139단언**, 기존 보호·수명주기·관리 API·패드·번역/주사위 검사와 injector 최초·반복 적용 검사를 통과했습니다.
- 읽기 전용 원본 176개 파일과 이전 공개 배포를 보존했습니다. 입력 130개·설치 ZIP CRC·정확히 두 파일·DLL/설정 바이트를 확인했습니다.

호출의 원본 존재·보존은 모든 효과의 완전성, 조건의 진리, 확정 보상이나 실제 저장 이후 상태를 증명하지 않습니다. 상세 근거는 [실제 Lua 정적 검증 기록](https://github.com/jungpaeng/dicemaster/blob/main/docs/ISSUE-2-REAL-LUA-VALIDATION.md)에 있습니다.

## 지원 경계와 남은 확인

추적은 깊이 8·루트 포함 고유 스크립트 32·누적 1,310,720자·262,144토큰·524,288작업으로 제한합니다. 실제 자료의 54개 선택지는 깊이 또는 문자 한도의 영향을 받아 부분 분석으로 표시합니다. 동적 대상·지원 밖 Lua·미증명 조건은 **추가 영향 가능 / 결과는 진행 후 확인**으로 남습니다.

무거운 7선택지 사례에서 macOS의 동기 정적 추출이 약 **0.49초** 걸리는 성능 한계가 있습니다. 이 수치는 Windows·Unity 프레임 시간이 아니며 실게임의 화면·현재 상태 수치·진행·native/Harmony·프레임/메모리 비용은 미검증입니다. 과거 Windows 확인을 이번 DLL에 승계하지 않습니다. PRD #2 전체나 이슈 완료를 선언하지 않으며 이슈는 open으로 유지합니다.

표시를 위해 게임 Lua·상태 변경 API·게임 RNG·원래 조건 실행 사슬을 실행하지 않습니다. 전체 Lua·세이브·인자 원문을 진단 로그에 남기지 않습니다. 기존 설정·세이브 형식과 로그·난수·수명주기·주사위·패드 계약을 유지합니다.
