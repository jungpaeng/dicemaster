# PRD #4 후속 — 목록 예약 표시와 예약 해제

이벤트·미션 목록에서 선택과 관계없이 현재 예약된 항목에 `(예약 중)`을 표시한다. 예약된 항목에 새 A 입력을 주면 예약을 해제하고, 예약되지 않은 항목에는 기존 예약을 설정한다. 이 문서는 alpha.9 게시 전 로컬 검토 후보를 만든 당시 기록이다. **2026-10-19 23:23:31 KST에 [v1.0.5-alpha.9](https://github.com/jungpaeng/dicemaster/releases/tag/v1.0.5-alpha.9)로 게시했다.** 고정 소스 `7d9c9ec0cfaadbb968c35cfaa5111912c1c68f45`의 깨끗한 재빌드·12개 검사와 공개 ZIP 검증을 통과했으며 [설치·게시 검증·Windows 확인](ISSUE-4-ALPHA9-RELEASE.md)을 따른다. 아래 후보 해시·검사는 게시 파일과 같다. 이전 공개 자산과 후보를 보존하며 실제 Windows 확인과 이슈 #4 완료는 사용자 확인 대기다.

## 조작과 표시

| 조작·표시 | 동작 |
| --- | --- |
| 목록의 `(예약 중)` | 해당 원본 대상이 현재 예약 슬롯에 있는지 표시한다. 다른 항목을 선택해도 예약된 행의 표시는 유지한다. |
| 선택된 이벤트·미션에서 새 A / Enter / Space | 예약되지 않았으면 예약하고, 같은 대상이 예약 중이면 해제한다. 누른 채 유지하거나 버튼을 떼는 것만으로 반복하지 않는다. |
| 선택이 없을 때 A / Enter / Space | 첫 선택 가능한 항목만 선택한다. 같은 입력으로 예약하거나 해제하지 않는다. |
| 마우스·터치 | 다른 행을 처음 누르면 선택만 변경한다. 이미 선택된 행을 다시 누르고 같은 행에서 떼면 예약 또는 해제한다. |
| ↑↓ / 왼쪽 스틱 | 목록 선택을 이동한다. 실제 대상이 없는 최하단 안내 행은 선택하지 않는다. |
| ← / → | 읽기 전용 상세로 진입하거나 예약을 변경하지 않는다. |
| 오른쪽 스틱 | 선택이 있으면 상세 본문, 선택이 없으면 목록을 스크롤한다. |
| B / Escape | 목록에서 바로 닫는다. 도구에서는 목록으로 복귀한다. |
| Y / X / LB·RB | 기존 도구 / 새로고침 / 탭 이동을 유지한다. |

상세의 예약 버튼·별도 포커스는 다시 추가하지 않는다. 상세는 `활성화 (예약 중)` / `비활성화 (예약 없음)`과 `예약 가능` / `예약 해제 가능` / `예약 변경 불가 · 이유`를 읽기 전용으로 표시한다. 실제 예약이 소비되거나 다른 대상으로 바뀌면 다음 그리기에 목록과 상세 표시가 바뀐다. 목록 선택·본문 읽기·스크롤·그리기만으로 예약을 변경하지 않는다.

선택지는 선택 없는 읽기 전용 본문, 조건은 목록 선택과 분기 설명을 유지한다. 이 두 탭에서 A로 예약하거나 해제하지 않는다. 검색 없는 네 탭, 한국어·읽음 표시·자동 갱신·창/글자 설정·전체 창 드래그·필요한 경우에만 보이는 스크롤바와 주사위 기능을 유지한다. L3/R3 겹침 열기, 기존 설정 키와 패드 입력 소유권·해제/중립 보호도 유지한다.

## 예약과 해제의 범위

`이벤트 우선 예약`은 다음 해당 판정에 가중치를 주는 기존 일회 예약이다. 지정 이벤트의 즉시 발생을 보장하지 않는다. `미션 조건 통과 예약`은 다음 해당 미션 검사에 적용하는 기존 일회 예약이며 즉시 실행·행동 재개를 보장하지 않는다.

해제는 아직 남아 있는 예약을 없애는 동작이다. 이미 소비된 판정 결과, 진행된 이야기·미션, 게임이 반영한 상태를 되돌리지 않는다. 해제 후 다시 예약하려면 최신 유효 대상을 선택한 채 새 확인 입력을 준다.

예약과 해제 모두 현재 선택된 최신 정상 대상에서만 허용한다. 조회 대기·실패·이전 값·게시 실패, 대상 없음·소멸·교체, 오래된 문맥이나 실제 게임 데이터에 더 이상 없는 대상은 변경하지 않는다. 이전 예약 표시가 남아 있다는 이유로 이 검증을 우회하지 않는다. 읽을 수 있는 실제 행은 계속 선택할 수 있으며 예약 변경 불가 사유를 상세에 표시한다.

## 지연 입력과 실제 게임 데이터 검증

새 확인 입력 또는 이미 선택된 행의 포인터 **누름 시점**에 예약 슬롯의 상태를 캡처한다. 불변 스냅샷에는 문맥·탭·원본 슬롯 객체와 변경 세대가 들어간다. UI 모델의 일회 티켓은 이 스냅샷을 그대로 보관한다. 조회 실패는 정상적인 `예약 없음`과 구분하며, 캡처하지 못하면 아무 작업도 하지 않는다.

관측된 예약 조회 실패는 이전 스냅샷도 무효화하므로 같은 슬롯으로 회복해도 오래된 누름을 받지 않는다.

포인터를 떼는 순간 현재 표시를 보고 예약/해제를 다시 결정하지 않는다. 원래 누른 컨트롤·문맥·선택 버전·ID·대상과 스냅샷을 재검증한 뒤 같은 슬롯·같은 변경 세대일 때만 원래 의도를 적용한다. 누르는 동안 예약이 소비되거나 다른 대상으로 교체되면 이전 누름을 거부한다. 예약이 소비된 후 같은 객체가 다시 예약되는 A→없음→A 변화도 실제 소비·예약 변경 알림의 세대로 구분한다.

다른 행 선택·키/패드 조작·도구·탭·새로고침·초점 상실·새 문맥은 진행 중 포인터 예약을 취소한다. 게시 실패 후 회복하거나 같은 대상이 재등장한 것만으로 이전 티켓을 살리지 않는다. 성공·거부·예외 후에는 `finally`에서 실행 권한을 해제한다. 버튼 에지·홀드 반복 방지와 연결/모드 변경·버튼 해제·스틱/트리거 중립 대기는 기존 controller 계약을 따른다.

최종 변경은 기존 Bridge의 선택·게시 정체성과 실제 게임 데이터 멤버십 검증을 거친다. 검증을 위해 Lua나 게임의 실행·판정 함수를 호출하지 않는다. 이전 `TryReserve` 호환 경로는 유지하고 새 UI는 스냅샷이 필요한 토글 경로를 사용한다.

## 미션 활성 항목의 안전한 복구

기존 미션 예약은 일회 `TargetMission`뿐 아니라 게임의 활성 미션 사전에 항목을 넣을 수 있다. 이번에는 이 예약이 **직접 바꾼 항목만** 기록한다. 예약을 해제할 때 관리자·사전 객체·키·현재 값이 모두 그 기록과 같으면 원래 값이 있던 자리는 복원하고, 원래 없던 자리는 제거한다. 다른 대상으로 예약을 바꿀 때도 아직 소유 중인 이전 주입만 정리한다.

예약 전부터 게임의 정상 활성 항목이 같은 대상을 가리켰다면 소유권을 만들지 않는다. 해제해도 정상 활성 항목을 삭제하지 않는다. 게임이 사전을 다시 만들거나 값을 바꾼 경우, 예약을 소비한 경우, 새 문맥으로 이동한 경우에는 복구 기록을 버리고 게임 상태를 건드리지 않는다. 이미 진행·소비된 미션을 이전 단계로 되감는 기능이 아니다.

기존 위치 클릭 안내는 미션 예약이 없을 때 현재 위치의 미션을 자동 지정할 수 있다. 명시적으로 해제한 미션이 안내를 다시 보는 것만으로 즉시 재예약되지 않도록, **같은 문맥에서 마지막으로 해제한 원본 미션 대상**의 자동 지정만 억제한다. 위치·미션 안내 출력은 계속한다. 다음 명시적 미션 예약 또는 새 문맥에서 이 억제를 해제한다. 전체 미션 기능을 끄거나 이후 게임 진행·판정을 막는 기능은 아니다.

## 적용·복구

1. 게임을 종료하고 현재 `BepInEx/plugins/DiceMaster/DiceMaster.dll`과 `BepInEx/config/DiceMaster.cfg`를 게임 폴더 밖에 백업한다.
2. 후보 ZIP을 임시 폴더에 풀고 위 SHA-256을 확인한다.
3. **DLL만** `BepInEx/plugins/DiceMaster/DiceMaster.dll`로 교체한다. 새 설정 키가 없으므로 기존 cfg를 보존한다.
4. 문제 시 게임 종료 후 백업 DLL을 복원한다. [alpha.8 설치·해시](ISSUE-4-ALPHA8-RELEASE.md)로 복구하면 목록 직접 예약 방식으로 돌아가며 A 예약 해제와 목록의 예약 마커는 없어진다.

```powershell
Get-FileHash .\DiceMaster-source-candidate.zip -Algorithm SHA256
Get-FileHash .\plugins\DiceMaster\DiceMaster.dll -Algorithm SHA256
```

| 7 | 유효 선택 자동 갱신, 대상 소멸·같은 ID 객체 교체·새 문맥 | 유효 선택은 유지한다. 소멸·교체·새 문맥은 이전 선택/티켓을 취소하고 오래된 대상에 변경하지 않는다. |
| 8 | 선택된 행을 누른 상태에서 다른 행·키/패드·탭·도구·새로고침으로 전환 후 떼기 | 취소한 누름이 뒤늦게 예약/해제하지 않는다. 상세는 읽기 전용이며 B는 바로 닫고 도구 B는 목록 복귀한다. |
| 9 | 미션 예약 전부터 정상 활성인 항목과, 이번 예약이 추가/교체한 항목에서 각각 해제 | 정상 활성 항목은 남는다. 직접 추가한 미소비 항목만 제거하고 직접 교체한 값만 원래대로 복원한다. |
| 10 | 미션 명시 해제 후 같은 문맥에서 위치 안내 재확인, 다음 명시 예약·새 문맥, 실제 소비·활성 사전/값 변경 | 안내만으로 해제한 대상이 재예약되지 않고 다음 명시 예약·새 문맥에서 억제가 풀린다. 게임이 반영한 진행·소비 결과나 활성 상태는 되돌리지 않는다. |
| 11 | A/B·스틱·트리거 홀드로 닫기, Alt-Tab·모드 전환·재연결·주사위 왕복 | 남은 입력은 해제·중립 뒤 반환한다. 게임 대화·취소·주사위·예약/해제로 중복 전달되지 않는다. |
| 12 | 네 탭의 짧고 긴 목록·상세, 창/글자 조절·재시작 | 목록 추적·상세 스크롤·필요한 스크롤바·설정 저장·한국어·읽음·선택지/조건 분기를 유지한다. |
