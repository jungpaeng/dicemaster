# v1.0.7-alpha.31 — 지도 로그의 장소 상세·자료 상태

<!-- alpha31-publication -->
v1.0.7-alpha.31 게시 준비 중. 로컬 전체21개 자동 검사·실제 DLL 연결·설치 ZIP 검증을 통과했다. 고정 커밋 재빌드·공개 다운로드는 게시 과정에서 기록한다. 이번 변경은 로그·진단 보완이며 최초 불러오기 흰색 마커 누락 버그는 미해결이다. 실제 Windows 확인과 PRD #6 완료는 대기다.

## 변경과 지원 범위

지도에서 포커스한 장소를 벗어난 뒤 로그를 열어도 마지막 유효한 장소의 상세를 새로 조회한다. 자동 화면의 현재 포커스는 별도이며 이전 툴팁/마커를 되살리지 않는다. 장소 미선택·미등록·조회 실패에도 지도 조회 성능 행에서 대상·등록 수·경로 준비/실패·로드된 자료 상태를 읽을 수 있다.

**이번 버전은 로그·진단 보완이다. 최초 불러오기 후 흰색 마커가 누락되는 버그는 미해결이다.** 필요한 자산 미로드와 횟수 분기 보류 등 실제 차단 지점을 새 진단으로 확인해야 한다. 사용자 Windows 실행에서 원인을 확정했다고 주장하지 않는다. [재현·구현·지원 경계](ISSUE-6-MAP-LOG-DIAGNOSTICS.md).

마지막 상세 대상과 실패 문맥은 새 게임/불러오기/장면/OFF 정리·Lua 문맥 무효화·종료에서 버린다. 상세는 현재 조건을 새로 읽으며 오래된 요청을 문맥 키로 거절한다. 진단은 기존 핸들과 캐시만 읽고 자산 검색·Lua 준비·조건/이벤트 실행을 추가하지 않는다. 본문 실패는 기존 실패/이전 값 상태와5초 재시도를 유지한다.

기존 정상0.25초/실패5초·숨김/창 가림/OFF 조회 중단·warm Lua 재분석 없음·읽기 전용·금색/아이보리 기준과 Xbox/XInput·키보드·마우스·터치·입력 소유권/해제/중립을 유지한다. #5 이벤트 선택·예약·로그 네 탭·주사위·상점·실제 분기 회귀를 포함한다. 새 설정·기본값·cfg 바이트 변화는 없다.

## 자동 검증

검토 후보의 전체21개 검사·296개 빌드 입력·119개 소스/리소스·16개 고정 게임 참조와 실제 후보 DLL 연결·ZIP 두 경로·CRC·내부 DLL/cfg 바이트를 확인했다. 배포 검증기 회귀20개도 통과했다. 고정 커밋 재빌드·후보 동일성·공개 다운로드 결과는 게시 후 보충한다.

MapGuideRouteIntegrationTests3748개·InformationRuntimeTests6016개·MapInformationTests679개·ChoiceStoryTests7719개·GamepadTests262831개를 포함한다. 포커스 해제 뒤 마지막 상세·현재 값 재조회, 자동 오버레이 부활 차단·문맥 정리·실패 중 독립 진단·5초 재시도·숨김/OFF·읽기 전용과 실제 DLL 연결을 확인했다. 관리 코드·명시적 Unity/게임 경계 검사이며 실제 Windows·native 화면·물리 입력·FPS 실행은 아니다.
