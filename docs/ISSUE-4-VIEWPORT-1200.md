# PRD #4 후속: 1920×1200 기준 창·글자 기본값

2026-10-19 KST. 사용자가 확인한 1920×1200 화면의 **872×960px 창과 20px 본문**을 새 기본값의 기준으로 사용한다.
너비는 화면 너비에 `872 / 1920`을, 높이는 화면 높이에 `960 / 1200`을 곱한 뒤 픽셀로 반올림한다.
기본 본문은 `20 × clamp(화면 높이 / 1200, 0.85, 4)`를 반올림하고 기존 12~64px 범위로 제한한다.
작은 화면에서 읽을 수 있는 최소 크기를 보존하기 위해 글자 배율의 하한 0.85를 유지한다.

| 화면 | 기본 창 크기 | 기본 본문 |
| --- | --- | --- |
| 1280×720 | 581×576 | 17px |
| 1920×1080 | 872×864 | 18px |
| 1920×1200 | 872×960 | 20px |
| 2560×1440 | 1163×1152 | 24px |
| 3440×1440 | 1562×1152 | 24px |
| 3840×2160 | 1744×1728 | 36px |

창은 기존과 같이 최소 540×440으로 보정하고 화면 크기를 상한으로 사용한다. 따라서 작은 화면에서는 위 비율 대신 화면 보정이 우선한다.
새 기본 위치는 화면 높이 배율을 적용한 `(20, 20)`이다. 창 크기 때문에 본문 글자를 다시 줄이지 않는다.

## 초기화와 기존 설정

첫 표시 때 유효한 화면 크기로 기본 배치를 결정하는 기존 지연 초기화를 유지한다. 생성자나 부팅 중 무효 화면에서는 배치를 저장하지 않는다.
기본 cfg와 `ConfigManager`는 해상도와 독립적인 씨앗 값 `(20, 20, 872, 960, 20)`을 사용한다.

이전 기본값을 그대로 쓰던 사용자는 첫 표시에서 새 기준으로 이행한다. 위치·크기·글자 전체가 다음 기본 배치 중 하나와 일치해야 한다.

- 이전 원래 씨앗: 750×750/14px, 1200×860/20px, 1280×960/20px, 1152×756/20px와 위치 `(20, 20)`.
- 현재 화면에 맞춰 계산했던 1200×860·1280×960 배율 기본값. 이 판별은 당시의 높이 `/1080` 배율과 글자를 사용한다.
- 현재 화면에 맞춰 계산했던 화면 너비 60%·높이 70% 기본값. 이 판별도 당시의 높이 `/1080` 위치·글자 배율을 사용한다.

예를 들어 이전 1920×1200 기본 배치는 창 1152×840, 위치 약 `(22.222, 22.222)`, 본문 22px이므로 새 기준으로 이행한다.
크기만 같은 사용자 지정 창은 이행 대상으로 판단하지 않는다. 좌표·크기의 허용 오차는 0.01px 미만이며 설정 직렬화 오차만 허용한다.
그 밖의 사용자 지정 배치와 글자는 기존 픽셀 값을 유지한다. 다른 해상도에서 저장한 배치도 현재 화면에서 알려진 기본값과 일치하지 않으면 보존한다.
첫 표시 후 해상도를 바꿀 때마다 창 비율을 강제로 다시 적용하지 않는다. 도구의 **창 위치·크기·글자 기본값 복구**는 현재 화면에서 새 기준을 계산한다.

cfg를 직접 바꿀 때는 기존 `[DiceMaster]` 섹션의 아래 다섯 키를 수정한다. 같은 키를 중복 추가하거나 다른 사용자 설정을 덮어쓸 필요가 없다.

```ini
[DiceMaster]
LogWindowX = 20
LogWindowY = 20
LogWindowWidth = 872
LogWindowHeight = 960
LogFontSize = 20
```

## 확인 범위와 Windows 검증

이 문서는 새 계산·이행 계약을 기록한다. [전체 후보·자동 검사·해시](ISSUE-4-READING-LAYOUT.md)를 따르며, 실제 Unity 화면 크기·배치·터치·패드 조작은 관리 대역 검사만으로 확인했다고 간주하지 않는다.
게임 설치·실행은 하지 않는다. 이슈 #4 완료와 prerelease 발행도 이번 기본값 수정만으로 결정하지 않는다.

| 확인 단계 | 기대 결과 | 실제 Windows 결과 |
| --- | --- | --- |
| 1920×1200에서 기본 cfg로 첫 열기 | 872×960px 창, 본문 20px | 확인 대기 |
| 같은 화면에서 도구 기본값 복구 후 재시작 | 첫 열기와 같은 크기·글자 | 확인 대기 |
| 1080p·1440p·4K에서 기본값 복구 | 위 표와 같은 크기·글자, 화면 안에 창 표시 | 확인 대기 |
| 이전 60%/70% 기본 배치 cfg로 첫 열기 | 전체 기본 배치가 일치하면 새 기본값 적용 | 확인 대기 |
| 크기·위치·글자를 사용자 지정한 cfg로 첫 열기 | 사용자 값 유지, 화면 밖 부분만 보정 | 확인 대기 |
| 부팅 초기 화면과 실제 플레이 해상도가 다름 | 표시 전 화면으로 cfg를 축소 저장하지 않음 | 확인 대기 |

DLL을 바꾸기 전에 기존 DLL·cfg를 백업한다. 문제 시 게임 종료 후 두 백업을 복원한다. 다른 UI·입력 확인은 [기존 Windows 검증표](ISSUE-4-WINDOWS-VALIDATION.md)를 함께 사용한다.
